# 港股控股回本公司讲解格式

目标读者：基于控股回本榜单做二次研究的人。

每家公司讲解优先回答三个问题：

1. 这家公司到底靠什么赚钱。
2. 为什么它会进入赚钱榜。
3. 最需要担心的业务、现金权属或利润质量问题是什么。

讲解顺序固定为：

1. 一句话业务：用大白话讲产品、客户和收费方式。
2. 收入结构：列最能解释生意的收入拆分，不够重要的小项合并。
3. 控股回本数字：列市值、折后可剥离净现金、经营业务购买价、折后现金利润、回本年和市值/现金利润。
4. 入榜原因：解释是清算便宜、主业便宜，还是两者都有。
5. 关键问题：现金能否拿走、利润能否持续、利润是否变成现金、是否依赖单一客户/产品/周期。

## IGG 示例

IGG（`00799.HK`）本质上是一个全球手游公司，不是传统工业公司。

大白话：它开发和运营手机游戏，靠玩家充值、游戏内消费，以及一部分 APP 业务赚钱。2025 年收入主要来自 `Lords Mobile`、`Doomsday: Last Survivors`、`Viking Rise`、其他游戏和 APP Business。它的经营特征是毛利高、固定资产轻、账上现金多，但利润波动也大。游戏公司不是靠厂房存货，而是靠爆款、老游戏生命周期、买量效率和研发运营能力。

按 2025 年 agent 核对后的主口径，单位折人民币亿元：

| 项目 | 数字 |
|---|---:|
| 市值 | 32.95 |
| 折后可剥离净现金 | 11.24 |
| 经营业务购买价 | 21.71 |
| 折后现金利润 | 3.41 |
| 控股回本年 | 6.37 |
| 市值/现金利润 | 9.66 |

为什么它进赚钱榜：不是因为极端清算便宜，而是“公司还有一大笔可剥离现金，扣掉现金后，剩下主业价格约 21.7 亿人民币；如果折后现金利润能维持在 3.4 亿人民币左右，大约 6.4 年回本”。

但要谨慎看三点：

1. 利润不稳定。2023 年核心业务利润很低，经营自由现金流为负；2024、2025 才明显恢复。所以不能按稳定消费股给高确定性。
2. 老游戏集中度高。`Lords Mobile` 仍是最大收入来源，如果老游戏流水下滑，新游戏接不上，利润会掉得很快。
3. 现金不能全扣。账上资金里有未上市股权、私募基金、内地现金、FVTPL 投资，还有年后拟派大额股息，所以只能用折后净现金。

简短备注：游戏公司，赚钱高波动。

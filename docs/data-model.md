# 财报与资产分类数据契约

## 目标读者

维护抓取、标准化、资产分类和报告生成流程的开发者与财报分析人员。

## 报告身份

一份报告由以下字段唯一识别：

```text
market + security_code + report_period + report_type
```

必须保存公司名称、公告时间、报告期间、报告类型、币种、单位、官方来源 URL、本地文件、SHA-256 和抓取时间。

默认分析报告使用最近年报口径：资产负债结构来自年末合并资产负债表，利润核心和现金流核心来自全年合并利润表和合并现金流量表。季度报告作为显式指定 period 的年内跟踪模式，不作为默认口径。

## 数据分层

### raw/filings

官方 PDF 原文和 `metadata.json`。PDF 不做原地修改；来源变化或更正版报告应生成新的版本记录。

### raw/statements

结构化接口完整响应。原始字段不得改名、缩放或删除，以便回溯数据源。

### normalized/facts

每条事实至少包含：

- `company_code`
- `report_period`
- `statement`
- `item_key`
- `source_field`
- `value`
- `currency`
- `unit`
- `source_type`
- `source_path`

### analysis/asset_structure

同时保存原始项目明细、分类汇总、权益口径、净额勾稽、利润核心和现金流核心：

```text
total_assets
  = funds_assets
  + operating_assets
  + investment_assets
  + other_assets

total_liabilities
  = financing_liabilities
  + operating_liabilities
  + investment_liabilities
  + other_liabilities

total_equity
  = net_funds
  + net_operating_assets
  + net_investment_assets
  + other_net_assets
```

每个资产或负债分类项目必须记录：原始字段、原始金额、标准名称、分类、业务实质、分类依据、证据报告和置信度。`business_substance` 说明现实业务里这项资产或负债是什么实物、权利或义务；`basis` 说明为什么把它归入资金、经营、投资或其他类别。主勾稽使用合并报表所有者权益合计；同时保存归属于母公司所有者权益、少数股东权益和少数股东权益占比。

利润核心必须保存本期和同比期的营业收入、营业成本、毛利、归母净利润；营业成本用于校验 `毛利 = 营业收入 - 营业成本`，不进入 Markdown 核心展示表。现金流核心必须保存本期和同比期的经营活动现金流净额、投资活动现金流净额、筹资活动现金流净额、现金及现金等价物净增加额。金额统一为人民币元。

当前股价必须单独保存为 `market_price`，至少包含证券代码、名称、币种、价格、行情时间、抓取时间、来源和来源 URL。当前股价属于市场行情数据，不参与财报公式勾稽；获取失败时不得复用旧价格。

## 分类边界

### 资金类资产

现金及现金等价物、可自由支取或可剥离的定期存款、大额存单、理财、基金、债券等。受限保证金不因名称含“货币资金”就自动视作可剥离资金。

### 经营类资产

随主业运转形成或为主业提供产能的资产，包括经营应收、预付款、存货、合同资产、固定资产、在建工程、使用权资产、经营性无形资产和长期待摊费用。

### 投资类资产

长期股权投资、以战略持有为目的的权益工具、投资性房地产等。只有能够脱离主业出售、且性质接近资金配置的投资，才可重分类为资金类资产。

### 其他资产

商誉、递延所得税资产、持有待售资产、性质混合的报表项目和暂时缺少附注证据的项目。

### 融资负债

短期借款、长期借款、一年内到期的非流动负债、应付债券、租赁负债和其他有息融资负债。不能把总负债当作融资负债。

### 经营负债

应付票据、应付账款、合同负债或预收款、应付职工薪酬、应交税费和其他经营应付款。与销售、采购、生产和履约循环直接相关。

### 投资性负债

能够直接归属于投资性资产、且未计入融资负债的投资义务。无法可靠识别对应负债时分别列示，不强行净额化。

### 其他负债

递延所得税负债、预计负债、持有待售负债、性质混合且暂时无法可靠拆分的负债。

## 净额与归母视角

```text
净资金 = 资金类资产 - 融资负债
净经营资产 = 经营类资产 - 经营负债
净投资资产 = 投资类资产 - 投资性负债
其他净资产 = 其他资产 - 其他负债
归母权益 = 所有者权益合计 - 少数股东权益
```

最终报告首屏汇总必须同时展示资产端和负债端，但不展示净额，固定结构如下：

```text
资金：资金类资产 / 融资负债
经营：经营类资产 / 经营负债
投资：投资类资产 / 投资性负债
```

净额用于 JSON 勾稽、结论归纳和必要解释，不进入首屏主表。资产端与负债端用于识别业务变化。其他净资产绝对值低于所有者权益合计 5% 时可标记为不重要，但不得删除明细或破坏勾稽。

人读报告必须在汇总表后解释资金、经营、投资三类资产端和负债端的主要构成，金额统一用亿元、保留两位小数。解释应覆盖足以理解该类别的主要项目，不能只写“其他”或只展示净额。

`其他` 的展示规则：

- `abs(other_net_assets) / total_equity >= 5%` 时，必须单独列示并解释其他资产和其他负债构成。
- 低于 5% 且主要由递延所得税、应付股利、政府补助递延收益、普通受限保证金等常规项目构成时，可以不列入主表，也不展开说明。
- 低于 5% 但存在非常规、不透明、一次性、或可能改变判断的项目时，应在存疑或异常段单独说明，不必放入主表。

构成解释应尽量把会计科目翻译成业务事实：

- 存货：说明是原材料、在产品、自制半成品/基酒、成品酒、包装物、发出商品等；季报没有拆分时引用最近年报构成并标注证据期。
- 票据与应收款项融资：说明是银行承兑汇票、商业承兑汇票、信用证还是其他结算工具。
- 合同负债与预收款项：说明是否是经销商或客户先款后货形成的交付义务。
- 固定资产、在建工程、无形资产：说明是生产设备、厂房、包装、智能仓储、土地、软件或其他经营设施。
- 不透明项目：如“监管商品”“监管商品款项”，只有在财报、业绩说明会、投资者关系活动记录、交易所互动问答或公告提供可追溯解释时才展开；否则保留科目名并说明业务合同细节未披露。

资产负债结构后必须追加两张核心表：

```text
## 资产负债结构
类别 / 资产端 / 负债端

## 利润核心
利润核心：营业收入 / 毛利 / 归母净利润

## 现金流核心
现金流核心：经营活动现金流净额 / 投资活动现金流净额 / 筹资活动现金流净额 / 现金及现金等价物净增加额
```

Markdown 使用上述固定二级标题，每张表前写 `单位：亿元`。利润和现金流两张表只放核心数字；文字说明负责解释业务含义。常规小项不解释，重要、异常、非常规、不透明或影响判断的项目必须说明。毛利使用营业收入减营业成本计算；现金流说明需要区分经营造血、投资配置或资本开支、融资或分红等动作。

报告标题下方必须展示当前股价、行情时间和来源。股价通过项目内 `a-share-price-fetch` skill 获取，不由财报 agent 自行选择行情接口。

## 重要性与勾稽

- 公式差额阈值：`max(总资产 × 0.5%, 100万元)`。
- 单个待复核项目超过总资产 5%：分类状态不得为高置信度。
- 投资类或其他类超过总资产 10%：汇总报告必须解释构成。
- 其他净资产绝对值超过所有者权益合计 5%：汇总报告必须解释构成；低于 5% 的常规其他项目默认弱化，低于 5% 的非常规项目进入存疑或异常段。
- 季报沿用年报附注分类时，若相关报表科目较年末变化超过 20%，必须重新复核，不能机械沿用。

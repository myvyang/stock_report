# 行业知识库索引

- Created: 2026-08-03 Asia/Shanghai
- Purpose: 按行业归纳可复用研究资料。每个行业一个目录，目录内用 `index.md` 说明已有文档、阅读顺序和后续缺口。

## 目录约定

```text
data/knowledge/industries/
-> index.md
-> <industry>/
   -> index.md
```

行业知识库只沉淀能复用的结构和判断，不记录零散对话过程。过程性学习笔记、草稿和临时研究材料可以继续放在 `data/analysis/industry_learning/<industry>/`，由行业 `index.md` 统一索引。等某份草稿稳定后，再迁入知识库正文。

每个行业 `index.md` 至少说明：

- 行业范围：这套知识库讨论什么，不讨论什么。
- 阅读顺序：从产品树、经营逻辑、供应链、公司映射到投资判断如何读。
- 核心文档：哪些文档是稳定复习入口。
- 草稿文档：哪些文档仍是学习或验证中的资料。
- 后续缺口：哪些问题还没有研究清楚。

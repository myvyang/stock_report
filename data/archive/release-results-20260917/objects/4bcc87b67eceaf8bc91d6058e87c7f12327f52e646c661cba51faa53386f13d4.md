## P0115-P0125

### P0115-P0116
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——租赁
- 内容：承租人租赁负债在初始确认后的调整、重新计量条件，以及租赁修改是否作为单独租赁和相关计量处理；折算租赁负债、使用权资产及租赁政策时应定向打开
- 主题：会计口径
- 重要性：相关
- 关键词：租赁负债, 使用权资产, 租赁修改, 重新计量

### P0117-P0118
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——收入确认
- 内容：履约义务、控制权转移及按时段或时点确认收入的判断，并说明合同负债和可变代价的处理；折算收入、合同负债及收入确认口径时应定向打开
- 主题：收入成本费用
- 重要性：核心
- 关键词：收入确认, 履约义务, 控制权, 合同负债, 可变代价

### P0119-P0119
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——收入确认、利息收入及外币
- 内容：应付客户代价冲减交易价格和收入的时点、现金管理相关利息收入列报，以及外币交易和货币项目的换算与汇兑差额处理；折算收入扣减、其他收入及汇兑项目时应定向打开
- 主题：收入成本费用
- 重要性：相关
- 关键词：应付客户代价, 销售回扣, 利息收入, 外币, 汇兑差额

### P0120-P0120
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——借款成本及政府补助
- 内容：借款成本在发生期间的损益确认，以及政府补助的确认条件、递延收入、系统化转入损益和与收入或费用相关的列报方式；折算融资成本、其他收入及相关资产成本时应定向打开
- 主题：现金投资融资
- 重要性：相关
- 关键词：借款成本, 政府补助, 递延收入, 其他收入

### P0121-P0121
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——员工福利
- 内容：退休福利供款、短期员工福利、应付员工福利负债及其他长期员工福利负债的确认和计量；折算员工成本、应付项目及长期福利负债时应定向打开
- 主题：收入成本费用
- 重要性：相关
- 关键词：员工福利, 退休福利, 工资薪金, 长期员工福利

### P0122-P0124
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——税项
- 内容：即期税项与递延税项、暂时差额、递延税项资产可收回性、投资相关税项、租赁交易税项及税项抵销和确认位置；折算所得税费用、递延税项资产负债及权益相关税项时应定向打开
- 主题：税项
- 重要性：核心
- 关键词：即期税项, 递延税项, 暂时差额, 税项资产, 税项负债

### P0125-P0125
- 原文章节：综合财务报表附注 3.2 重大会计政策信息——物业、厂房及设备
- 内容：物业、厂房及设备及在建或安装资产的成本、减值、可使用时开始折旧，以及试运行产出相关收入和成本的处理；折算固定资产、在建工程、折旧及相关损益时应定向打开
- 主题：经营资产
- 重要性：相关
- 关键词：物业厂房及设备, 在建工程, 折旧, 减值

## P0115-P0122

### P0115-P0117
- 原文章节：Corporate Governance Report — People and Governance Risk、Financial Risk
- 内容：涵盖人才招聘与留任、反欺诈与反腐败、气候变化、数据安全及个人资料保护等风险控制；随后转入资产估值、利率、汇率、流动性及信用/交易对手风险，以及新兴房地产风险的识别和缓释。涉及后续折算时，可定向打开相关经营资产、现金投资融资和周转资金的权威分页原文。
- 主题：承诺风险关联方, 经营资产, 现金投资融资, 周转资金
- 重要性：相关
- 关键词：人才与治理风险, 气候风险, 数据安全, 资产估值, 利率汇率, 流动性, 信用风险

### P0118-P0118
- 原文章节：Corporate Governance Report — Code of Conduct
- 内容：说明行为准则的覆盖范围、执行责任、违规处理、举报机制及内部审计向审计委员会的汇报安排，并介绍诚信培训与利益冲突申报。属于治理制度定位页，通常不作为三表折算的首要打开页。
- 主题：公司治理
- 重要性：相关
- 关键词：行为准则, 举报机制, 反腐败, 内部审计, 利益冲突

### P0119-P0119
- 原文章节：Corporate Governance Report — Inside Information、Independence of External Auditor
- 内容：说明内幕信息披露政策、结果公告及信息使用控制，并说明外聘核数师独立性、审计委员会监督和非审计服务管理。页末进入核数师服务费用披露，后续如需核对审计相关披露可定向打开本页原文。
- 主题：公司治理, 会计口径
- 重要性：相关
- 关键词：内幕信息, 信息披露, 外聘核数师, 审计委员会, 审计独立性

### P0120-P0121
- 原文章节：Corporate Governance Report — Communication With Stakeholders / Shareholders
- 内容：介绍股东沟通政策、股东信函、股东周年大会及投票安排，随后列出股东大会决议事项、股东召集会议和提出议案的程序，以及提名董事候选人的程序。主要用于公司治理和股东权利的原文定位，不替代财务报表页面。
- 主题：公司治理, 股东权益
- 重要性：普通
- 关键词：股东沟通, 股东周年大会, 投票, 股东议案, 董事提名

- 主题：股东权益, 公司治理
- 重要性：相关
- 关键词：股东查询, 投资者, 注册地, 持股范围, 股东结构

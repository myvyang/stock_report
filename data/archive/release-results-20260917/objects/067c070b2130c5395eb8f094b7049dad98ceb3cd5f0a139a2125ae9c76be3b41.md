## P0221-P0232

### P0221-P0222
- 原文章节：XII. Financial Report — Notes to the Consolidated Financial Statements
- 内容：税费及行政费用、财务费用、按性质分类的费用，以及资产减值损失附注；折算时应定向打开以核对费用结构、融资成本、减值项目及其与损益表的对应关系
- 主题：收入成本费用
- 重要性：核心
- 关键词：税费及附加, 行政费用, 财务费用, 按性质分类的费用, 资产减值

### P0223-P0225
- 原文章节：XII. Financial Report — Notes to the Consolidated Financial Statements
- 内容：信用减值、资产处置损益、其他收益、投资收益及所得税费用和税率调节；折算时应定向打开以核对非经营性损益、税项口径和递延所得税影响
- 主题：税项
- 重要性：核心
- 关键词：信用减值, 资产处置, 其他收益, 投资收益, 所得税费用, 税率调节

### P0226-P0226
- 原文章节：XII. Financial Report — Notes to the Consolidated Financial Statements
- 内容：基本及稀释每股收益的计算说明，包括归属于普通股股东的利润、加权平均股数及潜在普通股调整；折算时应定向打开以核对每股收益口径与股本摊薄因素
- 主题：财务主表
- 重要性：相关
- 关键词：基本每股收益, 稀释每股收益, 加权平均股数, 潜在普通股

### P0227-P0228
- 原文章节：XII. Financial Report — Notes to the Consolidated Financial Statements
- 内容：现金流量表中其他经营、投资及融资活动的收支项目，以及租赁负债现金支付和PPP项目建设支出的列报说明；折算时应定向打开以核对现金流分类和投资融资现金流口径
- 主题：现金投资融资
- 重要性：核心
- 关键词：其他经营活动现金流, 其他投资活动现金流, 其他融资活动现金流, 租赁负债, PPP项目

### P0229-P0231
- 原文章节：XII. Financial Report — Notes to the Consolidated Financial Statements
- 内容：现金流量表补充资料，包括净利润调节经营活动现金流、现金及现金等价物变动、融资活动负债变动、现金及现金等价物构成和外币货币性项目；折算时应定向打开以核对现金流间接法调节、融资负债滚动及现金余额口径
- 主题：现金投资融资
- 重要性：核心
- 关键词：经营活动现金流调节, 现金及现金等价物, 融资活动负债变动, 外币货币性项目

### P0232-P0232
- 原文章节：XII. Financial Report — Interests in Other Entities
- 内容：集团子公司构成及各实体的注册地、主要业务、资本信息、持股比例和取得方式；折算时应定向打开以核对合并范围、直接及间接持股和主体层级
- 主题：会计口径
- 重要性：相关
- 关键词：其他实体权益, 子公司, 合并范围, 直接持股, 间接持股, 取得方式

## P0021-P0029

### P0021-P0023
- 原文章节：Corporate Governance Report — Directors
- 内容：董事轮值及重选、独立非执行董事独立性、董事背景与董事会职责安排；并延续至主席与 CEO 分工、董事会会议及信息获取、董事证券交易守则和持续培训。涉及公司治理运作位置，后续如需核对治理结构或董事变动可定向打开。
- 主题：公司治理
- 重要性：相关
- 关键词：董事轮值, 独立非执行董事, 主席与CEO, 董事会会议, 证券交易守则, 董事培训

### P0024-P0024
- 原文章节：Corporate Governance Report — Directors’ Remuneration
- 内容：薪酬委员会的职能、成员与年度工作，以及执行董事和高级管理层薪酬政策；薪酬明细被指向合并财务报表相关附注，后续涉及人工成本或关联薪酬核对时定向打开。
- 主题：公司治理, 收入成本费用
- 重要性：相关
- 关键词：薪酬委员会, 董事薪酬, 高级管理层, 薪酬政策, 薪酬附注

### P0025-P0026
- 原文章节：Corporate Governance Report — Directors’ Nomination
- 内容：提名委员会的职责、董事会组成评估、独立性评估、董事委任与重选及继任规划；并说明委员会成员和年度工作，后续核对董事治理结构及任免事项可定向打开。
- 主题：公司治理
- 重要性：相关
- 关键词：提名委员会, 董事会组成, 独立性评估, 董事委任, 重选, 继任规划

### P0027-P0028
- 原文章节：Corporate Governance Report — Implementation of Board Diversity Policy
- 内容：董事会多元化政策的年度目标、评估与继任者培养安排，并延续至高级管理层继任来源；同时进入问责与审计部分，介绍审计委员会的职责范围，包括财务报告审阅、外部审计、内部控制及举报机制。后续核对治理政策与审计监督边界可定向打开。
- 主题：公司治理, 会计口径, 承诺风险关联方
- 重要性：相关
- 关键词：董事会多元化, 继任者, 高级管理层, 审计委员会, 财务报告审阅, 内部控制, 举报机制

### P0029-P0029
- 原文章节：Corporate Governance Report — Accountability and Audit, Audit Committee
- 内容：审计委员会成员与会议安排，以及年度内对财务报告、审计委聘、审计范围与费用、审计师独立性、内部控制和举报政策等事项的审阅；后续若需定向核对审计监督、会计审阅或内部控制信息，应打开本页原文。
- 主题：公司治理, 会计口径, 承诺风险关联方
- 重要性：核心
- 关键词：审计委员会, 财务审阅, 外部审计, 审计师独立性, 内部控制, 举报政策

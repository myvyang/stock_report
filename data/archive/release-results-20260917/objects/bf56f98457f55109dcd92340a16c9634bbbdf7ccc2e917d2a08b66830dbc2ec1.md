## P0056-P0064

### P0056-P0056
- 原文章节：Corporate Governance Report
- 内容：董事年度培训记录，以及董事对年度报告披露和合并财务报表编制责任的说明；后续理解治理责任边界时可定向打开
- 主题：公司治理
- 重要性：普通
- 关键词：董事培训, 董事责任, 合并财务报表, 持续经营

### P0057-P0058
- 原文章节：Corporate Governance Report
- 内容：董事证券交易守则、内部控制与风险管理、举报及反贿赂反腐败安排，并延续至内幕消息披露和投资者关系沟通；公司治理与风险口径变化时可定向打开
- 主题：承诺风险关联方
- 重要性：相关
- 关键词：证券交易守则, 内部控制, 风险管理, 举报, 反贿赂, 内幕消息, 投资者关系

### P0059-P0060
- 原文章节：Corporate Governance Report
- 内容：股东大会出席安排、股东召开特别股东大会及提出议案/董事候选人的权利、投票程序、组织章程文件和股息政策；权益变动或分配政策核对时可定向打开
- 主题：股东权益
- 重要性：相关
- 关键词：股东权利, 股东大会, 投票, 组织章程, 股息政策

### P0061-P0061
- 原文章节：Directors’ Report
- 内容：主要活动和业务回顾所引用的报告章节，以及业绩与利润分配事项；折算收入、利润和股东分配时应回到本页及其所指向的主表/附注
- 主题：收入成本费用
- 重要性：核心
- 关键词：主要活动, 业务回顾, 集团业绩, 利润分配, 中期股息, 末期股息

### P0062-P0062
- 原文章节：Directors’ Report
- 内容：银行及其他借款、债券/票据发行、五年财务摘要、投资物业及物业厂房设备、主要物业、股本和储备的附注及分页索引；折算负债、经营资产和权益时应定向打开
- 主题：现金投资融资
- 重要性：核心
- 关键词：银行借款, 其他借款, 债券, 财务摘要, 投资物业, 物业厂房设备, 股本, 储备

### P0063-P0064
- 原文章节：Directors’ Report
- 内容：董事名单、轮值退任与重选、上市规则董事资料披露、董事酬金/奖金及服务合约，并指向退休福利计划附注；治理、权益和人员成本分类需核对时可定向打开
- 主题：公司治理
- 重要性：相关
- 关键词：董事名单, 轮值退任, 董事酬金, 奖金, 服务合约, 退休福利

## P0034-P0040

### P0034-P0035
- 原文章节：Corporate Governance Report
- 内容：董事长与联席行政总裁职责安排、董事委任及重选程序、董事会和董事会委员会会议安排；随后列示会议出席、证券交易守则遵守情况，以及董事会对重大事项和日常管理的授权边界
- 主题：公司治理
- 重要性：相关
- 关键词：董事委任重选, 董事会会议, 出席情况, 证券交易守则, 授权

### P0036-P0038
- 原文章节：Corporate Governance Report
- 内容：公司治理职能及审计委员会职责、组成和履职事项；继而介绍提名委员会的组成、会议履历、董事提名标准、提名政策与董事会多元化政策，涉及独立性、继任安排及董事会构成
- 主题：公司治理, 会计口径, 承诺风险关联方
- 重要性：相关
- 关键词：审计委员会, 风险管理与内部控制, 提名委员会, 董事独立性, 董事会多元化

### P0039-P0039
- 原文章节：Corporate Governance Report
- 内容：薪酬委员会的组成、职责范围和年度会议履历，说明其审阅董事及高级管理层薪酬、个别薪酬建议和股份期权计划的治理流程
- 主题：公司治理, 收入成本费用
- 重要性：相关
- 关键词：薪酬委员会, 董事薪酬, 高级管理层薪酬, 股份期权计划

### P0040-P0040
- 原文章节：Corporate Governance Report
- 内容：董事薪酬资料的交叉引用，以及董事对财务报表编制责任的说明；本页还披露持续经营基础所涉及的重大不确定性、管理层应对依据及审计师报告对应位置，后续应定向打开独立核数师报告 P0044-P0046 和财务报表 Note 14
- 主题：公司治理, 承诺风险关联方, 财务主表
- 重要性：核心
- 关键词：董事薪酬, 财务报告责任, 持续经营, 重大不确定性, 独立核数师报告

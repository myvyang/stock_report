## P0042-P0051

### P0042-P0042
- 原文章节：Corporate Governance Report
- 内容：风险管理与内部控制的组织安排、年度审阅及反贪腐和举报政策；另说明内幕信息的保密、授权接触和对外披露控制
- 主题：公司治理, 承诺风险关联方
- 重要性：相关
- 关键词：内部审计, 风险管理, 内部控制, 反贪腐, 内幕信息

### P0043-P0045
- 原文章节：Corporate Governance Report
- 内容：董事会向审计委员会授予企业管治职能，并集中列示股东召集特别股东大会、提出议案或声明等权利及程序；后续查阅股东权利和治理合规安排时定向打开
- 主题：公司治理
- 重要性：普通
- 关键词：企业管治职能, 股东权利, 特别股东大会, 议案程序

### P0046-P0046
- 原文章节：Corporate Governance Report
- 内容：股东向董事会查询的渠道、宪章性文件年度变动情况，以及与股东和投资者持续沟通的政策框架；可用于定位治理披露和信息沟通安排
- 主题：公司治理
- 重要性：普通
- 关键词：董事会查询, 宪章性文件, 股东沟通

### P0047-P0048
- 原文章节：Corporate Governance Report
- 内容：股东大会及报告披露的沟通执行情况，并说明股息政策的宣派条件、形式、董事会考虑因素及政策的非承诺性质；折算股东权益、现金分配或融资约束时应定向打开
- 主题：股东权益, 现金投资融资, 公司治理
- 重要性：相关
- 关键词：股东大会, 股息政策, 分派条件, 留存收益, 营运资金

### P0049-P0049
- 原文章节：Directors’ Report
- 内容：董事会报告引言、集团主要业务及业务回顾的交叉索引，并提示已终止经营事项；同时概述利率、外汇、信用和流动性等主要风险及其财报附注索引
- 主题：业务与经营, 承诺风险关联方
- 重要性：相关
- 关键词：主要业务, 业务回顾, 终止经营, 利率风险, 外汇风险, 流动性风险

### P0050-P0050

### P0051-P0051

- 重要性：核心
- 关键词：员工, 客户, 供应商, 银行融资, 合并财务报表, 股息

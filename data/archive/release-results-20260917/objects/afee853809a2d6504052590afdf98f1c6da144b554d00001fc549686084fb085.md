## P0026-P0033

### P0026-P0027
- 原文章节：Corporate Governance Report — Board Committees / Audit Committee
- 内容：董事任期、独立非执行董事安排，以及审计委员会的组成、职责、权限、审阅事项和会议参与情况；后续定向阅读可关注财务报告、内部控制、风险管理及外部审计监督的治理接口
- 主题：公司治理
- 重要性：相关
- 关键词：独立非执行董事, 审计委员会, 财务报告, 内部控制, 风险管理

### P0028-P0029
- 原文章节：Corporate Governance Report — Nomination Committee
- 内容：提名委员会的组成和职责、董事提名与独立性评估、董事会多元化政策及执行安排，并列示本期提名委员会工作与会议参与情况；后续定向阅读可关注董事会结构、任命标准及性别多元化披露
- 主题：公司治理
- 重要性：相关
- 关键词：提名委员会, 董事提名, 董事独立性, 董事会多元化, 性别多元化

### P0030-P0031
- 原文章节：Corporate Governance Report — Remuneration Committee / Communication with Shareholders and Investor Relations
- 内容：薪酬委员会职责、执行董事薪酬评估、服务合约及股份奖励计划相关审阅事项，随后说明股东沟通、投票及投资者关系安排；后续定向阅读可关注股份奖励与董事薪酬的相关附注，以及公司与股东沟通机制
- 主题：公司治理
- 重要性：相关
- 关键词：薪酬委员会, 执行董事薪酬, 股份奖励计划, 股东沟通, 投资者关系

### P0032-P0033
- 原文章节：Corporate Governance Report — Shareholders’ rights
- 内容：股东召开特别股东大会、在股东大会提出议案或要求发布决议及声明的权利、适用门槛和程序条件；后续定向阅读可关注股东权利、会议召集及议案通知的程序性披露
- 主题：公司治理
- 重要性：普通
- 关键词：股东权利, 特别股东大会, 股东提案, 决议通知, 公司法

## P0041-P0045

### P0041-P0041
- 原文章节：治理——Corporate Governance Report
- 内容：公司治理总述、董事证券交易守则遵守情况，以及董事会的职责、授权边界、委员会设置和董事履职支持安排；折算三表时通常不作为直接财务主表来源，但可用于定向了解治理与风险监督框架
- 主题：公司治理
- 重要性：相关
- 关键词：公司治理, 董事证券交易, 董事会职责, 委员会, 风险管理

### P0042-P0042
- 原文章节：治理——Corporate Governance Report
- 内容：董事委任、重选及轮值退任安排，主席与行政总裁的职责分工，以及非执行董事和独立非执行董事的角色；折算三表时可在需要核查治理责任与关键管理安排时定向打开
- 主题：公司治理
- 重要性：相关
- 关键词：董事委任, 董事重选, 主席, 行政总裁, 独立非执行董事

### P0043-P0043
- 原文章节：治理——Corporate Governance Report
- 内容：非执行董事独立性及任职年限说明、董事会组成和董事之间的关系披露，并指向董事履历分页；折算三表时可用于定向核查董事会结构及关联关系披露背景
- 主题：公司治理
- 重要性：相关
- 关键词：董事独立性, 董事会组成, 董事履历, 关联关系

### P0044-P0044
- 原文章节：治理——Corporate Governance Report
- 内容：董事会会议制度、年度审议与监督事项、董事获取经营及行业信息的机制、书面决议和专业意见安排，以及会议记录保存要求；折算三表时可在核查重大事项监督、内部控制或关联交易治理时定向打开
- 主题：公司治理
- 重要性：相关
- 关键词：董事会会议, 监督事项, 内部控制, 关联交易, 会议记录

### P0045-P0045
- 原文章节：治理——Corporate Governance Report
- 内容：董事出席记录部分，列示董事会、董事会各委员会、股东大会及持续专业发展培训等项目的年度记录表；折算三表时通常不直接提供主表数据，但可在需要核查治理参与度时定向打开
- 主题：公司治理
- 重要性：普通
- 关键词：董事出席, 董事会委员会, 股东大会, 持续专业发展

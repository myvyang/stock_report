## P0153-P0160

### P0153-P0153
- 原文章节：Sustainability Report
- 内容：可持续性会计准则指标表的赌场吸烟环境、反洗钱及活动指标；页面主要用于定位非财务运营与治理披露
- 主题：承诺风险关联方
- 重要性：相关
- 关键词：吸烟区域, 反洗钱, 活动指标, 博彩桌台, 博彩机, 博彩面积

### P0154-P0154
- 原文章节：Corporate Governance Report
- 内容：公司战略与文化、道德与诚信要求、反腐败及反洗钱合规安排，以及公司治理守则和董事证券交易守则的遵循情况
- 主题：公司治理
- 重要性：相关
- 关键词：公司战略, 企业文化, 道德与诚信, 反洗钱, 公司治理守则, 董事证券交易

### P0155-P0157
- 原文章节：Corporate Governance Report
- 内容：董事会构成、技能与多元化分析，独立董事资格与独立性评估，董事会会议流程、资料和会议记录要求，以及董事出席情况和董事会独立性机制
- 主题：公司治理
- 重要性：相关
- 关键词：董事会构成, 独立非执行董事, 董事会流程, 董事会会议, 出席情况, 董事会独立性

### P0158-P0159
- 原文章节：Corporate Governance Report
- 内容：主席与行政总裁的职责分工、非执行董事任期、董事会对战略和财务报告及风险管理内控的职责，以及董事承诺、上任培训和持续专业发展
- 主题：公司治理
- 重要性：核心
- 关键词：主席与行政总裁, 董事职责, 财务报告, 风险管理, 内部控制, 董事培训

### P0160-P0160
- 原文章节：Corporate Governance Report
- 内容：董事会向审计、薪酬、提名及反洗钱监督委员会的授权，审计委员会对财务报告、风险管理、内部控制和外部审计关系的监督，以及举报政策的责任分工；后续核对财务报表相关治理与内控时应定向打开
- 主题：公司治理
- 重要性：核心
- 关键词：董事会授权, 审计委员会, 财务报告, 内部控制, 外部审计, 举报政策

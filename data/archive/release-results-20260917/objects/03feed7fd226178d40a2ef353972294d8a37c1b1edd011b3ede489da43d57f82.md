## P0022-P0028

### P0022-P0022
- 原文章节：企业管治报告——核心价值、企业文化及董事证券交易
- 内容：说明集团以供水、环境责任和可持续发展为导向的核心价值与文化建设，并交代董事证券交易遵守上市发行人董事进行证券交易的标准守则；文化、ESG及合规背景可作治理脉络参考，证券交易部分属于治理合规披露。
- 主题：公司治理
- 重要性：相关
- 关键词：核心价值, 企业文化, 可持续发展, ESG, 董事证券交易, Model Code

### P0023-P0023
- 原文章节：企业管治报告——董事会及董事委员会
- 内容：介绍报告期末董事会的组成、独立非执行董事的资格与独立性、董事会职责和管理层授权范围，以及审计、提名和薪酬三个委员会的设立及职权依据；后续理解治理结构、财务监督和风险控制时应定向打开。
- 主题：公司治理
- 重要性：相关
- 关键词：董事会组成, 执行董事, 非执行董事, 独立非执行董事, 董事会职责, 董事委员会

### P0024-P0024
- 原文章节：企业管治报告——审计委员会及薪酬委员会
- 内容：列示审计委员会成员及其对会计政策、财务报告、内外部审计、风险管理、内部控制和ESG的监督职责，并记录报告期内会议事项；随后开始说明薪酬委员会的组成，财务报告和内部控制相关治理信息后续折算时值得定向核对。
- 主题：公司治理
- 重要性：核心
- 关键词：审计委员会, 会计政策, 财务报告, 内部审计, 外部审计, 风险管理, 内部控制, ESG, 薪酬委员会

### P0025-P0025
- 原文章节：企业管治报告——薪酬委员会、董事及高级管理层薪酬、提名委员会
- 内容：说明薪酬委员会对董事及高级管理层薪酬和股份计划的职责，指向综合财务报表附注中的董事薪酬披露，并介绍提名委员会的组成、董事提名及任免审议工作；后续如需核对管理层报酬或治理相关费用，应定向打开本页及所指附注。
- 主题：公司治理
- 重要性：相关
- 关键词：董事薪酬, 高级管理层薪酬, 股份计划, 综合财务报表附注14, 提名委员会, 董事任免

### P0026-P0026
- 原文章节：企业管治报告——董事会多元化政策及会议出席记录

- 主题：公司治理
- 重要性：相关
- 关键词：董事会多元化, 性别代表, 多元化政策, 董事会会议, 委员会会议, 出席记录

### P0027-P0027
- 原文章节：企业管治报告——董事会运作、董事职责及财务报告责任
- 内容：说明董事获取会议资料、寻求独立专业意见、会议记录及年度检讨机制，随后交代主席与行政总裁职能安排、董事持续专业发展、公司秘书培训，以及董事对年度账目编制、会计政策选择、估计判断和持续经营评估的责任；财务报告责任与审计师报告的页码指引值得后续定向打开。
- 主题：公司治理
- 重要性：核心
- 关键词：董事会运作, 独立意见, 主席, 行政总裁, 公司秘书, 账目编制责任, 会计政策, 判断和估计, 持续经营, 独立核数师报告

### P0028-P0028

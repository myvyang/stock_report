## P0216-P0223

### P0216-P0219
- 原文章节：Corporate Governance Report
- 内容：企业风险管理、财务报告内部控制及年度有效性审阅；董事对财务报表的责任、核数师酬金、公司秘书安排；股东沟通、股东大会提案与问询程序、章程文件修订及股息政策指引
- 主题：公司治理, 承诺风险关联方
- 重要性：相关
- 关键词：企业风险管理, 内部控制, 董事责任, 核数师酬金, 股东沟通, 股东大会, 章程文件, 股息政策

### P0220-P0220
- 原文章节：Independent Auditor’s Report
- 内容：独立核数师对合并财务报表的审计意见、审计范围与涵盖的报表及附注、美国公认会计原则和香港公司条例口径，以及审计基础与独立性说明；后续定向打开合并财务报表及附注起止页核对三表和会计口径
- 主题：财务主表, 会计口径
- 重要性：核心
- 关键词：独立核数师报告, 审计意见, 合并财务报表, 审计基础, U.S. GAAP, 香港公司条例

### P0221-P0223
- 原文章节：Independent Auditor’s Report — Key Audit Matters
- 内容：关键审计事项及审计应对，聚焦车辆保修准备，以及业务合并中取得的无形资产和或有代价相关衍生负债的估值；涉及准备估计、收购会计、估值方法、预测收入、特许权费率、折现率和交付量等判断，后续定向打开相关财务报表附注核对估计与分类
- 主题：经营资产, 收入成本费用, 会计口径
- 重要性：核心
- 关键词：关键审计事项, 保修准备, 业务合并, 无形资产估值, 衍生负债, 或有代价, 估计不确定性

## P0076-P0083

### P0076-P0077
- 原文章节：3. Corporate Governance Report — Governance framework for the Board
- 内容：公司秘书职责、董事会公司治理指引、董事会审批与授权政策，以及商业行为与道德、反腐败、举报与不报复等治理政策；后续查看时可用于定位董事会授权边界、治理流程和合规制度。
- 主题：公司治理
- 重要性：相关
- 关键词：公司秘书, 公司治理指引, 审批与授权, 商业道德, 反腐败, 举报政策

### P0078-P0078
- 原文章节：3. Corporate Governance Report — Board effectiveness and evaluation
- 内容：董事入职与持续培训安排、年度培训议题及董事会年度自我评估；后续查看时可用于定位董事会履职、培训和治理有效性披露。
- 主题：公司治理
- 重要性：相关
- 关键词：董事培训, 入职安排, 董事会评估, ESG培训, 风险管理培训

### P0079-P0080
- 原文章节：3. Corporate Governance Report — Directors’ responsibility for Financial Reporting; Board activities in 2023
- 内容：董事对财务报告的责任、董事会会议与年度活动，以及运营业务监督、治理、财务、监管和其他事项；后续查看时可定向打开以了解预算审批、投资项目、财务报告审阅、融资与关联交易治理事项的董事会监督位置。
- 主题：公司治理
- 重要性：相关
- 关键词：财务报告责任, 董事会活动, 预算, 投资项目, 财务报告审阅, 融资, 关联交易

### P0081-P0082
- 原文章节：3.4.2 Audit Committee
- 内容：审计委员会的组成、职责和年度工作，涵盖外部审计关系、财务信息审阅、内部审计、风险管理、内部控制、财务报告系统及持续关联交易；后续查看时应定向打开以定位审计监督、风险控制和财务报告审查依据。
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：审计委员会, 外部审计, 财务信息, 内部审计, 风险管理, 内部控制, 关联交易

### P0083-P0083
- 原文章节：3.4.3 Remuneration Committee
- 内容：薪酬委员会的组成、职责和年度工作，涉及薪酬政策结构、董事及高级管理层薪酬、激励与股权奖励计划及奖励授予；后续查看时可定向打开以定位薪酬治理和股权激励披露。
- 主题：公司治理
- 重要性：相关
- 关键词：薪酬委员会, 薪酬政策, 高级管理层, 激励计划, 股权奖励

## P0071-P0078

### P0071-P0072
- 原文章节：董事会报告（Directors’ Report）
- 内容：高级管理人员履历与职责；随后说明董事服务合同、董事在交易/安排/合同中的权益、董事责任保险及董事取得股份或债券的安排
- 主题：公司治理
- 重要性：相关
- 关键词：高级管理层, 董事服务合同, 董事权益, 责任保险

### P0073-P0074
- 原文章节：董事会报告（Directors’ Report）
- 内容：董事及最高行政人员在公司及关联公司的股份、相关股份和债权证中的权益与淡仓披露，并附权益性质、奖励股份计划及持股口径说明
- 主题：股东权益
- 重要性：相关
- 关键词：董事证券权益, 关联公司权益, 长仓, 奖励股份计划

### P0075-P0075
- 原文章节：董事会报告（Directors’ Report）
- 内容：关联交易章节及结构合同安排的背景、适用外资限制、经济利益与控制安排；说明报告期内结构合同及相关情形没有重大变化
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：关联交易, 结构合同, OPCO, 外资限制, 可变利益实体

### P0076-P0076
- 原文章节：董事会报告（Directors’ Report）
- 内容：结构合同相关监管要求及法律不确定性，包括中国监管规则解释、未来法律变化和结构合同被视为外商投资安排时的潜在影响
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：结构合同风险, 中国监管, 外商投资法, 负面清单, 法律不确定性

### P0077-P0078
- 原文章节：董事会报告（Directors’ Report）
- 内容：签订结构合同的 OPCO 名称、注册持有人和业务活动；说明相关 OPCO 的许可作用，并记录报告期结构合同交易的独立非执行董事审阅、盈余现金安排及审计师程序
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：OPCO, 结构合同交易, 牌照, 独立非执行董事审阅, 审计师程序

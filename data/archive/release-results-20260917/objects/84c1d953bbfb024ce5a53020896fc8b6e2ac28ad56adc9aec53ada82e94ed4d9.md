## P0047-P0057

### P0047-P0049
- 原文章节：Corporate Governance Report
- 内容：股东周年大会出席与议案通过情况、公司与股东沟通、股东召开特别股东大会及提名董事的程序、向董事会提出询问的渠道、章程修订说明和年末市值披露；后续定向阅读治理与股东事项时应打开
- 主题：公司治理
- 重要性：相关
- 关键词：股东大会, 股东权利, 董事提名, 章程修订

### P0050-P0050
- 原文章节：Financial Section 目录
- 内容：列出董事会报告、独立核数师报告、合并损益表、其他综合收益表、财务状况表、权益变动表、现金流量表、合并财务报表附注及五年摘要的页码；后续折算三表最值得从目录指向的年报第 64–70 页定向打开
- 主题：财务主表
- 重要性：核心
- 关键词：财务部分, 三表, 财务报表附注, 五年摘要

### P0051-P0052
- 原文章节：Directors’ Report
- 内容：说明集团主营活动及业务回顾所对应的管理层讨论与分析位置，指向年度业绩、股息、股本、储备和五年财务摘要，并列示董事任职、退任与委任事项；后续核对利润、权益及治理关联事项时应与所指财务报表和附注交叉打开
- 主题：业务与经营
- 重要性：相关
- 关键词：主营活动, 业务回顾, 股息, 股本, 储备, 董事变动

### P0053-P0053
- 原文章节：Directors’ Report
- 内容：董事轮值退任与重选、董事服务合约、竞争业务、关联方交易及董事和控股股东在交易安排合同中的权益披露；后续定向核对关联方与治理风险时应打开相关财务报表附注
- 主题：承诺风险关联方
- 重要性：相关
- 关键词：董事轮值, 服务合约, 关联方交易, 控股股东

### P0054-P0054
- 原文章节：Directors’ Report
- 内容：管理合约、员工与经销商及客户和供应商关系、员工薪酬政策、退休计划和税务提示；后续涉及人工成本、退休福利或税项时应定向打开对应财务报表附注
- 主题：收入成本费用
- 重要性：相关
- 关键词：经销商, 供应商, 员工薪酬, 退休计划, 税务

### P0055-P0055
- 原文章节：Directors’ Report
- 内容：董事责任保险与弥偿安排、董事及高级管理层薪酬、股份收购安排，以及董事和行政总裁的股份及债权证权益披露；后续核对薪酬、股东权益或治理风险时应打开所指附注
- 主题：公司治理
- 重要性：相关
- 关键词：董事弥偿, 董事薪酬, 股份收购, 董事权益

### P0056-P0057
- 原文章节：Directors’ Report
- 内容：持有公司 5% 或以上股份及相关股份权益人士的登记披露，按持有人、持有身份和权益类别组织；后续核对股权结构、控股关系及权益变动时应定向打开本页原表和相关权益附注
- 主题：股东权益
- 重要性：核心
- 关键词：主要股东, 持股权益, 控股关系, 股份权益

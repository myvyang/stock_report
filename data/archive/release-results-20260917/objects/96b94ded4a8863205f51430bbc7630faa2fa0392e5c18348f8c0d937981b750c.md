## P0155-P0163

### P0155-P0158
- 原文章节：VIII. Bonds（债券）
- 内容：可转换债券的偿债能力、信用评级、利息安排、转股价下调事项及转股稀释影响；后续应定向打开以核对债务融资、潜在股本变化和相关权益披露。
- 主题：现金投资融资, 股东权益, 承诺风险关联方
- 重要性：核心
- 关键词：可转换债券, 偿债能力, 信用评级, 转股价, 稀释影响

### P0159-P0159
- 原文章节：IX. Financial Report — Auditor’s Report
- 内容：审计报告开篇，包括审计对象、合并及公司财务报表范围、审计意见基础和关键审计事项的引入；后续应定向打开以确认三表及附注的权威审计入口。
- 主题：财务主表, 会计口径
- 重要性：核心
- 关键词：审计报告, 审计意见, 财务报表, 关键审计事项

### P0160-P0160
- 原文章节：IX. Financial Report — Auditor’s Report — Key Audit Matters
- 内容：应收账款坏账准备的关键审计事项，涉及信用风险分组、预期信用损失、历史回款与前瞻性信息等审计关注点；后续应定向打开应收账款、减值准备及相关会计政策附注。
- 主题：周转资金, 会计口径
- 重要性：核心
- 关键词：应收账款, 坏账准备, 预期信用损失, 信用风险, 回款

### P0161-P0162
- 原文章节：IX. Financial Report — Auditor’s Report — Key Audit Matters
- 内容：固定资产及无形资产减值的关键审计事项，涉及资产组、特许经营权、可收回金额、现金流预测及关键假设敏感性；后续应定向打开经营资产、减值测试和相关估计政策附注。
- 主题：经营资产, 会计口径
- 重要性：核心
- 关键词：固定资产, 无形资产, 特许经营权, 减值测试, 可收回金额, 敏感性分析

### P0163-P0163
- 原文章节：IX. Financial Report — Auditor’s Report
- 内容：其他信息、管理层及治理层对财务报表的责任，以及审计师对财务报表审计的责任说明；后续用于确认报告责任边界、持续经营及财务信息阅读口径，不替代具体报表和附注页面。
- 主题：公司治理, 会计口径
- 重要性：相关
- 关键词：其他信息, 管理层责任, 治理层责任, 持续经营, 审计责任

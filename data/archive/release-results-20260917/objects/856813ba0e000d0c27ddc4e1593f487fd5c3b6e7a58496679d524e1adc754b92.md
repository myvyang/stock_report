## P0047-P0055

### P0047-P0047
- 原文章节：Corporate Governance Report — Board Committees / Executive Committee
- 内容：说明董事会向多个委员会授权的治理框架，重点介绍执行委员会的组成、权限边界、审批流程及年度履职事项；后续阅读可用于定位经营决策、预算和融资审批的治理背景。
- 主题：公司治理
- 重要性：相关
- 关键词：董事会委员会, 执行委员会, 授权, 审批流程

### P0048-P0049
- 原文章节：Corporate Governance Report — Audit Committee
- 内容：介绍审计委员会对财务报告、年度及中期合并报表、外部审计、财务报告程序和会计政策的监督工作，并衔接审计服务与非审计服务披露；后续折算三表或核对附注时，应定向打开相关财务报告和审计附注原页。
- 主题：公司治理
- 重要性：核心
- 关键词：审计委员会, 财务报告, 外部审计, 会计政策

### P0050-P0051
- 原文章节：Corporate Governance Report — Nomination Policy / Board Diversity
- 内容：说明董事提名政策的候选人标准、提名程序和董事会最终决策责任，并延伸至董事会构成、继任安排和多元化政策的执行情况；适合用于核对董事会治理与后续公司治理披露的出处。
- 主题：公司治理
- 重要性：相关
- 关键词：提名政策, 董事任命, 董事会多元化, 继任

### P0052-P0052
- 原文章节：Corporate Governance Report — Nomination Committee / Remuneration Committee
- 内容：收束提名委员会年度工作，转入薪酬委员会的职责、授权范围及其对董事和高级管理层薪酬的审阅；薪酬细节指向年报财务报告中的相关附注，后续需要事实核对时应回到附注原页。
- 主题：公司治理
- 重要性：相关
- 关键词：提名委员会, 薪酬委员会, 高级管理层, 薪酬审阅

### P0053-P0053
- 原文章节：Corporate Governance Report — Remuneration Committee
- 内容：说明董事及高级管理层薪酬政策、委员会年度审阅事项，以及股份奖励安排的治理审批背景；这里用于定位薪酬、股份奖励和相关附注的权威分页，不作金额或奖励数量提取。
- 主题：公司治理
- 重要性：相关
- 关键词：薪酬政策, 股份奖励, 董事薪酬, 高级管理层

### P0054-P0054
- 原文章节：Corporate Governance Report — Remuneration Committee / Corporate Governance and Risk Control Committee
- 内容：完成股份奖励审批说明并转入企业管治及风险控制委员会，涵盖其监督范围、成员构成和会议履职记录；后续定向阅读可优先关注风险控制、内部控制和财务管理监督相关原文。
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：风险控制, 内部控制, 财务管理监督, 企业管治

### P0055-P0055
- 原文章节：Corporate Governance Report — Corporate Governance and Risk Control Committee / Company Secretary / Induction and Continuous Professional Development
- 内容：列出风险控制委员会年度审阅事项，并说明公司秘书职责、上市规则合规及董事入职与持续专业发展安排；本页属于治理、内控和合规导航，不对应三张主表的金额页。
- 主题：公司治理
- 重要性：相关
- 关键词：内部审计, 风险管理, 公司秘书, 上市规则合规

## P0202-P0213

### P0202-P0203
- 原文章节：综合财务报表附注 3 财务风险管理——市场风险
- 内容：外汇风险的货币资产及负债敞口、汇率敏感性分析，以及定期存款、现金及现金等价物和借款对应的利率风险；折算相关风险敏感性和融资成本时应定向打开
- 主题：现金投资融资, 承诺风险关联方
- 重要性：相关
- 关键词：外汇风险, 利率风险, 敏感性分析, 借款

### P0204-P0205
- 原文章节：综合财务报表附注 3 财务风险管理——信贷风险
- 内容：现金、受限制现金、应收款项及投资的信贷风险管理安排，以及贸易应收款项预期信贷亏损的分组、账龄和个别识别方法；折算应收款项质量和减值口径时应定向打开
- 主题：周转资金, 承诺风险关联方, 会计口径
- 重要性：核心
- 关键词：信贷风险, 贸易应收款项, 预期信贷亏损, 账龄

### P0206-P0207
- 原文章节：综合财务报表附注 3 财务风险管理——贸易应收款项减值
- 内容：按客户信贷特征及逾期区间展示贸易应收款项、亏损拨备和净额，并给出预期亏损率；折算应收账款周转和坏账拨备时应定向打开
- 主题：周转资金, 会计口径
- 重要性：核心
- 关键词：贸易应收款项, 亏损拨备, 逾期账龄, 预期亏损率

### P0208-P0210
- 原文章节：综合财务报表附注 3 财务风险管理——其他应收款项减值
- 内容：贸易应收款项核销与减值损失列报、其他应收款项的 12 个月或全期预期信贷亏损原则、受限制用途指定存款账户的风险安排，以及评估信贷风险显著增加所参考的前瞻性指标和阶段分类；折算其他应收款项减值时应定向打开
- 主题：周转资金, 会计口径, 承诺风险关联方
- 重要性：核心
- 关键词：其他应收款项, 指定存款账户, 信贷风险显著增加, 阶段分类

### P0211-P0211
- 原文章节：综合财务报表附注 3 财务风险管理——其他应收款项亏损拨备变动
- 内容：其他应收款项按阶段列示年初拨备、损益确认的变动、核销及年末拨备的对账；折算应收款项减值变动时应定向打开
- 主题：周转资金, 会计口径
- 重要性：相关
- 关键词：亏损拨备对账, 第一阶段, 第三阶段, 应收款项核销

### P0212-P0213
- 原文章节：综合财务报表附注 3 财务风险管理——按公允价值计量且其变动计入损益的金融资产、价格风险及流动性风险
- 内容：按公允价值计量且其变动计入损益的投资的信贷风险上限、投资组合价格风险管理和敏感性分析指引，并开始按合同到期日分析借款、贸易应付款项、其他应付款项及租赁负债的未折现现金流；折算金融资产、负债期限和流动性时应定向打开
- 主题：现金投资融资, 周转资金, 承诺风险关联方
- 重要性：核心
- 关键词：公允价值计量且其变动计入损益, 价格风险, 流动性风险, 合同到期日

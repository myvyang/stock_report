## P0095-P0103

### P0095-P0096
- 原文章节：环境、社会及管治报告附录 B——气候相关披露索引
- 内容：按 ESG Code 的治理、策略、风险管理、指标与目标条目，标示气候相关披露或不适用项目；后续如需核对气候披露口径，应定向打开 ESG 报告相应章节
- 主题：其他
- 重要性：普通
- 关键词：气候相关披露, ESG Code, 治理, 风险管理, 指标与目标

### P0097-P0097
- 原文章节：独立核数师报告——意见、意见基础及关键审计事项引言
- 内容：核数师报告确认审计对象为合并财务报表，并说明合并财务报表所在页段；随后引出关键审计事项。后续折算三表及附注应先定向打开合并财务报表与附注 P0104-P0186
- 主题：会计口径
- 重要性：核心
- 关键词：独立核数师报告, 合并财务报表, 关键审计事项, HKFRS Accounting Standards

### P0098-P0099
- 原文章节：独立核数师报告——关键审计事项：物业、厂房及设备与使用权资产减值评估
- 内容：说明该减值评估涉及可收回金额、现金产生单位、预算收入、毛利率、增长率及折现率等判断，并列示核数师对估值模型、预测现金流、假设及敏感性分析的核查方向；后续应优先打开附注 Note 19
- 主题：经营资产
- 重要性：核心
- 关键词：物业、厂房及设备, 使用权资产, 减值评估, 现金产生单位, 可收回金额, 敏感性分析

### P0100-P0100
- 原文章节：独立核数师报告——关键审计事项：存货估值
- 内容：说明存货可变现净值、过期及滞销识别和跌价准备判断，并列示核数师对库龄、盘点、后续售价及管理层判断回顾的核查方向；后续应优先打开附注 Note 22
- 主题：周转资金
- 重要性：核心
- 关键词：存货估值, 可变现净值, 过期存货, 滞销存货, 跌价准备

### P0101-P0101
- 原文章节：独立核数师报告——关键审计事项：贸易应收款项及按金和其他应收款项减值评估
- 内容：说明预期信贷亏损模型、拨备矩阵、历史违约率及前瞻性信息的判断，并列示核数师对账龄、收款时点、债务人信用质量及后续结算的核查方向；后续应优先打开附注 Note 6(b) 及 Note 23
- 主题：周转资金
- 重要性：核心
- 关键词：贸易应收款项, 按金及其他应收款项, 预期信贷亏损, 拨备矩阵, 账龄

### P0102-P0103
- 原文章节：独立核数师报告——其他信息、董事及管治责任、核数师责任
- 内容：界定年报其他信息与合并财务报表及核数师报告的范围，说明董事对财务报表编制、持续经营评估和管治监督的责任，并概述核数师对重大错报、内部控制、会计政策、估计、持续经营及整体列报的审计责任；三表折算仍应回到合并财务报表 P0104-P0186
- 主题：会计口径
- 重要性：相关
- 关键词：其他信息, 董事责任, 持续经营, 内部控制, 核数师责任

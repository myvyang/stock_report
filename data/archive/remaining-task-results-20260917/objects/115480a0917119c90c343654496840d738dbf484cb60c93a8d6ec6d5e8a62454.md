## P0028-P0040

### P0028-P0030
- 原文章节：项目审阅（Project Review）
- 内容：俄罗斯业务的制裁影响、单位现金成本与安全表现，随后介绍 Garinskoye 项目的资源定位、开发路径及其他勘探项目和配套业务；折算时应定向打开经营成果、成本费用及项目资产相关原文页。
- 主题：业务与经营
- 重要性：相关
- 关键词：制裁风险, 单位现金成本, 安全表现, Garinskoye, 勘探项目

### P0031-P0036
- 原文章节：矿产资源及矿石储量声明（Mineral Resources and Ore Reserves Statement）
- 内容：说明资源储量编制口径、勘探活动变化，并按 K&S、Garinskoye 与 Bolshoi Seym 分项目展开资源和储量；折算时应定向打开经营资产、长期资产减值/开发判断及相关承诺风险页面。
- 主题：经营资产
- 重要性：核心
- 关键词：矿产资源, 矿石储量, K&S, Garinskoye, Bolshoi Seym, JORC Code

### P0037-P0040

- 重要性：相关
- 关键词：ESG, 环境, 用水, 温室气体, 废弃物, 健康与安全, 披露原则

## P0053-P0060

### P0053-P0054
- 原文章节：Corporate Governance Report — Compliance with the CG Code、Securities Transactions by Directors and Supervisors、The Board: Responsibilities
- 内容：公司对企业管治守则及董事、监事证券交易守则的适用与遵守说明，并交代股东大会、董事会、高级管理层及监事会的职责分工，以及董事会委员会和日常管理授权安排；后续若需核对治理架构、监督职责或风险控制责任，应定向打开此处原页
- 主题：公司治理
- 重要性：相关
- 关键词：企业管治守则, 证券交易, 董事会职责, 高级管理层, 监事会, 董事会委员会

### P0055-P0055
- 原文章节：Corporate Governance Report — Board Composition
- 内容：董事会构成、独立非执行董事资格与比例、董事之间关系披露及董事会结构审查安排；后续核对治理结构和独立性背景时应定向打开此页原文
- 主题：公司治理
- 重要性：相关
- 关键词：董事会构成, 执行董事, 独立非执行董事, 独立性, 董事会结构

### P0056-P0056
- 原文章节：Corporate Governance Report — Independent Non-executive Directors、Independent Views and Input
- 内容：独立非执行董事的任职要求和独立性确认，以及董事会获取独立意见、专业建议和年度审查相关机制；后续核对治理监督机制时应定向打开此页原文
- 主题：公司治理
- 重要性：相关
- 关键词：独立非执行董事, 独立性确认, 独立意见, 专业建议, 年度审查

### P0057-P0057
- 原文章节：Corporate Governance Report — Board Diversity Policy
- 内容：董事会多元化政策的目标、考量维度、人才培养与性别多元化安排，以及提名委员会的监督职责；后续核对董事会组成政策和提名机制时应定向打开此页原文
- 主题：公司治理
- 重要性：普通
- 关键词：董事会多元化, 性别多元化, 教育背景, 行业经验, 提名委员会

### P0058-P0058
- 原文章节：Corporate Governance Report — Induction and Continuous Professional Development
- 内容：新任董事入职培训、持续专业发展、法规更新阅读及董事培训记录的披露方式；后续核对董事履职支持和专业发展安排时应定向打开此页原文
- 主题：公司治理
- 重要性：普通
- 关键词：董事入职培训, 持续专业发展, 法规更新, 董事培训记录

### P0059-P0060
- 原文章节：Corporate Governance Report — Appointment and Re-Election of Directors、Board Meetings and General Meetings
- 内容：董事任期、轮席退任、委任及罢免程序、服务合约与提名委员会职责，并说明董事会会议、股东大会的召开通知和议事安排；第 60 页继续披露董事利益回避、上市后会议情况、董事会会议及出席记录，后续核对治理程序、关联利益回避或董事会监督记录时应定向打开此两页原文
- 主题：公司治理
- 重要性：相关
- 关键词：董事任期, 轮席退任, 董事委任, 提名委员会, 董事会会议, 股东大会, 利益回避, 出席记录

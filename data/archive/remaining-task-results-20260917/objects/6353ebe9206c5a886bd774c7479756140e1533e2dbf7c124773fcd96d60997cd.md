## P0014-P0026

### P0014-P0015
- 原文章节：管理层讨论与分析——资本管理、资本开支、资金政策及主要风险
- 内容：说明资本结构与净现金/负债管理、借款和贸易应付款安排；列示资本开支投向及年度变动，并介绍资金与财务工具管理政策；随后引入商品价格、汇率和利率等主要风险。折算时应定向打开，以衔接借款、贸易应付款、资本性投入和金融风险相关附注。
- 主题：现金投资融资, 承诺风险关联方
- 重要性：核心
- 关键词：资本管理, 借款, 贸易应付款, 资本开支, 财务风险

### P0016-P0016
- 原文章节：管理层讨论与分析——主要风险、经营概览及业务回顾
- 内容：继续说明商品价格、外汇和利率风险，并转入年度经营概览和业务回顾，涉及铜钴采选冶炼业务、主要经营实体、产品产量与收入变化背景。折算时应定向打开，以定位经营表现、产销变化及收入成本解释的原文。
- 主题：业务与经营
- 重要性：核心
- 关键词：商品价格风险, 经营概览, 业务回顾, 产量, 铜钴

### P0017-P0022
- 原文章节：管理层讨论与分析——资源与储量：资源量
- 内容：说明资源量年度更新所采用的 JORC Code 假设及资源变动背景，并逐矿列示赞比亚和刚果（金）多个矿区的资源量分类、矿石与品位信息及开采/勘探说明。折算时应定向打开，以核对资源基础、矿区变化和后续产能解释；这些页面不是三张主表。
- 主题：业务与经营
- 重要性：相关
- 关键词：资源量, JORC Code, 矿区, 品位, 勘探

### P0023-P0026
- 原文章节：管理层讨论与分析——资源与储量：储量
- 内容：逐矿列示多个矿区的 JORC Code 证实储量和概略储量、矿石与品位信息，并附开采、勘探、截点品位调整及矿体重定义等说明。折算时应定向打开，以核对储量基础及资源储量变化对经营资产和生产规划的关联；这些页面不是三张主表。
- 主题：业务与经营
- 重要性：相关
- 关键词：储量, 证实储量, 概略储量, JORC Code, 矿体

## P0218-P0231

### P0218-P0223
- 原文章节：16. Social Responsibility Report
- 内容：ESG 报告索引，按环境、雇佣与劳工、供应链、客户、反腐及社区等主题列出披露事项和对应报告位置，并延伸至气候相关披露索引；属于非财务披露定位页，后续如需核对治理、风险或可持续经营信息可按报告位置定向打开。
- 主题：其他
- 重要性：普通
- 关键词：ESG 指标索引, 环境责任, 员工责任, 气候相关披露

### P0224-P0225
- 原文章节：16.9.3 About the Report
- 内容：社会责任报告的编制依据、覆盖范围、数据来源、报告期间及重要性、量化和一致性等编制原则；用于判断 ESG 信息的口径和出处，后续阅读相关披露时可回看。
- 主题：会计口径
- 重要性：相关
- 关键词：报告编制标准, 报告范围, 数据来源, 报告原则

### P0226-P0227
- 原文章节：17. Organizational Chart
- 内容：股东会、董事会、监事会、管理层、专门委员会、总部职能部门、分支机构及主要子公司的组织关系图；后续涉及治理结构、集团范围或主体归属时可定向核对。
- 主题：公司治理
- 重要性：相关
- 关键词：组织架构, 专门委员会, 分支机构, 子公司

### P0228-P0228
- 原文章节：18. Audit Report and Financial Statements
- 内容：审计报告及合并财务报表目录，定位合并损益表、综合收益表、财务状况表、权益变动表、现金流量表和财务报表附注的后续页码；是后续折算三表和定向打开附注的总导航。
- 主题：财务主表
- 重要性：核心
- 关键词：审计报告目录, 合并财务报表, 三表页码, 财务报表附注

### P0229-P0229
- 原文章节：Independent Auditor’s Report — Opinion
- 内容：独立审计师报告的意见段，确认审计对象覆盖合并财务报表及附注，并指向财务状况、经营成果和现金流相关原文页码；后续折算应以所指向的权威报表和附注分页为准。
- 主题：会计口径
- 重要性：核心
- 关键词：审计意见, 合并财务报表, IFRS, 香港公司条例

### P0230-P0230
- 原文章节：Independent Auditor’s Report — Basis for opinion and Key audit matters
- 内容：审计依据、独立性与审计证据说明，并引出关键审计事项及其处理背景；用于理解后续审计重点的口径，不替代财务报表或附注原文。
- 主题：会计口径
- 重要性：相关
- 关键词：审计依据, 审计独立性, 关键审计事项

### P0231-P0231
- 原文章节：Independent Auditor’s Report — Key audit matters (continued)
- 内容：围绕按摊余成本计量债务工具的预期信用损失，说明模型、参数、前瞻性信息和个别减值判断构成的审计关注点，并列出相应审计程序；后续定向阅读时应优先打开相关金融资产、减值及预期信用损失附注页面。
- 主题：经营资产
- 重要性：核心
- 关键词：预期信用损失, 摊余成本, 债务工具, 减值判断

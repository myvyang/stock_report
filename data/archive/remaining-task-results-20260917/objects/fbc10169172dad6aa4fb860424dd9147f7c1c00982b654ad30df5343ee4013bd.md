## P0096-P0104

### P0096-P0097
- 原文章节：Corporate Governance Report
- 内容：董事独立性、利益冲突回避、独立非执行董事沟通与履职安排；并说明董事及高管职责、董事长与总经理分工，以及报告期末部分治理职位出现空缺后的合规安排。
- 主题：公司治理
- 重要性：相关
- 关键词：董事独立性, 利益冲突, 董事长与总经理, 治理合规

### P0098-P0101
- 原文章节：Corporate Governance Report
- 内容：董事会会议的召集、资料提供、回避表决与年度审议事项；随后为董事及委员会会议出席、董事培训、证券交易守则遵守情况，以及董事会五个专门委员会的设置和职责概览。
- 主题：公司治理
- 重要性：相关
- 关键词：董事会会议, 出席记录, 董事培训, 董事会委员会

### P0102-P0102
- 原文章节：Corporate Governance Report
- 内容：战略委员会及薪酬与考核委员会的组成、职责和报告期内审议范围，覆盖中长期战略、重大投资融资建议、薪酬政策与绩效考核等治理接口。
- 主题：公司治理
- 重要性：相关
- 关键词：战略委员会, 薪酬与考核委员会, 投资融资建议, 薪酬政策

### P0103-P0104
- 原文章节：Corporate Governance Report
- 内容：提名委员会、审计委员会及关连交易委员会的组成、职责和会议审议范围；审计委员会部分涉及财务报告、内部控制、风险管理及外部审计安排，是后续核对三表披露背景和审计治理链条时本页块内最值得定向打开的页面。
- 主题：承诺风险关联方
- 重要性：相关
- 关键词：提名委员会, 审计委员会, 内部控制, 风险管理, 关连交易

## P0013-P0020

### P0013-P0014
- 原文章节：Management Discussion and Analysis
- 内容：毛利及毛利率、销售与市场推广、行政管理、研发、其他收入与其他收益，以及金融资产减值、融资成本、联营公司权益法损益、所得税和年度亏损的变动说明；折算时应定向打开以核对利润表项目及经营表现解释。
- 主题：收入成本费用
- 重要性：核心
- 关键词：毛利率, 销售与市场推广费用, 行政费用, 研发费用, 其他收益, 金融资产减值, 联营公司, 所得税, 年度亏损

### P0015-P0015
- 原文章节：Management Discussion and Analysis
- 内容：非国际财务报告准则指标的定义、适用限制及与国际财务报告准则口径的调节；折算时应定向打开以区分报表亏损与管理层使用的调整后经营指标。
- 主题：会计口径
- 重要性：相关
- 关键词：非IFRS指标, EBITDA, 调整后EBITDA, 股份支付, 上市费用, 指标调节

### P0016-P0016
- 原文章节：Management Discussion and Analysis
- 内容：流动性、资金来源及用途、经营投资融资现金流、现金及现金等价物、银行借款、未使用银行授信、财务契约和资金管理政策；折算时应定向打开以核对现金流量表、借款及融资信息。
- 主题：现金投资融资
- 重要性：核心
- 关键词：流动性, 经营活动现金流, 投资活动现金流, 融资活动现金流, 现金及现金等价物, 银行借款, 授信, 资金管理

### P0017-P0017
- 原文章节：Management Discussion and Analysis
- 内容：投资审批与监督机制、资本结构、资本性开支及其资金来源，以及存货余额的经营说明；折算时应定向打开以关注投资活动、固定资产及存货相关页面。
- 主题：经营资产
- 重要性：相关
- 关键词：投资政策, 投资审批, 资本结构, 资本性开支, 固定资产, 无形资产, 存货

### P0018-P0018
- 原文章节：Management Discussion and Analysis
- 内容：贸易应收款、贸易应付款、预付款及其他应收款和其他流动资产的构成与变动原因，随后转入未来经营展望；折算时应定向打开以核对营运资金项目及关联方往来线索。
- 主题：周转资金
- 重要性：核心
- 关键词：贸易应收款, 贸易应付款, 预付款, 其他应收款, 其他流动资产, 结算周期, 关联方往来, 展望

### P0019-P0019
- 原文章节：Management Discussion and Analysis
- 内容：员工规模与职能分布、招聘培训、社会保障、劳动关系、员工激励安排及员工福利费用说明；折算时应定向打开以关注人力成本和股份支付相关披露。
- 主题：业务与经营
- 重要性：相关
- 关键词：员工, 研发人员, 销售与市场推广人员, 福利, 培训, 社会保障, 股份期权计划, 股份支付

### P0020-P0020
- 原文章节：Management Discussion and Analysis
- 内容：资产抵押、或有负债、控股股东股份质押、杠杆水平、重大并购处置、重大投资计划及外汇风险；折算时应定向打开以核对借款担保、承诺风险、资本事项和汇率风险披露。
- 主题：承诺风险关联方
- 重要性：核心
- 关键词：资产抵押, 或有负债, 股份质押, 杠杆率, 重大收购处置, 重大投资, 外汇风险

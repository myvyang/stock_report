## P0133-P0141

### P0133-P0133
- 原文章节：董事会报告（Directors’ Report）—业务及财务回顾索引
- 内容：说明集团主要经营活动，并将财务报表、财务五年摘要、盈利及股息、业务表现、风险、展望及关联人士关系分别指向年报其他章节；适合据此定向打开后续经营分析、风险及三表原文
- 主题：业务与经营, 财务主表
- 重要性：相关
- 关键词：主要经营活动, 业务回顾, 风险管理, 财务报表, 股息

### P0134-P0134
- 原文章节：董事会报告（Directors’ Report）—资产
- 内容：涵盖固定资产及在建工程、借款和资本化融资成本，并指向财务报表相关附注；随后进入主要附属公司及股本发行上市沿革，折算资产、债务及股本时应定向打开对应附注
- 主题：经营资产, 现金投资融资, 股东权益
- 重要性：核心
- 关键词：固定资产, 在建工程, 借款, 资本化融资成本, 股本

### P0135-P0135
- 原文章节：董事会报告（Directors’ Report）—股本、公司治理及董事
- 内容：说明上市股份交易、股权挂钩协议及报告期股份数量结构无变化，并交叉指向公司治理报告、董事会会议、董事履历及薪酬页面；治理和权益核对可据此定向打开所引页面
- 主题：股东权益, 公司治理
- 重要性：相关
- 关键词：上市股份, 股权挂钩协议, 股份结构, 董事会会议, 董事薪酬

### P0136-P0136
- 原文章节：董事会报告（Directors’ Report）—监事及高级管理层
- 内容：披露监事变动及高级管理层续任，并将现任人员履历和薪酬分别指向治理及薪酬报告、财务报表附注；属于治理人员变动与薪酬的定向入口
- 主题：公司治理
- 重要性：相关
- 关键词：监事变动, 监事会, 高级管理层, 续任, 薪酬

### P0137-P0137
- 原文章节：董事会报告（Directors’ Report）—董事、监事及主要行政人员权益；须披露的股东权益
- 内容：先说明董事、监事及行政总裁的权益披露，再列示主要股东持有的股份及相关股份权益；如需核对控制权、股权结构或衍生权益，应定向打开本页原表及相关股东披露页
- 主题：股东权益, 公司治理
- 重要性：核心
- 关键词：董事权益, 主要股东, 长仓, A股, H股, 控股股东

### P0138-P0138
- 原文章节：董事会报告（Directors’ Report）—股东淡仓及重大合同
- 内容：列示主要股东淡仓及衍生工具说明，并说明其他人士权益、控股股东重大合同及董事监事关联交易的披露位置；关联交易和控制股东合同核对应定向打开本页及所引的 Connected Transactions 页面
- 主题：承诺风险关联方, 股东权益
- 重要性：核心
- 关键词：淡仓, 衍生工具, 控股股东, 重大合同, 关联交易

### P0139-P0139
- 原文章节：董事会报告（Directors’ Report）—竞争业务及控股股东不竞争承诺
- 内容：披露董事在竞争业务中的其他职务、控股股东避免横向竞争的承诺及报告期履行情况，并延续说明保留业务注入、优先购买及收购选择权安排；若评估关联方承诺、潜在竞争或未来资产安排，应定向打开本段原文
- 主题：承诺风险关联方, 公司治理
- 重要性：核心
- 关键词：竞争业务, 不竞争承诺, 保留业务, 优先购买权, 收购选择权

### P0140-P0140
- 原文章节：董事会报告（Directors’ Report）—优先认购权及可分派储备
- 内容：说明公司章程及中国相关法律下的优先认购安排，并交代母公司可供分派储备的项目性质；股东权益或股息分配相关核对可定向打开本页及财务报表权益附注
- 主题：股东权益
- 重要性：相关
- 关键词：优先认购权, 可分派储备, 留存收益, 股息分配

### P0141-P0141

- 主题：业务与经营, 收入成本费用, 承诺风险关联方
- 重要性：核心

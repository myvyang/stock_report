# EMPEROR CAPITAL 控股回本分析

报告期输入为 2025-12-31；公司实际年报期为截至 2025-09-30 止年度。金额均为 HKD 绝对金额。

## 1. 核心结论表

| 项目 | 金额/倍数 |
|---|---:|
| 粗筛市值 | 411,191,584 |
| 折前可剥离净现金 | 1,553,844,000 |
| 折后可剥离净现金 | 714,998,600 |
| 经营业务购买价 | -303,807,016 |
| 折前可分配现金利润 | 80,000,000 |
| 现金利润折扣 | 0.50 |
| 折后可持续可分配现金利润 | 40,000,000 |
| 市值/折后现金利润 | 10.28 年 |
| 折后控股回本年数 | -7.60 年 |
| 分类 | profit_cheap |
| 回本质量 | earnback_available |

这个结果不是买卖建议。它表示在严格排除客户资金和配套金融产品资产后，按保守折扣估算的可剥离净现金仍高于粗筛市值；但公司是金融服务业务，现金权属、监管资本和贷款减值会显著影响可动用程度，置信度为低。

## 2. 资金类资产原值、折扣和折后金额

| 项目 | 原值 | 折扣 | 折后金额 | 处理 |
|---|---:|---:|---:|---|
| 一般账户银行结余及现金 | 2,253,844,000 | 0.65 | 1,464,998,600 | 作为潜在可剥离资金池，但未披露控股公司/监管子公司拆分，因此大幅折扣 |
| 已抵押银行存款 | 100,000,000 | 0.00 | 0 | 抵押给银行作为融资额度担保 |
| 独立账户银行结余及现金 | 1,834,290,000 | 0.00 | 0 | 客户及其他机构资金，对应应付客户款 |
| 为已发行金融产品购入的资产 | 147,602,000 | 0.00 | 0 | 与同额已发行金融产品负债配套，不作为现金扣除项 |

粗筛把资金类资产看成约 24.01 亿。深度核对后，只有一般账户现金进入可剥离资金池；客户独立账户现金和配套金融产品资产均不能按普通企业现金扣除。

## 3. 必要经营现金、受限资金和融资负债扣除

| 项目 | 金额 | 说明 |
|---|---:|---|
| 银行借款 | 0 | 年报披露 2025-09-30 无银行借款 |
| 普通租赁负债 | 5,917,000 | 办公室等经营租赁，放在利润/现金质量中体现，不机械从现金中扣除 |
| 必要经营及监管流动性 | 700,000,000 | 金融服务、证券期货、财富/资管和融资业务需要保留流动性，年报未披露精确监管资本 |
| 税费、汇兑和分派摩擦准备 | 50,000,000 | 现金所在法律主体和可分派路径未拆清 |

折后可剥离净现金 = 1,464,998,600 - 700,000,000 - 50,000,000 = 714,998,600。

## 4. 可分配现金利润

2025 年报净利润为 146,936,000，但不能直接作为分母。主要调整是：

| 项目 | 金额 | 处理 |
|---|---:|---|
| 报告净利润 | 146,936,000 | 起点 |
| 银行存款利息收入 | -53,182,000 | 已把一般账户现金作为可剥离本金处理，避免本金和收益双算 |
| 非现金股份支付费用 | +16,166,000 | 可视作现金利润加回，但不完全释放为可分配现金 |
| 保守折前现金利润主口径 | 80,000,000 | 考虑 2021-2023 亏损、包销波动、减值和贷款业务资本占用后取保守值 |
| 现金利润折扣 | 0.50 | 金融业务、减值波动和经营现金流不可直接分配 |
| 折后现金利润 | 40,000,000 | 主排序口径 |

2025 经营现金流为 1,002,259,000，但包含贷款余额减少 585,092,000、独立账户现金增加 356,213,000、应付款增加 344,502,000 和收取利息 234,688,000，因此不能把该数字当作普通自由现金流。

## 5. 折后控股回本年数

经营业务购买价 = 411,191,584 - 714,998,600 = -303,807,016。

控股回本年数 = -303,807,016 / 40,000,000 = -7.60 年。

正式分类使用 `market_cap / discounted_sustainable_net_profit <= 15`，本次为 10.28 年，因此归入 `profit_cheap`。负的控股回本年数只表示折后净现金已经超过粗筛市值，不表示金融牌照、客户资金、贷款账簿和监管资本可以无摩擦变现。

## 6. 潜在问题

1. 公司是金融/类金融业务，客户资金、监管资金和业务流动性不能按普通企业现金处理。
2. 一般账户现金未拆控股公司、持牌子公司和最低监管资本，折扣与 7 亿必要流动性保留是估算。
3. 2021-2023 连续亏损，2024-2025 才恢复盈利，利润分母置信度低。
4. 2025 利润中配售/包销佣金和债券处置亏损规模都很大，业务利润波动性高。
5. 贷款及垫款仍有 877,393,000 账面值和 913,633,000 减值准备，融资业务信用风险会影响可持续现金利润。

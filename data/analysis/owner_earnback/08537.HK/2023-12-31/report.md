## 4. 可分配现金利润原值、折扣和折后现金利润

2024 年报表净利润 HK$1.592m，经营现金流 HK$10.691m。由于 HKFRS 16 下租赁本金 HK$7.990m 和已付利息 HK$1.249m 在融资现金流，若站在控股股东继续经营视角，需要从经营现金流中扣回：

| 项目 | 金额 |
|---|---:|
| 经营现金流 | 10,691,000 |
| 减：购置 PPE | -21,000 |
| 减：租赁负债付款 | -7,990,000 |
| 减：已付利息 | -1,249,000 |
| 折前可分配现金利润 | 1,431,000 |
| 现金利润折扣 | 0.35 |
| 折后可持续可分配现金利润 | 500,850 |

折扣原因：2023 年同口径为负，2024 年改善受高金价、回收黄金交易和 FVTPL 资产减少影响；存货年末仍有 HK$62.890m，且 2024 年存货继续增加 HK$4.058m。已作为可剥离资金折扣扣除的 FVTPL 股票本金，其利息、股息、公允价值和处置损益没有进入可持续现金利润。

## 5. 折后控股回本年数

```text
折后可剥离净资金 = 10,591,550 - 22,799,000 - 5,000,000 - 500,000 = -17,707,450
经营业务购买价 = 9,784,275 - (-17,707,450) = 27,491,725
折后控股回本年数 = 27,491,725 / 500,850 = 54.9 年
```

## 6. 潜在问题

核心问题不是账上没有现金，而是有息银行借款显著大于现金和上市股票。公司经营可以产生一定现金，但租赁店铺现金流出很重，扣除租赁本金、利息和维护性资本开支后，剩余可分配现金很薄。存货占总资产比例高，黄金价格高位有利于 2024 毛利率，但也提高了库存和价格波动对现金利润的影响。

粗筛仅有市值，币种为 CNY 8,982,865。本次按输入的 `signal_close_hkd` 与股数折回 HKD 市值 HK$9,784,275。粗筛未提供资金类资产、融资负债和净资金；深度核对后，年报口径资金类资产原值 HK$13.003m，但银行借款 HK$22.799m，折后可剥离净资金为负 HK$17.707m。

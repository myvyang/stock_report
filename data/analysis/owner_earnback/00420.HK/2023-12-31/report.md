# FOUNTAIN SET 控股回本分析

## 核心结论表

金额主口径为人民币绝对金额。年报原始披露为 `HK$'000`，本次用粗筛历史信号日 `2024-05-27` 的 `HKD/CNY=0.9039300084114075` 折算。

| 项目 | 金额 |
|---|---:|
| 粗筛历史市值 | 752,990,276 |
| 折前可剥离净资金 | 632,244,805 |
| 折后可剥离净资金 | 71,312,259 |
| 折后经营业务购买价 | 681,678,018 |
| 折前可分配现金利润 | 46,012,749 |
| 利润现金折扣 | 0.25 |
| 折后可持续可分配现金利润 | 11,503,187 |
| 折后控股回本年数 | 59.26 年 |

结论：粗筛看到的是“市值低于账上现金”的线索，但深度核对后不能把集团现金全扣。年报没有拆 parent/子公司现金和可上划路径，且业务在内地、斯里兰卡、印尼等地经营，需要保留较大经营现金。利润端 2023 年有 `HKD 259.011m` 土地征收补偿收益，2022 年亏损，因此分母要大幅折扣。折后主口径下，回本年数约 `59.26` 年。

## 资金类资产原值、折扣和折后金额

| 项目 | 原值 | 折扣 | 折后金额 | 处理 |
|---|---:|---:|---:|---|
| 银行结余及现金 | 908,564,458 | 0.55 | 499,710,452 | 可剥离但大幅折扣 |
| 短期银行存款 | 337,952,312 | 0.55 | 185,873,772 | 可剥离但大幅折扣 |
| 受限制银行存款 | 1,714,755 | 0.00 | 0 | 不可剥离 |

年报披露 2023 年末短期银行存款和银行结余及现金合计 `HKD 1,378.997m`，主要为 HKD、USD 和 RMB。受限制银行存款 `HKD 1.897m` 是存放在中国及斯里兰卡银行、作为票据应付款和银行透支抵押的保证金，不进入可剥离池。

现金和短存采用 `0.55` 折扣，原因是年报只给集团合并数，没有拆上市母公司、香港子公司、内地经营子公司、斯里兰卡或其他地区现金，也没有证明控股股东可快速上划或分红。公司不是金融企业，也没有 VIE 现金问题，但制造资产和营运资金主要在经营子公司内，所以不适合按 0.95-1.00 扣现金。

## 必要经营现金、受限资金和融资负债扣除

| 扣除项 | 金额 | 说明 |
|---|---:|---|
| 银行借款 | 180,385,561 | 年报附注 30：银行贷款及进口贷款合计 `HKD 199.557m`，100% 扣除。 |
| 必要经营现金 | 406,768,504 | 按制造业持续经营保守估计，约 `HKD 450m`。 |
| 税费、汇兑、分红摩擦准备 | 27,117,900 | 现金所在地和上划路径不清，留 `HKD 30m` 摩擦准备。 |

必要经营现金的估计依据是：2023 年收入 `HKD 4.440bn`、销售成本 `HKD 4.118bn`、存货 `HKD 783.908m`、应收及票据 `HKD 808.091m`，且收入下滑时仍需要维持生产、采购、账期和外币周转。租赁负债 `HKD 125.473m` 主要对应工厂、宿舍、办公室、仓库和设备租赁，是继续经营所需租赁，未机械从现金中 100% 扣除，而是在利润现金质量中体现。

## 可分配现金利润原值、折扣和折后现金利润

| 项目 | 数值 |
|---|---:|
| 2021 归母净利润 | HKD 241.334m |
| 2022 归母净利润 | HKD -115.532m |
| 2023 归母净利润 | HKD 50.903m |
| 三年归母中位数 | HKD 50.903m |
| 折前可分配现金利润 | CNY 46.013m |
| 利润现金折扣 | 0.25 |
| 折后可持续可分配现金利润 | CNY 11.503m |

2023 年经营现金流为 `HKD 293.758m`，购买物业、机器及设备为 `HKD 87.871m`，表面自由现金流为正。但经营现金流主要来自营运资金释放：存货减少、应收减少、应付增加。更关键的是，2023 年税前利润包含 `HKD 259.011m` 土地征收补偿收益；若剔除该非经常项目，主营盈利基础弱得多。2022 年归母亏损也说明分母不能用最好年份美化。

因此主口径用三年归母中位数作为折前分母，再按 `0.25` 折成折后可持续可分配现金利润。

## 折后控股回本年数

计算：

```text
折后可剥离净资金 = CNY 71.312m
经营业务购买价 = CNY 752.990m - CNY 71.312m = CNY 681.678m
折后可持续可分配现金利润 = CNY 11.503m
控股回本年数 = 681.678 / 11.503 = 59.26 年
```

## 潜在问题

- 现金权属和可上划路径没有披露，不能把合并现金直接当母公司可分配现金。
- 主要经营资产和现金可能沉在内地及海外经营子公司，需要保留经营现金。
- 2023 年利润被土地征收补偿收益显著抬高，不能视作持续主业利润。
- 2022 年亏损，2023 年收入继续下滑，纺织制造存在周期和订单波动。
- 经营现金流在 2023 年受营运资金释放支持，不能直接等同于长期可分配现金。

## 粗筛数字和深度核对差异

粗筛阶段只有历史市值，未给出资金类资产、融资负债、净资金或现金调整倍数。深度核对后的主要差异是：年报账面现金和短存约 `HKD 1.379bn`，高于历史市值对应的港元金额，但控股视角下必须先按可剥离性折扣，再扣银行借款、必要经营现金和摩擦准备。最终折后可剥离净资金只有约 `CNY 71.31m`，并没有形成低回本年数。

本报告不构成买卖建议，不给目标价。

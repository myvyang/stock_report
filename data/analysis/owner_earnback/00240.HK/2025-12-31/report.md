# BUILD KING HOLD 控股回本分析

## 1. 核心结论表

| 指标 | 折后主口径 |
|---|---:|
| 市值 | HK$1.763bn |
| 折前可剥离净资金 | HK$1.860bn |
| 折后可剥离净资金 | HK$0.988bn |
| 经营业务购买价 | HK$0.775bn |
| 折前可分配现金利润 | HK$430.0m |
| 利润现金折扣 | 0.55 |
| 折后可持续可分配现金利润 | HK$236.5m |
| 控股回本年数 | 3.3 年 |
| 市值/折后现金利润 | 7.5 年 |
| 分类 | profit_cheap |
| 回本质量 | earnback_available |

结论：按折后主口径，市值/折后可分配现金利润约 7.5 年，进入 `profit_cheap`。扣除折后可剥离净资金后，经营业务购买价约 HK$775m，控股回本约 3.3 年。这个结论的主要约束是项目制建筑公司的营运资金波动和现金权属未拆。

## 3. 必要经营现金、受限资金和融资负债扣除

| 扣除项 | 金额 | 说明 |
|---|---:|---|
| 银行贷款 | HK$88.3m | 有息借款100%扣除 |
| 必要经营现金 | HK$900.0m | 约为2025收入6.5%；合同资产、应付工程款、合同负债规模很大，项目现金流波动高 |
| 税费、汇兑和分红摩擦准备 | HK$50.0m | 现金未拆母公司/子公司/内地子公司，保留上翻摩擦 |
| 质押存款 | HK$90.3m | 已在资金池中按0折处理，不再重复扣除 |

折后可剥离净资金约 HK$988.0m。

## 4. 可分配现金利润原值、现金利润折扣和折后现金利润

三年归母净利润为 HK$473.5m、HK$434.0m、HK$452.7m；三年经营自由现金流约 HK$194.9m、HK$420.7m、HK$759.5m。2025年经营现金流很强，但主要来自合同资产下降和合同负债增加；2023年则相反，合同资产增加压低现金流。

主口径折前可分配现金利润取 HK$430m，已剔除已扣资金本金对应的银行存款利息、FVTPL利息/股息和公允价值变动，利润现金折扣取 0.55，折后可持续可分配现金利润为 HK$236.5m。

## 5. 折后控股回本年数

经营业务购买价 = 市值 HK$1763.5m - 折后可剥离净资金 HK$988.0m = HK$775.4m。

控股回本年数 = HK$775.4m / HK$236.5m = 3.3 年。

## 6. 潜在问题

现金多，但不能全扣。建筑工程业务有 HK$3.536bn 合同资产、HK$3.867bn 应付及应计款、HK$1.377bn 合同负债，项目认证、保留金和客户付款节奏会显著影响现金。2025现金流是好年份，但不代表全部可分配。

FVTPL中最大块是Road King相关深圳旧改项目的非流动权益/贷款，回收依赖项目销售和物业市场，不适合按短期可剥离现金处理。

## 7. 粗筛数字和深度核对差异

粗筛把资金类资产 HK$2.660bn、融资负债 HK$120.8m、净资金 HK$2.540bn直接推到现金调整PE。深度核对后，质押存款打0、FVTPL大幅折价、保留必要经营现金和摩擦准备，折后可剥离净资金降至 HK$988.0m。粗筛现金覆盖市值超过1倍；深度口径仍有净现金，但覆盖率降至约 0.56 倍。

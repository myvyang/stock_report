# 山东出版控股回本分析

## 1. 核心结论表

| 项目 | 金额/倍数 |
|---|---:|
| 当前总市值 | 151.93 亿元 |
| 折前可剥离净资金 | 103.86 亿元 |
| 折后可剥离净资金 | 82.17 亿元 |
| 折后经营业务购买价 | 69.76 亿元 |
| 折前可分配现金利润 | 12.00 亿元 |
| 现金利润折扣 | 0.85 |
| 折后可持续可分配现金利润 | 10.20 亿元 |

| 回本质量 | earnback_available |

结论：山东出版按本次折后口径勉强进入 `profit_cheap`。它不是因为清算现金覆盖市值，而是因为折后现金利润仍能在约 14.90 年覆盖总市值；扣掉折后可剥离净资金后，经营业务购买价约 69.76 亿元，控股回本约 6.84 年。这个分类接近 15 年边界，敏感项是定期存款折扣、必要经营现金和利润折扣。

## 3. 扣除项

| 扣除项 | 金额 | 处理 |
|---|---:|---|
| 短期借款 | 0.10 亿元 | 银行押汇形成，有息债务 100% 扣除 |
| 必要经营现金 | 17.50 亿元 | 按约两个月经营现金流出估算 |
| 税费/分红/执行摩擦准备 | 3.00 亿元 | 境内现金、存款和理财用于还债、分红或回购的执行安全垫 |
| 经营租赁负债 | 1.42 亿元 | 继续经营所需，不机械从净现金扣除，在利润质量中体现 |

由此得到折后可剥离净资金约 82.17 亿元。

## 4. 可分配现金利润

2025 年归母净利润 11.74 亿元，扣非归母净利润 10.74 亿元；2024 年扣非归母净利润 14.18 亿元，2023 年扣非归母净利润 15.74 亿元。近三年经营现金流分别为 24.22 亿元、8.62 亿元、16.01 亿元，中位数约 16.01 亿元。

本次不用简单报表净利润作为分母。以近三年扣非归母净利润中位数为起点，剔除已扣本金对应的代表性利息收入和金融资产收益，并考虑 2024-2025 年资本开支约 2.35-2.98 亿元、经营租赁和营运资金波动，给出折前可分配现金利润 12.00 亿元，现金利润折扣 0.85，折后可持续可分配现金利润 10.20 亿元。

## 5. 折后控股回本年数

```text
经营业务购买价 = 151.93亿元 - 82.17亿元 = 69.76亿元
控股回本年数 = 69.76亿元 / 10.20亿元 = 6.84年
总市值 / 折后现金利润 = 151.93亿元 / 10.20亿元 = 14.90年
```

按规则，正式分类先看 `market_cap / discounted_sustainable_net_profit <= 15`，所以本次为 `profit_cheap`，但安全垫很薄。

## 6. 潜在问题

- 定期存款及一年内到期重分类未逐笔拆清，若期限更长或提前支取受限更强，0.75 折扣可能仍偏高。
- 2025 年收入下降 4.60%，第四季度归母净利润为负，不能用最好年份利润美化分母。
- 利润中有利息收入、结构性存款收益和金融资产收益；本次已在分母中扣除代表性资金收益，避免本金和收益双算。
- 经营现金流季节性和营运资金波动明显，2024 年经营现金流仅 8.62 亿元。
- 出版发行有政策、教材教辅和渠道属性，控股后现金提出路径需要董事会、股东会和国资/监管现实约束配合。

## 7. 粗筛差异

粗筛资金类资产为 84.67 亿元，主要对应货币资金和交易性金融资产；深度核对把其他非流动资产中的定期存款及应计利息纳入资金池，原始资金池升至 124.46 亿元。粗筛融资负债 1.52 亿元包含租赁负债；深度口径只把短期押汇借款 0.10 亿元作为净现金扣除项，经营租赁改由利润折扣体现。粗筛现金调整回本约 5.86 年，深度折后主口径约 6.84 年。

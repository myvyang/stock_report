# Photronics（NASDAQ: PLAB）FY2025 经营质量与控股回本研究

> 口径说明：输入报告期为 2025-12-31，但 Photronics 的法定财年截至 2025-10-31，因此本报告使用 FY2025 10-K。除市值外，美元金额按 1 美元约 7.12 元人民币统一换算；市值和 PE 沿用输入中 2026-08-03 的 Yahoo Finance yfinance 快照。本文不构成买卖建议。

## 先说结论

Photronics 是一家普通制造企业，而不是需要特殊资产负债模型的金融或特许经营公司。它把芯片和显示面板客户的设计数据制成高精度光掩模，客户用掩模把电路图形曝光转印到晶圆或显示基板。生意的价值在认证、精度、良率、快速交付和贴近客户的工厂网络；代价是固定成本高、设备更新昂贵，利润不能简单等同于可分配现金。[FY2025 10-K](https://www.sec.gov/Archives/edgar/data/810136/000114036125045801/ef20057458_10k.htm)

FY2025 营收 8.493 亿美元，同比下降 2.0%；毛利率由 36.4%降至 35.3%，营业利润率由 25.6%降至 24.5%。归母净利润仍从 1.307 亿美元增至 1.364 亿美元，主要受较低税费影响，而不是主营利润增长。经营现金流 2.478 亿美元，但资本开支 1.881 亿美元后，自由现金流只有 0.597 亿美元；更重要的是，公司预计 FY2026 资本开支约 3.30 亿美元。利润质量并不差，但当前扩产阶段的可分配性明显弱于会计利润。

按本文的保守控股口径，折后可剥离净现金约 21.96 亿元，约占输入市值 18.2%；折后可持续归母现金利润约 5.28 亿元。由 120.52 亿元市值扣除折后现金，经营业务购买价约 98.56 亿元，对应约 18.7 年回本；若不扣现金，市值约为现金利润的 22.8 倍。这个结果依赖合资现金归属、资本开支正常化和折价假设，不能理解成确定回收期。

## 公司怎么赚钱

光掩模是带有微观电路图案的石英或玻璃板，相当于晶圆和显示面板光刻环节的“母版”。Photronics 向集成电路（IC）和显示器（FPD）的设计商、制造商销售按客户规格定制的掩模。FY2025 IC 收入 6.151 亿美元，占 72.4%；FPD 收入 2.342 亿美元，占 27.6%。高端 IC 与高端 FPD 合计收入 4.344 亿美元，约占 51.2%。[10-K Note 10](https://www.sec.gov/Archives/edgar/data/810136/000114036125045801/ef20057458_10k.htm)

客户在新产品设计、改版或工艺迁移时产生掩模需求，所以掩模销售更相关于“新设计活动”，不完全跟随芯片或面板终端出货量。订单到交付通常只有一天至三周，部分 IC 产品可延长到两三个月，因此积压订单不是可靠的远期指标。通过客户认证后，公司依靠质量、交期、价格、技术能力和本地服务争取订单份额。高良率洁净生产、检测修复设备和靠近客户的工厂构成经营壁垒，也构成持续资本开支。[10-K Business](https://www.sec.gov/Archives/edgar/data/810136/000114036125045801/ef20057458_10k.htm)

公司有 11 座工厂，分布于台湾、中国、韩国、美国和欧洲，自称全球领先的独立光掩模制造商之一。行业参与者有限，但竞争并不轻：除 DNP、Hoya、LG Innotek、SK-Electronics 等专业厂商外，芯片和面板制造商也拥有自制掩模能力。客户普遍采用多供应商策略，技术升级所需设备投资与价格压力长期并存。

## 经营数据说明什么

FY2025 核心数据如下，人民币仅为统一展示换算：

| 项目 | FY2025 | 经营含义 |
|---|---:|---|
| 营收 | 60.47 亿元 | 8.493 亿美元，同比下降 2.0% |
| 毛利 / 毛利率 | 21.35 亿元 / 35.3% | 毛利率同比下降 1.1 个百分点 |
| 营业利润 / 利润率 | 14.82 亿元 / 24.5% | 主营盈利同比下降，固定成本模式仍保持较高利润率 |
| 归母净利润 / 净利率 | 9.71 亿元 / 16.1% | 归母利润同比增长，但增量并非来自营业利润 |
| 经营现金流 | 17.64 亿元 | 高于归母净利润，但这是含少数股东的合并现金流 |
| 资本开支 | 13.40 亿元 | 明显高于折旧摊销，处于重投入阶段 |
| 经营自由现金流 | 4.25 亿元 | 仅为合并口径，归母后更低 |

毛利到归母利润之间，主要扣除了销售管理费用 0.756 亿美元、研发费用 0.158 亿美元、少数股东利润 0.538 亿美元；利息及其他收入提供了 0.220 亿美元正贡献。FY2025 合并净利润 1.902 亿美元，其中约 28.3%归少数股东，说明看合并利润和现金流时必须做归母调整。[10-K financial statements](https://www.sec.gov/Archives/edgar/data/810136/000114036125045801/ef20057458_10k.htm)

三年平均合并经营自由现金流约 1.203 亿美元，但 FY2025 单年降至 0.597 亿美元。公司下一财年 3.30 亿美元资本开支计划甚至高于 FY2025 经营现金流，表明近期现金储备首先是扩产和技术投资的缓冲，而不是天然可全部分配给普通股东。

## 资产负债对应什么

期末总资产约 128.48 亿元、总负债 14.75 亿元，总权益 113.73 亿元；其中归母权益 83.56 亿元、少数股东权益 30.17 亿元。资产负债率低、期末有息债务仅 2.4 万美元，偿债压力很小。

资产的核心是两块：一是现金与短期投资合计 5.882 亿美元（约 41.90 亿元）；二是厂房设备净额 8.544 亿美元（约 60.84 亿元）。后者对应 11 座工厂、洁净室以及写入、检测和修复设备，是业务必须占用的生产能力，不能从市值中扣走。应收、存货和其他流动资产合计约 21.43 亿元，代表客户账期、基板耗材、在制订单和日常预付款，并没有显示异常膨胀。

负债端主要是应付账款和应计负债合计约 11.81 亿元，对应材料、设备、薪酬税费等结算；其他长期负债约 2.95 亿元，包括税务、退休福利、合同负债和租赁义务。它们虽然大多不是融资债务，仍然约束现金，不能忽略。

最容易误判的是资金归属。4.923 亿美元现金中，4.461 亿美元在境外子公司，3.538 亿美元在台湾和中国合资公司；公司还明确提示跨境调拨可能产生预提税和美国州税。期末少数股东权益占总权益 26.5%，因此不能把合并现金全额当作 PLAB 普通股东的钱。[10-K Liquidity](https://www.sec.gov/Archives/edgar/data/810136/000114036125045801/ef20057458_10k.htm)

## 利润能否变成可分配现金

公司过去三年的经营现金流分别为 3.022、2.614 和 2.478 亿美元，现金生成总体稳定；但资本开支分别为 1.313、1.309 和 1.881 亿美元，FY2025 的扩张显著抬高资产占用。同期归母净利润在 1.255—1.364 亿美元之间，盈利波动不大，但“归母利润稳定”与“近期可以分配同等现金”是两回事。

FY2025 没有普通股现金股息，现金股东回报主要是回购 5.0 百万股、支出 0.974 亿美元。没有已宣布股息的证据时，下一年度现金股息按 0 预测，预测股息率为 0；回购可能提升每股价值，但它不是现金股息，也不保证持续。尤其在 FY2026 大额资本开支面前，历史回购不能机械外推。

## 控股回本拆解

现金端先将 3.538 亿美元合资现金按约 50.01%归母，非合资现金和短期投资纳入基数，扣除微量有息债务，得到归母资金约 4.113 亿美元；再整体折价 25%，反映跨境税费、合资治理、营运缓冲和下一年度资本开支，折后净现金约 21.96 亿元。

利润端以 FY2023—FY2025 三年平均“经营现金流减资本开支”1.203 亿美元为起点，用同期归母净利润占合并净利润 68.43%的比例归母化，再折减 10%反映周期和资本开支不确定性，得到约 0.741 亿美元、即 5.28 亿元折后现金利润。

| 控股口径 | 数值 |
|---|---:|
| 输入市值 | 120.52 亿元 |
| 折后可剥离净现金 | 21.96 亿元 |
| 折后净现金 / 市值 | 18.2% |
| 经营业务购买价 | 98.56 亿元 |
| 折后可持续现金利润 | 5.28 亿元 |
| 经营业务回本年 | 18.7 年 |
| 市值 / 现金利润 | 22.8 倍 |

这个估算比直接用输入 PE 11.18 倍严格得多：PE 的分母接近会计归母利润，而控股现金利润扣除了实际资本开支、少数股东份额和安全折价。反过来，如果 FY2026 的 3.30 亿美元主要是有高回报的增长投资，三年平均资本开支又可能低估成熟期现金能力；若它实质上是维持技术竞争力所必需，本文现金利润仍可能偏乐观。真正决定回本判断的，是未来数年资本开支回落幅度及新增产能回报，而不是账面现金的绝对值。

## 可能推翻判断的事实

- 若 FY2026 大额设备投资不能带来高端产品收入和利润增长，折旧、利用率和现金消耗会同时恶化。
- 若合资公司现金难以上划、需持续留作本地扩产，21.96 亿元折后净现金仍可能偏高。
- 单一关联方大客户 FY2025 贡献 1.373 亿美元收入，约占 16.2%；客户变动会显著影响收入和产能利用率。
- 82%收入来自美国以外业务，汇率、出口限制、关税和地域经营约束会影响利润与现金可转移性。
- 新设计活动若放缓，即便终端半导体销量增长，光掩模需求也不一定同步增长。

## 结论

这是一家从疫情停摆中恢复、但尚未证明稳定盈利能力的香港出境游公司，而不是一家已经成熟的“旅游科技”成长企业。FY24/25（截至2025年3月31日）旅行团、FIT及旅游附属服务贡献3.711亿港元收入，占公司含终止业务收入约94.9%；核心旅游业务的分部利润为901万元，但扣除中央费用、持续经营的其他附属业务亏损和零售终止前亏损后，公司EBIT仅319万元。经营拐点是真实的，利润缓冲却很薄。

稳定期不采用恢复期增长外推，而以3.75亿港元收入、18.5%毛利率、6,400万元期间经营费用为基准，得到约449万元稳定经营收益。按八倍固定标尺，经营资产基准价值约3,590万元；加上3,970万元多余现金和536万元非经营资产、扣除227万元融资负债后，普通股基准价值约7,870万元，即每股约0.116港元。这个结果对“经营必需现金”和正常费用极敏感。任务未提供截至研究日的市场价格、汇率观察或信息截止时间，因此不能计算当前折溢价，也不应把每股基准价值解读成买卖建议。

## 生意怎样运转

客户主要是香港出境旅客。订单从旅行团产品设计开始，公司组合机票、酒店、地接、交通、餐饮和景点，再通过分店、网上平台、数字营销和媒体广告获客。客户通常在出发前支付订金，直至旅行服务交付前都记作合同负债；2025年3月末旅行团合同负债为4,539万元。这让公司可以用客户预付款支持供应商付款，形成负的经营性营运资金，是其现金效率最重要的结构性来源。[《Annual Report 2024/2025》，PDF P5-P7、P121-P122](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

收入确认揭示了两种不同经济角色。旅行团由公司整合并承担履约责任，以总额确认收入；单卖机票、酒店和旅游附属产品时，公司更多充当代理，只把佣金或差价以净额确认。FY24/25旅行团收入3.671亿元、毛利6,210万元，FIT净收入24万元、旅游附属服务净收入383万元。单卖机酒竞争激烈，几乎不赚钱；真正承载品牌和毛利的是整包旅行团。[《Annual Report 2024/2025》，PDF P6-P7、P90](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

供给端不存在单一不可替代供应商：最大供应商占采购19.3%，前五大合计31.9%，客户前五大合计不足收入30%。但公司对日本线路及日元成本高度暴露。客户以港元付款，酒店、交通、餐饮和门票有相当部分用日元结算；公司按已报名人数采购未来四周、旺季八周所需日元，并可用远期合约管理短期风险。这个机制能限制已成团订单的汇率波动，却不能消除产品重新定价前的日元升值压力。[《Annual Report 2024/2025》，PDF P9-P10、P48-P52](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

难复制之处不是技术专利，而是超过45年的品牌信誉、路线设计经验、供应商网络和事故处理能力。它们能够提高旅客对高客单价旅行团的信任，却没有形成宽阔的价格护城河：FY24/25旅行团收入大致持平，毛利仍因通胀、油价及地接成本上升而下降5.2%。品牌能带来订单，但尚未证明能把成本上升稳定转嫁给客户。[《Annual Report 2024/2025》，PDF P5、P7、P47-P48](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

## 利润和现金

三年收入从1.586亿元增至4.076亿元，再回落至3.912亿元，主要反映疫情后旅游恢复以及业务组合退出，而不是稳定的同店增长。毛利率由18.2%升至20.0%后降至17.7%。FY24/25费用下降使EBIT由亏损821万元转为盈利319万元，其中董事酬金下降、餐饮出售后的人员和使用权资产折旧减少贡献明显；这说明本年改善既有经营恢复，也有费用基数收缩。[《Annual Report 2023/2024》，PDF P62-P68、P97-P105](https://www1.hkexnews.hk/listedco/listconews/gem/2024/0628/2024062803505.pdf)；[《Annual Report 2024/2025》，PDF P6-P8、P59-P64、P97-P98](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

经营现金流连续三年为正，分别为1,389万元、830万元和821万元，但不能直接视为股东可取现金。把租赁本金纳入资本开支，并扣除经营性营运资金需求后，FCFF约为218万元、负328万元和161万元。2023年的正现金流很大部分来自旅游恢复后客户订金增加；2025年营运资金反而占用约237万元。由此看，当前业务仍是“薄利润、预收款融资、门店和租赁需要持续更新”的模式，而非轻资产高利润平台。

FY22/23和FY23/24估计分别有约980万元及405万元现金资本开支流向当时尚未稳定赚钱的零售和餐饮。餐饮于2024年3月出售，零售于2025年3月停止，最新年度开拓性资本开支已降至约24万元。退出减少了未来现金消耗，但也说明此前多元化投入没有建立出可持续的第二利润来源。[《Annual Report 2022/2023》，PDF P13、P103、P118-P121](https://www1.hkexnews.hk/listedco/listconews/gem/2023/0629/2023062900472.pdf)；[《Annual Report 2024/2025》，PDF P6-P10、P92-P93、P98](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

## 资本占用与资产效率

2025年3月末经营性营运资金约为负2,444万元，核心是4,676万元合同负债对存货、应收和预付款的融资。扣除经营租赁负债后，经营性长期资产净额仅约192万元；再加入估计的3,180万元经营必需现金，投入资本约928万元。程序计算ROIC为28.8%，但这个比率不适合作为护城河证据：分母很小，而且经营必需现金是中等置信度估计，轻微改变现金边界就会显著改变ROIC。更可靠的判断是，公司能利用预收款降低资本占用，但利润率仍不足以证明定价权。

经营必需现金按一个月现金经营成本估计。这个数还得到公司外汇操作的支持：日元采购通常覆盖未来四周、旺季八周。若实际淡旺季最低现金余额明显高于3,180万元，则多余现金和普通股价值都应等额下降；这是本估值最重要的可推翻条件之一。

## 股东资金能否到达

期末现金为7,150万元，模型保留3,180万元经营必需现金，余下3,970万元作为多余现金。年末没有资本承诺或重大或然负债，但公司连续两年不派息，过去又通过配售融资：2022年两次配售，2023年6月再发行1.125亿股，净筹约1,760万元用于租赁装修、采购、员工、租金和行政开支。现金账面上属于上市公司，不等于已经建立稳定返还机制。[《Annual Report 2024/2025》，PDF P9、P11、P49、P123-P130](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

非经营资产按账面值计入：合营投资176万元、加密货币67万元，以及向关联方提供的293万元免息、无抵押、按要求偿还款。最后一项的法律到期条件有利于公司，但没有利息和担保，经济可达性弱于银行现金；若期后不能及时回收，应直接折价。另有向非控股股东所欠227万元属非交易性质并可按要求偿还，作为融资负债扣除。少数股东账面权益为负，且主要零售主体已终止，本基准没有赋予少数股东正经济价值。[《Annual Report 2024/2025》，PDF P61-P62、P115、P123-P125、P132-P133](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

截至2025年3月31日，董事及行政总裁没有申报公司股份权益；唯一披露的主要股东WWPKG Investment持有14.69%。这意味着公开披露中没有一名绝对控股股东，但资金分配仍由董事会决定，而公司股息政策没有预设派息率。[《Annual Report 2024/2025》，PDF P23、P51-P52](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

## 当前阶段、风险与反证

公司处于“核心旅游恢复、非核心业务收缩、尚待证明稳定利润”的阶段。最关键的下行链条是：日本需求或日元环境变化，地接成本上升而售价调整滞后，旅行团毛利率下降；中央费用的刚性随后把本已很薄的EBIT压回亏损。自然灾害、战争、传染病和香港外游警示还可能同时打击订单与客户订金，使负营运资金优势逆转。[《Annual Report 2024/2025》，PDF P47-P48](https://www1.hkexnews.hk/listedco/listconews/gem/2025/0730/2025073000467.pdf)

支持当前基准的后续事实应包括：持续经营旅游收入稳定在3.4亿至4.1亿元、毛利率不低于约18%、期间费用不高于约6,400万元、零售清算不再消耗现金、关联方应收按要求收回。相反，以下任一事实都足以推翻或下调基准：毛利率连续低于17%；正常费用重新升至6,800万元以上；维持性资本开支连续高于700万元；客户订金下降导致营运资金持续占用；经营必需现金高于3,180万元；合营投资、加密货币或关联方应收不能按账面变现。

上行反证也很明确：如果旅行团在不增加门店和大量营运资金的情况下恢复20%以上毛利率，持续经营EBIT能够明显高于本模型的538万元，且现金连续两年留存为FCFF，则当前八倍标尺会低估品牌和供应网络的价值。在这些证据出现前，不给“旅游科技”名称、合营投资或尚未启动的新业务额外成长价值。

## 口径与证据说明

任务把报告期标为2025-12-31，但三份法定年报实际分别覆盖截至2023、2024和2025年3月31日止年度；正文和事实底稿均采用真实财年期间，表头年度是任务要求的年度标签。2025年公司总量把已终止零售业务纳入，以闭合集团当期收入、费用和现金流；稳定期则剔除该业务。

租赁统一采用经营口径：现金资本开支包含租赁本金，经营性长期资产净额扣除租赁负债，普通股价值桥不再重复扣租赁负债。主营与开拓性资本开支、经营必需现金、分业务中央费用和现金流贡献均为研究估计，详细依据、置信度和可推翻条件保存在结构化底稿。合营企业损益不进入EBIT，对应投资列作非经营资产；商誉全部从投入资本剔除。三年虽有三份年报支持，但旅游恢复、餐饮出售和零售终止使业务边界变化明显，因此稳定状态只能给予中等置信度。

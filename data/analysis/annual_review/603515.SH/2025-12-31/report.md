# 欧普照明 603515.SH ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务数据使用者。

## 结论

核对年度：2025-12-31，上一年度：2024-12-31。单位均为人民币元。

ROIC = NOPAT / 平均投入资本 = 853,773,861.32 / 3,071,943,455.40 = 27.7926%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 327,889,588.30 / 3,071,943,455.40 = 10.6737%。

期初、期末和平均投入资本均大于 0，`formula_status` 为 `ok`。

## 公式与数字

NOPAT：

```text
初算 EBIT = 利润总额 + 利息费用
          = 1,083,251,582.76 + 1,187,029.81
          = 1,084,438,612.57

经营 EBIT = 初算 EBIT - 已扣除金融资产对应收益 - 超额现金对应利息收入
          = 1,084,438,612.57 - 81,916,662.59 - 92,628.69
          = 1,002,429,321.29

有效税率 = 所得税费用 / 利润总额
        = 160,641,013.67 / 1,083,251,582.76
        = 14.8295%

NOPAT = 1,002,429,321.29 * (1 - 14.8295%)
      = 853,773,861.32
```

投入资本：

```text
经营必要现金 = 年度经营活动现金流出合计 * 25%

2025 经营必要现金 = 6,832,558,179.48 * 25% = 1,708,139,544.87
2025 可扣除超额现金 = max(1,715,158,948.15 - 1,708,139,544.87, 0) = 7,019,403.28
2025 投入资本 = 7,014,557,222.24 + 27,670,999.59 - 3,642,802,853.79 - 7,019,403.28
              = 3,392,405,964.76

2024 经营必要现金 = 6,968,717,296.19 * 25% = 1,742,179,324.05
2024 可扣除超额现金 = max(1,576,091,564.61 - 1,742,179,324.05, 0) = 0
2024 投入资本 = 6,724,059,001.28 + 104,656,990.78 - 4,077,235,046.02
              = 2,751,480,946.04

平均投入资本 = (3,392,405,964.76 + 2,751,480,946.04) / 2
             = 3,071,943,455.40
```

现金辅助口径：

```text
经营自由现金流 = 经营活动现金流净额 - 购建长期资产支付的现金
              = 689,874,479.51 - 361,984,891.21
              = 327,889,588.30
```

## 核对判断

交易性金融资产：年报附注显示 2025 年末交易性金融资产 3,642,802,853.79 元均为投资理财；年报“委托理财情况”列示未到期银行理财 3,021,233,500.00 元、券商理财 610,000,000.00 元。该部分作为可剥离投资从投入资本扣除。2024 年末交易性金融资产中，只有投资理财 4,077,235,046.02 元被扣除，权益工具投资和其他项目未扣除。

金融资产收益配对：与扣除的交易性金融资产对应，经营 EBIT 扣除投资收益 79,290,238.82 元和交易性金融资产公允价值变动收益 2,626,423.77 元，合计 81,916,662.59 元。其他非流动金融资产为权益工具投资，本次未从投入资本扣除，因此其 -878,741.62 元公允价值变动没有从经营 EBIT 中剔除。

现金：没有把货币资金全部扣除。按统一口径以现金及现金等价物计算超额现金，2025 年末只扣除 7,019,403.28 元，2024 年末不扣除。保函保证金和其他受限货币资金已在年报现金等价物附注中列为不属于现金及现金等价物。

利息收入：财务费用附注列示利息收入 22,633,394.20 元。由于只扣除超额现金，按超额现金 / 现金及现金等价物比例剔除利息收入 92,628.69 元，没有机械剔除全部利息收入。

有息融资负债：只纳入短期借款、一年内到期的非流动负债和租赁负债。没有用总负债替代融资负债。

## 粗筛差异

粗筛 ROIC 为 69.2466%，本次核对 ROIC 为 27.7926%，差异为 -41.4540 个百分点。

主要原因是粗筛把货币资金大额纳入可扣除资金资产，导致平均投入资本偏低。本次按标准口径只扣除超过 25% 年度经营现金流出的现金及现金等价物，并保留经营必要现金。

第二个差异是投资资产范围收窄：长期股权投资、其他非流动金融资产、投资性房地产没有明确属于可剥离银行理财、结构性存款、基金或债券，因此保留在投入资本内。

## 口径限制

现金利息收入没有年报披露的逐笔资金池对应关系，使用统一比例公式估算剔除额。该项金额很小，不改变结论。

期初交易性金融资产中“权益工具投资”和“其他”没有作为可剥离理财扣除；若后续有更细明细证明其也属于可剥离现金管理资产，可另行复核。

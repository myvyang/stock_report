# 隆鑫通用 603766.SH ROIC 核对报告

目标读者：复核 `stock_analysis` ROIC 排名口径的研究/数据人员。

## 核对结论

报告期：2025-12-31。单位：人民币元。

公式：

```text
ROIC = NOPAT / 平均投入资本
NOPAT = 调整后经营 EBIT * (1 - 有效税率)
平均投入资本 = (期末投入资本 + 期初投入资本) / 2
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
现金 ROIC = 经营自由现金流 / 平均投入资本
```

核心结果：

| 项目 | 金额/比例 |
|---|---:|
| 初算 EBIT = 利润总额 + 利息费用 | 1,962,232,028.02 |
| 调整后经营 EBIT | 1,888,655,915.10 |
| 有效税率 | 15.3202% |
| NOPAT | 1,599,310,789.55 |
| 期末投入资本 | 6,537,952,653.61 |
| 期初投入资本 | 5,997,393,615.63 |
| 平均投入资本 | 6,267,673,134.62 |
| verified_roic | 25.5168% |
| 经营自由现金流 | 2,546,132,988.50 |
| verified_cash_roic | 40.6233% |

`formula_status = warning`，原因是现金利息收入无法由年报精确拆分到经营必要现金、超额现金、受限定期存款和保证金，本次按标准比例法估计剔除；其余关键项目已用完整年报附注核对。

## NOPAT 调整

有效税率：

```text
295,309,881.87 / 1,927,589,946.81 = 15.3202%
```

经营 EBIT 调整：

```text
初算 EBIT 1,962,232,028.02
- 超额现金对应利息收入 66,488,282.09
- 可剥离金融投资对应收益 7,087,830.83
= 调整后经营 EBIT 1,888,655,915.10
```

超额现金对应利息收入使用比例法：

```text
177,827,818.99 * 3,488,994,308.53 / 9,331,572,856.10 = 66,488,282.09
```

可剥离金融投资对应收益包括债权投资利息收入 6,905,072.31、交易性金融资产持有收益 129,305.48、金融资产公允价值收益 53,453.04。未扣除投资性房地产，因此其公允价值变动损益不调整。处置长期股权投资损失不与已扣除资产对应，未作为经营 EBIT 剔除项。

## 粗筛差异

粗筛 ROIC 为 94.7676%，核对后为 25.5168%，下降 69.2508 个百分点。主要差异：

1. 粗筛近似扣除了大部分货币资金；本次按现金及现金等价物减经营必要现金计算超额现金，且不把受限保证金、诉讼冻结资金和非现金等价物的应收定期存款利息计入超额现金。
2. 年报披露 2025 年末其他流动负债中有票据融资款 1,000,000,000.00 元，本次纳入有息融资负债。
3. 国债逆回购 950,195,505.13 元列报在其他流动资产，本次作为短期可剥离理财扣除，同时剔除对应收益。
4. 现金利息收入按配对原则仅剔除超额现金对应部分，没有机械剔除全部利息收入。

## 口径限制

现金利息收入不能从年报中精确拆分到超额现金和经营必要现金，本次使用标准比例法，置信度为 `medium`。受限银行定期存款没有计入超额现金；由于其与票据融资、保证金安排有关系，且契约要求受限资金不计入可扣除超额现金，本次没有额外把受限定期存款作为可剥离投资扣除。

# 中际联合 2025 ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务分析人员。

## 公式和结果

核对口径：

```text
ROIC = NOPAT / 平均投入资本
NOPAT = 经营 EBIT * (1 - 有效税率)
经营 EBIT = 利润总额 + 利息费用 - 可剥离金融资产收益 - 按比例剔除现金利息收入
投入资本 = 所有者权益 + 有息融资负债 - 可扣除超额现金 - 可剥离金融投资
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
```

## 分子调整

已从投入资本扣除的金融资产，对应收益同步从 EBIT 中剔除：

```text
交易性金融资产投资收益 30,802,362.27
+ 债权投资利息收入 816,356.18
+ 理财产品及基金公允价值变动收益 -7,153,023.54
= 24,465,694.91
```

现金只扣除超额现金，因此没有剔除全部利息收入。按平均可扣除超额现金 / 平均现金及现金等价物计算：

```text
34,450,283.51 * 668,204,811.05 / 972,223,065.35 = 23,677,534.51
```

所得税费用为 75,281,448.92 元，利润总额为 605,324,781.67 元，有效税率为 12.4365%。年报所得税调节表显示研发费用加计扣除、其他影响、非应税收入等降低税负，因此沿用实际有效税率。

## 与粗筛差异

粗筛 ROIC 为 64.9347%，本次核对为 44.2463%，下降 20.6884 个百分点。主要差异：

- 粗筛把货币资金/交易性金融资产粗略作为资金资产扣除；本次保留经营必要现金，仅扣现金及现金等价物中的超额部分。
- 本次新增扣除可转让大额存单，并同步剔除债权投资利息收入。
- 本次按现金配对原则剔除超额现金对应的利息收入，未剔除全部利息收入。

现金 ROIC 从粗筛 31.0864% 调整为 23.0085%，主要因平均投入资本从粗筛 817,873,974.40 元上调至 1,105,014,009.53 元。

## 口径限制

`formula_status` 为 `ok`，`confidence` 为 `medium`。完整年报 PDF 已由证据包逐页解析并核对关键附注。

主要限制是现金利息收入无法逐笔拆分经营必要现金和超额现金收益，本次按契约的比例法估算剔除金额；该处理避免了机械剔除全部利息收入。

本报告不构成买卖建议，也不包含目标价。

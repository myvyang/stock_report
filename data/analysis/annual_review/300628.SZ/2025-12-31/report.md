# 亿联网络 300628.SZ ROIC 核对报告

目标读者：复核 ROIC 排名口径的财务分析人员。

## 公式和结果

核对年度：2025-12-31，上一年度：2024-12-31。单位：人民币元。

ROIC = NOPAT / 平均投入资本 = 2,466,736,573.63 / 3,779,378,488.11 = 65.27%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 1,779,426,120.39 / 3,779,378,488.11 = 47.08%。

NOPAT = 经营 EBIT * (1 - 有效税率)。经营 EBIT = 利润总额 2,838,296,951.98 + 利息费用 381,700.05 - 理财产品收益 154,847,444.30 - 交易性金融资产公允价值变动收益 (-8,358,406.87) = 2,692,189,614.60。有效税率 = 所得税费用 237,688,562.32 / 利润总额 2,838,296,951.98 = 8.3743%。NOPAT = 2,466,736,573.63。

期末投入资本 = 所有者权益 9,327,725,234.70 + 融资债务 8,807,355.11 - 可剥离金融投资 5,029,326,612.07 - 可扣除超额现金 0 = 4,307,205,977.74。

期初投入资本 = 所有者权益 8,947,671,403.62 + 融资债务 10,851,816.90 - 可剥离金融投资 5,706,972,222.05 - 可扣除超额现金 0 = 3,251,550,998.47。

平均投入资本 = 3,779,378,488.11。两期投入资本均大于 0，ROIC 具备排序含义。

经营自由现金流 = 经营活动现金流量净额 1,832,386,223.28 - 经营性资本开支 52,960,102.89 = 1,779,426,120.39。

## 核对判断

完整年报来源为巨潮资讯 2025 年年度报告，URL：https://static.cninfo.com.cn/finalpage/2026-04-22/1225142083.PDF。证据包已逐页解析 PDF，关键项目已用年报主表和附注核对。

交易性金融资产附注列示期末 4,929,220,166.53 元，包括银行理财产品、证券资管产品、可转让定期存单；其他非流动金融资产 100,106,445.54 元为预期持有超过一年的证券资管产品。两项合计 5,029,326,612.07 元，本次作为可剥离金融投资扣除。期初可剥离金融投资为交易性金融资产 5,706,972,222.05 元。

与分母配对，理财产品收益 154,847,444.30 元从经营 EBIT 扣除。交易性金融资产公允价值变动收益为 -8,358,406.87 元，也按配对原则扣除；因该项目为损失，扣除后经营 EBIT 增加。长期股权投资 179,472,544.63 元和投资性房地产 169,132,892.49 元未认定为可剥离金融投资，因此权益法收益 742,635.24 元未机械剔除。

经营必要现金采用统一基准：2025 年经营活动现金流出 3,995,813,487.59 元，25% 为 998,953,371.90 元，高于期末现金及现金等价物 834,944,541.01 元；2024 年经营活动现金流出 3,364,463,085.12 元，25% 为 841,115,771.28 元，高于期初现金及现金等价物 450,671,867.65 元。因此两期可扣除超额现金均为 0。由于没有扣除超额现金，本次不剔除现金利息收入。

融资债务只包括租赁负债：期末一年内到期租赁负债 4,725,814.41 元、租赁负债 4,081,540.70 元，合计 8,807,355.11 元；期初合计 10,851,816.90 元。短期借款、长期借款、应付债券为空。

有效税率 8.3743% 低于法定税率，所得税附注显示主要受研发费用加计扣除、子公司适用不同税率等因素影响；本次使用实际有效税率。

## 粗筛差异

粗筛 ROIC 为 85.69%，本次核对后为 65.27%，差异 -20.42 个百分点。主要原因是标准口径下不扣除货币资金中的经营必要现金，且年报显示交易性金融资产 4,929,220,166.53 元与其他非流动金融资产 100,106,445.54 元合计为 5,029,326,612.07 元，不能在合计口径之外重复扣除其他非流动金融资产。

粗筛现金 ROIC 为 58.63%，本次核对后为 47.08%，同样来自平均投入资本分母上调。

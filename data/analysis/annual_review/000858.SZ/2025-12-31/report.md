# 五 粮 液（000858.SZ）2025 年 ROIC 核对报告

## 公式和结果

核对年度：2025-12-31；上一年度：2024-12-31；单位：元。

ROIC = NOPAT / 平均投入资本 = 7,550,082,162.99 / 22,410,067,877.72 = 33.6906%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 27,738,852,602.77 / 22,410,067,877.72 = 123.7785%。

NOPAT = 经营 EBIT × (1 - 有效税率) = 9,885,287,524.92 × (1 - 23.62303935%) = 7,550,082,162.99。

初算 EBIT = 利润总额 + 利息费用 = 12,198,853,038.23 + 28,573,949.37 = 12,227,426,987.60。

经营 EBIT = 初算 EBIT - 配对剔除的超额现金利息收入 = 12,227,426,987.60 - 2,342,139,462.68 = 9,885,287,524.92。

## 投入资本

期末经营必要现金 = 经营活动现金流出小计 64,708,104,332.23 × 25% = 16,177,026,083.06。

期末可扣除超额现金 = 现金及现金等价物 124,114,690,633.67 - 经营必要现金 16,177,026,083.06 = 107,937,664,550.61。

期末投入资本 = 所有者权益 122,180,683,645.14 + 有息融资负债 408,530,653.28 - 可扣除超额现金 107,937,664,550.61 = 14,651,549,747.81。

期初经营必要现金 = 经营活动现金流出小计 70,969,875,612.37 × 25% = 17,742,468,903.09。

期初可扣除超额现金 = 现金及现金等价物 124,771,274,417.68 - 经营必要现金 17,742,468,903.09 = 107,028,805,514.59。

期初投入资本 = 所有者权益 136,394,793,732.69 + 有息融资负债 802,597,789.53 - 可扣除超额现金 107,028,805,514.59 = 30,168,586,007.63。

平均投入资本 = (14,651,549,747.81 + 30,168,586,007.63) / 2 = 22,410,067,877.72。

## 核对判断

完整年报来源为巨潮资讯《2025年年度报告》，PDF URL：https://static.cninfo.com.cn/finalpage/2026-04-30/1225273091.PDF。证据包记录该 PDF 共 141 页，并已抽取关键报表和附注。

货币资金不能全额扣除。年报第117页列示期末现金及现金等价物为 124,114,690,633.67，同时不属于现金及现金等价物的货币资金包括银行承兑汇票保证金等 334,485,788.13 和计提的定期存款利息 2,565,266,595.06。本次只以现金及现金等价物为现金资金池，并保留 25% 年度经营现金流出作为经营必要现金。

现金利息收入按配对原则处理。利润表第56页列示利息收入 2,693,164,763.58；因分母只扣除超额现金，不剔除全部利息收入，而是按期末可扣除超额现金 / 期末现金及现金等价物 = 86.9656706% 计算，应剔除现金利息收入 2,342,139,462.68。

长期股权投资未扣除。合并资产负债表第51页列示长期股权投资 2,233,514,411.45；利润表第56页列示投资收益 111,568,486.77，且均为对联营企业和合营企业的投资收益。该项未被认定为可剥离银行理财、结构性存款、基金或债券资产，因此不从投入资本扣除，相关收益也不从经营 EBIT 剔除。

交易性金融资产为空；其他非流动金融资产为 1,200,000.00，金额不重大且证据包附注片段未说明其为可剥离金融投资，本次不调整。未见短期借款、长期借款、应付债券或短期融资款；有息融资负债仅包括一年内到期的租赁负债和租赁负债。

## 粗筛差异

粗筛 ROIC 为 347.7640%，本次核对 ROIC 为 33.6906%，差异主要来自分母修正。粗筛期末投入资本为 -4,426,428,718，本次期末投入资本为 14,651,549,747.81；原因是粗筛口径接近把货币资金和投资资产大额扣除，而本次按统一规则保留经营必要现金，并且未把长期股权投资默认为可剥离资金资产。

粗筛现金 ROIC 为 1032.9414%，本次核对现金 ROIC 为 123.7785%，同样主要由平均投入资本从 2,685,423,660 修正为 22,410,067,877.72 导致。

## 口径限制

现金利息收入未逐笔披露其对应经营必要现金或超额现金，本次按契约采用标准比例法。长期股权投资和其他非流动金融资产未取得可剥离非经营投资的充分证据，未作扣除。以上限制不影响核心三表和年报来源的可追溯性。

# 炬华科技 300360.SZ 2025 ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务数据使用者。

## 核对结果

金额单位：元。

ROIC = NOPAT / 平均投入资本 = 456,819,464.34 / 1,209,086,442.34 = 37.7822%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 437,322,774.11 / 1,209,086,442.34 = 36.1697%。

公式状态：warning。两期投入资本均大于 0，可排序；但其他非流动金融资产缺少逐项标的明细，利息收入也需要按资金池比例分摊，置信度为 medium。

## NOPAT 计算

初算 EBIT = 利润总额 + 利息费用 = 669,318,222.30 + 113,207.38 = 669,431,429.68。

有效税率 = 所得税费用 / 利润总额 = 90,575,605.83 / 669,318,222.30 = 13.5325%。年报所得税调节显示公司受研发加计扣除、子公司税率差异等影响；本次使用实际有效税率。

从初算 EBIT 中配对剔除的非经营资金资产收益：

| 项目 | 调整金额 |
|---|---:|
| 其他非流动金融资产投资收益和公允价值变动净额 | 70,461,744.28 |
| 理财产品收益 | 628,630.14 |
| 按资金池比例剔除的现金利息收入 | 70,027,461.12 |
| 合计 | 141,117,835.54 |

经营 EBIT = 669,431,429.68 - 141,117,835.54 = 528,313,594.14。

NOPAT = 528,313,594.14 × (1 - 13.5325%) = 456,819,464.34。

## 现金 ROIC

经营自由现金流 = 经营活动现金流量净额 - 经营性资本开支 = 507,093,704.45 - 69,770,930.34 = 437,322,774.11。

现金 ROIC = 437,322,774.11 / 1,209,086,442.34 = 36.1697%。

## 与粗筛差异

粗筛 ROIC 为 64.7664%，本次核对为 37.7822%，下降 26.9842 个百分点。

主要差异来自分母和分子配对修正：

- 粗筛基本扣除了全部货币资金和金融资产，本次保留经营必要现金，并排除保证金和衍生金融资产。
- 本次把 3 个月以上定期存款、明确理财产品、其他非流动金融资产作为可剥离资金资产扣除，同时剔除对应投资收益、公允价值变动和按比例分摊的现金利息收入。
- 其他非流动金融资产在年报中没有逐项标的明细，因此虽然收益可配对识别，仍不能给 high 置信度。

## 口径限制

年报披露的其他非流动金融资产为以公允价值计量且其变动计入当期损益的金融资产，并披露了公允价值层级，但未披露逐项投资标的。本次按可剥离金融资产处理，相关收益也从经营 EBIT 剔除；若后续取得逐项标的，需复核是否存在战略性投资。

利息收入 78,440,062.36 元无法精确拆分至活期存款、现金等价物和 3 个月以上定期存款。本次按平均已扣现金类资产 / 平均可生息现金资金池 = 89.2751% 剔除 70,027,461.12 元，未机械剔除全部利息收入。

本报告不构成买卖建议，不包含目标价。

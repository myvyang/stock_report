# 浦东建设 2025 ROIC 核对报告

目标读者：复核 `stock_analysis` ROIC 排序结果的财务数据使用者。

## 结论与公式

核对年度：2025-12-31；上一年度：2024-12-31；单位：元，人民币。

ROIC = NOPAT / 平均投入资本 = 330,662,709.32 / 5,278,879,161.53 = 6.26%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 1,011,866,231.07 / 5,278,879,161.53 = 19.17%。

投入资本两期均大于 0，公式状态为 `ok`，但其他非流动金融资产是否可剥离需要人工持续关注，置信度设为 `medium`。

## NOPAT 核对

初算 EBIT = 利润总额 489,873,078.95 + 利息费用 61,819,936.54 = 551,693,015.49。

分母扣除了交易性金融资产，因此分子同步扣除其可识别收益：

- 交易性金融资产持有期间投资收益：22,656,902.25
- 处置交易性金融资产投资收益：17,515,331.55
- 交易性金融资产公允价值变动收益：63,564,380.02

经营 EBIT = 551,693,015.49 - 103,736,613.82 = 447,956,401.67。

有效税率 = 所得税费用 128,269,228.88 / 利润总额 489,873,078.95 = 26.1842%。税率略高于 25%，年报调节表显示有以前期间所得税调整、不同税率子公司和非应税收入影响；本次使用实际有效税率。

NOPAT = 447,956,401.67 × (1 - 26.1842%) = 330,662,709.32。

## 投入资本核对

2025期末投入资本 = 所有者权益 8,044,811,567.37 + 融资债务 1,850,064,932.66 - 可扣除现金 0 - 可剥离交易性金融资产 5,183,104,954.88 = 4,711,771,545.15。

2024期末投入资本 = 所有者权益 7,856,034,597.70 + 融资债务 2,850,984,796.69 - 可扣除现金 0 - 可剥离交易性金融资产 4,861,032,616.47 = 5,845,986,777.92。

平均投入资本 = 5,278,879,161.53。

现金按统一基准重新核对：2025经营现金流出小计14,390,040,703.66，经营必要现金为3,597,510,175.92；现金及现金等价物3,239,190,169.23，未超过必要现金。2024同样未超过必要现金。因此两期均不扣除超额现金，利息收入也不从经营 EBIT 扣除。

交易性金融资产附注披露期末含货币基金、结构性存款、定制理财，属于可剥离资金资产，本次全额扣除。其他非流动金融资产为权益工具投资，主要为科创、张江燧锋、浦东海望等股权投资基金；结合公司披露的园区招商和科创基金矩阵背景，本次按战略投资保留在投入资本中，其公允价值变动收益不剔除。

## 现金 ROIC

经营自由现金流 = 经营活动现金流净额 1,273,389,537.87 - 购建固定资产、无形资产和其他长期资产支付的现金 261,523,306.80 = 1,011,866,231.07。

现金 ROIC = 1,011,866,231.07 / 5,278,879,161.53 = 19.17%。

## 粗筛差异

粗筛 ROIC 为58.02%，核对后为6.26%，差异为 -51.76 个百分点。主要原因是粗筛把货币资金、交易性金融资产和其他非流动金融资产作为资金资产整体扣除，导致平均投入资本仅约7.02亿元；核对后按25%经营现金流出基准不扣除现金，并保留战略股权基金，平均投入资本提高到约52.79亿元。

粗筛现金 ROIC 为144.17%，核对后为19.17%，差异同样来自分母修正。

计算：

```text
初算 EBIT = 利润总额 + 利息费用
          = 2,546,785,866.01 + 36,090,923.52
          = 2,582,876,789.53

经营 EBIT = 初算 EBIT - 理财产品收益 - 交易性金融资产公允价值变动收益
          = 2,582,876,789.53 - 14,187,663.76 - 19,402,482.64
          = 2,549,286,643.13

税率 = 所得税费用 / 利润总额
     = 411,966,879.46 / 2,546,785,866.01
     = 16.17595279%

NOPAT = 经营 EBIT * (1 - 税率)
      = 2,136,915,239.14

ROIC = NOPAT / 平均投入资本
     = 2,136,915,239.14 / 3,728,769,875.09
     = 0.573088528
```

## 核对判断

交易性金融资产附注明确为理财产品，期末 2,189,881,690.40 元、期初 799,195,629.55 元，作为可剥离金融投资从投入资本扣除。分子同步剔除与该资产配对的理财产品收益 14,187,663.76 元和交易性金融资产公允价值变动收益 19,402,482.64 元。

现金及现金等价物低于按经营活动现金流出 25% 计算的经营必要现金，因此标准口径不扣除超额现金。财务费用附注中的利息收入 76,816,422.92 元没有对应被扣除的现金资金池，本次不从 EBIT 剔除。

年报列示可转让大额存单投资收益 23,535,848.18 元，但证据包没有展开其对应资产归属；原始资产负债表 JSON 可见其他流动资产金额较大，但没有年报附注明细可直接配对。按配对原则，本次不剔除该收益，并将 `formula_status` 设为 `warning`。

其他权益工具投资 216,315,000.00 元不默认视为可剥离非经营投资，未从投入资本扣除；其相关处置收益也未机械剔除。

## 粗筛差异

粗筛 ROIC 为 1.880571757，本次核对后为 0.573088528，差异 -1.307483229。主要原因是粗筛把货币资金纳入资金资产扣除；本次按统一标准用现金及现金等价物与 25% 经营现金流出测算，现金没有超额部分，因此不扣除现金。

粗筛现金 ROIC 为 1.525295514，本次核对后为 0.4709456801，差异同样主要来自平均投入资本口径扩大。

## 口径限制

本次已使用完整年报证据包和本地三表抽取字段核对关键主表、现金、理财产品、有息债务和损益调整。限制是：大额存单投资收益未能在现有证据中可靠配对到分母扣除资产，其他流动资产明细未展开，因此结果为中等置信度、公式状态 `warning`。

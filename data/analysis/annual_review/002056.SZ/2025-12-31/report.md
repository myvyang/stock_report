# 横店东磁 002056.SZ ROIC 核对报告

目标读者：复核本次 ROIC 排名口径的研究员。

## 公式与结果

- 核对年度：2025-12-31；上期：2024-12-31
- ROIC = NOPAT / 平均投入资本 = 2,159,328,044.36 / 12,615,308,043.84 = 17.12%
- NOPAT = 经营 EBIT × (1 - 有效税率) = 2,621,403,701.96 × (1 - 17.6270%) = 2,159,328,044.36
- 平均投入资本 = (13,692,152,178.92 + 11,538,463,908.76) / 2 = 12,615,308,043.84
- 经营自由现金流 = 经营活动现金流净额 - 经营性资本开支 = 3,258,111,466.45 - 1,428,766,763.70 = 1,829,344,702.75
- 现金 ROIC = 1,829,344,702.75 / 12,615,308,043.84 = 14.50%

## 关键口径

投入资本采用“所有者权益 + 有息融资负债 - 可扣除非经营资金资产”。2025 年末所有者权益为 11,058,444,408.25 元；有息融资负债为 2,633,707,770.67 元，包括短期借款、长期借款、一年内到期租赁负债、租赁负债，以及其他应付款中有明确利率说明的关联方资金拆借。2024 年末对应有息融资负债为 1,268,568,397.61 元。

标准必要现金按年度经营活动现金流出合计的 25% 计算。2025 年必要现金为 5,172,731,896.84 元，高于现金及现金等价物 3,314,909,637.30 元；2024 年必要现金为 4,538,487,479.11 元，高于现金及现金等价物 4,242,422,625.39 元。因此两期可扣除超额现金均为 0。

年报货币资金附注显示，2025 年末不属于现金及现金等价物的货币资金为 5,971,272,473.09 元，主要为定期存款及利息、质押定期存款及利息、票据/保函/信用证/海关保证金及冻结银行存款，不作为可扣除超额现金。

交易性金融资产 30,362,053.74 元全部为远期外汇合约；公允价值披露也说明二层次衍生金融资产/负债为远期外汇合约。该项目不是银行理财、结构性存款、基金或债券等可剥离资金资产，本次未从投入资本扣除，远期结售汇相关投资收益和公允价值变动收益也不从经营 EBIT 剔除。

其他权益工具投资 220,930,000.00 元为非交易性权益工具投资。按任务规则，其他权益工具不默认扣除；本次未扣除，对应股利收入 760,000.00 元也未剔除。

## 粗筛差异

粗筛 ROIC 为 64.11%，本次核对为 17.12%，差异主要来自分母。粗筛投入资本期末约 42.98 亿元、期初约 24.38 亿元，显著扣除了货币资金/资金资产；但年报现金等价物低于 25% 必要现金基准，且大量货币资金为受限或不属于现金等价物的定期存款、保证金和冻结资金，不应按标准口径扣除。分子 NOPAT 与粗筛基本一致，因为本次没有扣除可剥离金融资产，也没有与之配对的收益剔除。

## 质量判断

完整年报 PDF 已由证据包逐页解析，并用全文定向核对现金、交易性金融资产、有息债务、关联方资金拆借、投资收益和公允价值变动收益。`formula_status` 为 `ok`，`confidence` 为 `high`。

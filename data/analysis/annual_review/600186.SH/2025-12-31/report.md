# 莲花控股 2025 ROIC 核对结果

目标读者：复核 `stock_analysis` ROIC 排名口径的研究或数据维护人员。

## 结论

公式：

```text
ROIC = NOPAT / 平均投入资本
NOPAT = 经营 EBIT * (1 - 有效税率)
平均投入资本 = (期末投入资本 + 期初投入资本) / 2
投入资本 = 所有者权益 + 有息融资负债 - 可扣除超额现金 - 可剥离金融投资
```

精修结果：

| 指标 | 金额或比例 |
| --- | ---: |
| 经营 EBIT | 416,757,011.79 |
| 税率 | 18.8622% |
| NOPAT | 338,147,648.66 |
| 2025-12-31 投入资本 | 2,454,131,733.44 |
| 2024-12-31 投入资本 | 1,659,579,512.18 |
| 平均投入资本 | 2,056,855,622.81 |
| ROIC | 16.4400% |
| 经营自由现金流 | 209,398,108.06 |
| 现金 ROIC | 10.1805% |

期初、期末和平均投入资本均大于 0，因此 ROIC 有可排序意义。`formula_status` 设为 `warning`，主要因为现金利息收入只能按标准比例估算剔除，且 2025 年新增 2,000 万元私募基金/股权投资具有战略布局描述，扣除存在判断空间。

## 分子核对

初算 EBIT：

```text
利润总额 394,524,347.01 + 利息费用 36,048,377.18 = 430,572,724.19
```

经营 EBIT 调整：

```text
扣除已扣除金融资产对应收益 13,402,714.16
扣除超额现金对应利息收入 412,998.24
经营 EBIT = 430,572,724.19 - 13,402,714.16 - 412,998.24 = 416,757,011.79
```

已扣除金融资产对应收益来自年报证券投资情况及投资收益、公允价值变动收益附注，包含上市公司股票、股票 ETF、国债逆回购、货币型基金等产生的公允价值变动、处置收益和交易费用净额。长期股权投资收益、权益法转换收益和处置长期股权投资损益未机械剔除，因为长期股权投资未从投入资本扣除。

现金利息收入 12,723,093.27 元未全额剔除。按标准配对口径：

```text
应剔除现金利息 = 12,723,093.27 * 40,203,653.62 / 1,238,539,990.47 = 412,998.24
```

有效税率：

```text
74,415,802.93 / 394,524,347.01 = 18.8622%
```

## 分母核对

2025 年经营必要现金：

```text
4,793,345,347.39 * 25% = 1,198,336,336.85
可扣除超额现金 = 1,238,539,990.47 - 1,198,336,336.85 = 40,203,653.62
```

2024 年经营必要现金：

```text
2,578,156,808.87 * 25% = 644,539,202.22
可扣除超额现金 = 1,128,580,294.02 - 644,539,202.22 = 484,041,091.80
```

2025 年投入资本：

```text
所有者权益 1,804,050,891.67
+ 有息融资负债 860,317,977.17
- 可扣除超额现金 40,203,653.62
- 可剥离金融投资 170,033,481.78
= 2,454,131,733.44
```

2024 年投入资本：

```text
所有者权益 1,515,739,214.86
+ 有息融资负债 756,770,541.09
- 可扣除超额现金 484,041,091.80
- 可剥离金融投资 128,889,151.97
= 1,659,579,512.18
```

有息融资负债包括短期借款、长期借款、一年内到期非流动负债、租赁负债和非流动长期应付款。长期应付款附注列示为租赁付款额扣除未确认融资费用，现金流量附注列示偿还融资租赁公司借款，因此纳入融资负债。

未扣除项目：

| 项目 | 处理 |
| --- | --- |
| 长期股权投资 | 未扣除，属于联营/合营或并购相关权益投资 |
| 投资性房地产 | 未扣除，按成本模式计量，未确认为可剥离金融资产 |
| 商誉 | 未扣除 |
| 不属于现金及现金等价物的贷款保证金、票据保证金、在途资金 | 未作为可扣除超额现金 |

## 与粗筛差异

粗筛 ROIC 为 62.2688%，精修 ROIC 为 16.4400%，下降 45.8288 个百分点。差异主要来自分母：粗筛把货币资金、交易性金融资产、其他非流动金融资产等合计资金资产大额扣除，导致平均投入资本仅 561,047,023.20 元；精修按 25% 年度经营现金流出保留经营必要现金，且不扣除受限保证金，平均投入资本提高至 2,056,855,622.81 元。

粗筛现金 ROIC 为 37.3227%，精修现金 ROIC 为 10.1805%，同样主要由投入资本分母修正导致。

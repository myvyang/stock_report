# 开发科技 2025 ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务分析或数据质检人员。

## 公式和结果

- ROIC = NOPAT / 平均投入资本 = 669,970,060.87 / 1,786,256,895.58 = 37.51%
- 现金 ROIC = 经营自由现金流 / 平均投入资本 = 553,571,623.14 / 1,786,256,895.58 = 30.99%
- NOPAT = 经营 EBIT 773,733,266.63 * (1 - 13.4107%) = 669,970,060.87
- 平均投入资本 = (期末投入资本 1,891,139,619.75 + 期初投入资本 1,681,374,171.41) / 2

投入资本两期均为正，ROIC 有可排序经济含义；但现金利息与资金池无法精确逐项匹配，`formula_status` 设为 `warning`，置信度为 `medium`。

## 分子核对

初算 EBIT = 利润总额 815,921,567.89 + 利息费用 4,388,209.96 = 820,309,777.85。

分子调整：

- 现金利息收入 61,605,920.76。只扣除超额现金，不扣全部货币资金；按 2025 期末可扣超额现金 1,886,965,853.42 / 现金及现金等价物 2,580,762,587.10 = 73.1166%，剔除 45,044,154.55。
- 交易性金融资产为理财产品 100,000,000.00，对应处置交易性金融资产取得投资收益 1,532,356.67，剔除。
- 衍生金融资产为外汇远期合约；年报披露报告期内以投机为目的的衍生品投资不适用，相关交割收益和公允价值变动不与扣除的理财资产配对，不剔除。
- 资产处置收益 444,575.38 来自处置废旧资产，不对应本次扣除的资金资产，不剔除。

经营 EBIT = 820,309,777.85 - 45,044,154.55 - 1,532,356.67 = 773,733,266.63。

所得税费用 109,420,960.92，利润总额 815,921,567.89，有效税率 13.4107%。税率低于法定税率主要由研发费加计扣除影响，使用实际有效税率。

## 分母核对

经营必要现金按年度经营活动现金流出合计的 25%：

- 2025：2,775,186,934.74 * 25% = 693,796,733.69；现金及现金等价物 2,580,762,587.10；可扣除超额现金 1,886,965,853.42。
- 2024：2,627,627,353.00 * 25% = 656,906,838.25；现金及现金等价物 1,270,607,327.60；可扣除超额现金 613,700,489.35。

期末投入资本：

- 所有者权益 3,730,414,506.84
- 有息融资负债 187,696,966.32 = 短期借款 187,382,851.95 + 一年内到期租赁负债 124,600.89 + 租赁负债 189,513.48
- 可扣除资金资产 2,026,971,853.42 = 超额现金 1,886,965,853.42 + 交易性金融资产理财产品 100,000,000.00 + 其他流动资产债权投资 40,006,000.00
- 期末投入资本 1,891,139,619.75

期初投入资本：

- 所有者权益 2,116,922,272.16
- 有息融资负债 178,152,388.60 = 短期借款 177,863,936.82 + 一年内到期租赁负债 220,333.12 + 租赁负债 68,118.66
- 可扣除资金资产 613,700,489.35 = 超额现金
- 期初投入资本 1,681,374,171.41

## 现金口径

经营自由现金流 = 经营活动现金流净额 697,931,733.93 - 购建固定资产、无形资产和其他长期资产支付的现金 144,360,110.79 = 553,571,623.14。

现金 ROIC = 553,571,623.14 / 1,786,256,895.58 = 30.99%。

## 与粗筛差异

粗筛 ROIC 为 64.87%，本次核对为 37.51%，下降 27.37 个百分点。主要原因是粗筛把现金相关资产接近全额从投入资本中扣除；本次按统一规则保留 25% 年度经营现金流出作为经营必要现金，使平均投入资本从约 10.95 亿元提高到 17.86 亿元。

同时，本次按配对原则从 EBIT 中剔除了超额现金对应的部分现金利息收入和理财产品处置收益；没有剔除全部利息收入，也没有剔除外汇远期合约损益。

## 口径限制

年报披露理财产品投资未到期余额 470,006,000.00 元；资产负债表可单独识别为可剥离投资并额外扣除的为交易性金融资产理财产品 100,000,000.00 元和其他流动资产债权投资 40,006,000.00 元。其余银行理财若包含于现金及现金等价物或募集资金现金余额，已通过超额现金口径处理，未重复扣除。

现金利息收入未按存款类型、募集资金、经营必要现金和超额现金逐项拆分，因此采用标准比例调整。该限制影响分子精度，但不改变期初、期末投入资本均为正的判断。

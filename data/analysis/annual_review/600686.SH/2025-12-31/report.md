# 金龙汽车 600686.SH 2025 年 ROIC 核对

## 公式与结果

单位：人民币元。

ROIC = NOPAT / 平均投入资本 = 559,582,768.41 / 5,042,891,376.53 = 11.10%

现金 ROIC = 经营自由现金流 / 平均投入资本 = 1,331,917,954.56 / 5,042,891,376.53 = 26.41%

NOPAT = 经营 EBIT x (1 - 有效税率) = 559,582,768.41 x (1 - 0.00%) = 559,582,768.41

平均投入资本 = (期末投入资本 + 期初投入资本) / 2 = (4,630,478,378.84 + 5,455,304,374.21) / 2 = 5,042,891,376.53

经营自由现金流 = 经营活动现金流净额 - 经营性资本开支 = 1,663,628,959.76 - 331,711,005.20 = 1,331,917,954.56

初算 EBIT = 利润总额 + 利息费用 = 536,123,241.03 + 146,772,755.64 = 682,895,996.67

本次从初算 EBIT 扣除与已扣除可剥离金融资产对应的收益合计 123,313,228.26：

- 银行理财产品收益：44,337,507.18
- 处置交易性金融资产取得的投资收益：250,433.17
- 交易性金融资产公允价值变动收益：4,916,399.68
- 债权投资持有期间取得的利息收入：79,021,155.85 x 未受限大额存单占比 93.40395928% = 73,808,888.23

经营 EBIT = 682,895,996.67 - 123,313,228.26 = 559,582,768.41

所得税费用为 -49,842,432.90，原始税率为 -9.30%。年报所得税调节显示负税费主要来自递延所得税费用、使用前期未确认递延所得税资产的可抵扣亏损/暂时性差异和研发费用加计扣除。本次为避免负税率放大 NOPAT，`tax_rate_used` 取 0。

期初、期末和平均投入资本均大于 0，因此 ROIC 具备可排序含义。

## 与粗筛差异

粗筛 ROIC 为 64.45%，本次精修 ROIC 为 11.10%，差异为 -53.36 个百分点。

主要差异来自现金和投资资产口径：粗筛把较大规模资金资产从投入资本中扣除，导致分母仅约 10.59 亿元；本次按统一规则用现金及现金等价物与 25% 经营现金流出计算超额现金，两期均无可扣除超额现金，因此平均投入资本提高到约 50.43 亿元。同时，本次额外剔除了银行理财和大额存单对应收益，使 NOPAT 从粗筛 6.83 亿元降至 5.60 亿元。

## 口径限制

`formula_status` 为 `warning`，置信度为 `medium`。

限制项：

- 所得税费用为负，本次税率取 0，不把负税率收益资本化进 NOPAT。
- 财务费用中的利息收入未剔除，因为本次未扣除超额现金；现金利息与现金资金池不作机械全额剔除。
- 大额存单利息收入未按受限/未受限拆分，本次按未受限大额存单占总大额存单比例剔除。
- 其他非流动金融资产为权益工具投资，未证明为可剥离非经营投资，未扣除；对应股利和公允价值变动未剔除。
- 长期股权投资、投资性房地产和商誉未扣除。

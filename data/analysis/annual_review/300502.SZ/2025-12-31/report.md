## 公式明细

税率使用合并口径有效税率：

```text
tax_rate_used = 所得税费用 / 利润总额
              = 1,312,442,819.71 / 10,865,719,036.86
              = 0.1207874799
```

经营 EBIT：

```text
初算 EBIT = 利润总额 + 利息费用
          = 10,865,719,036.86 + 1,186,447.97
          = 10,866,905,484.83

可扣除超额现金 = 现金及现金等价物 - 经营活动现金流出合计 * 25%
              = 7,866,344,058.19 - 17,835,563,284.86 * 25%
              = 3,407,453,236.98

剔除现金利息 = 利息收入 * 可扣除超额现金 / 现金及现金等价物
            = 77,949,111.25 * 3,407,453,236.98 / 7,866,344,058.19
            = 33,765,107.33

经营 EBIT = 10,866,905,484.83 - 33,765,107.33
          = 10,833,140,377.50
```

NOPAT：

```text
NOPAT = 经营 EBIT * (1 - tax_rate_used)
      = 10,833,140,377.50 * (1 - 0.1207874799)
      = 9,524,632,651.95
```

投入资本：

```text
期末融资负债 = 一年内到期租赁负债 + 租赁负债
            = 3,622,424.57 + 11,316,444.97
            = 14,938,869.54

期末投入资本 = 所有者权益 + 融资负债 - 可扣除超额现金
            = 18,064,255,651.50 + 14,938,869.54 - 3,407,453,236.98
            = 14,671,741,284.07

期初可扣除超额现金 = max(1,535,167,887.89 - 6,956,384,055.66 * 25%, 0)
                  = 0

期初投入资本 = 8,328,129,817.86 + 18,333,994.99 - 0
            = 8,346,463,812.85

平均投入资本 = (14,671,741,284.07 + 8,346,463,812.85) / 2
            = 11,509,102,548.46
```

现金 ROIC：

```text
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
              = 7,701,234,651.00 - 1,319,702,128.54
              = 6,381,532,522.46

现金 ROIC = 6,381,532,522.46 / 11,509,102,548.46
          = 0.5544769886
```

## 核对判断

完整年报 PDF 已由证据包逐页解析，关键附注已核对。年报来源为巨潮资讯：`https://static.cninfo.com.cn/finalpage/2026-04-24/1225172598.PDF`。

现金不按货币资金全额扣除。期末货币资金 8,155,613,938.09 元，其中其他货币资金 289,269,879.90 元为票据保证金、履约保证金、保函保证金等受限资金；用于超额现金计算的是现金及现金等价物 7,866,344,058.19 元。上期期末现金及现金等价物 1,535,167,887.89 元低于 25% 经营必要现金 1,739,096,013.92 元，因此上期不扣超额现金。

有息融资负债只包括租赁负债及一年内到期租赁负债。年报未列示短期借款、长期借款、应付债券等融资负债。

其他非流动金融资产 32,110,962.00 元披露为非上市公司股权，长期股权投资 13,765,767.88 元为联营企业权益法投资。两者没有证据表明属于银行理财、结构性存款、基金或债券等可剥离资金资产，因此未从投入资本扣除；对应的股利收益、公允价值变动和权益法损益也未从经营 EBIT 中剔除。

所得税有效税率 12.0787%，低于一般法定税率。年报所得税附注显示影响因素包括西部大开发 15%税率、子公司适用不同税率、优惠税率影响和税法规定的额外可扣除费用，该税率可用于本期 NOPAT。

## 粗筛差异

粗筛 ROIC 为 1.151515426，本次核对为 0.8275738801，差异为 -0.3239415459。主要原因是粗筛分母近似扣除了更大范围的资金资产；本次只按统一基准扣除现金及现金等价物中的超额现金，且未扣除非上市股权类其他非流动金融资产和长期股权投资。

粗筛现金 ROIC 为 0.7691215736，本次核对为 0.5544769886，差异同样主要来自平均投入资本上修。

## 口径限制

年报只披露财务费用中的利息收入总额，未给出按日均现金、币种或账户拆分的利息收入。本次按标准口径用期末可扣超额现金占期末现金及现金等价物的比例剔除现金利息收入。

未发现导致 ROIC 不适用的金融、地产或类金融业务口径；也未发现期初、期末或平均投入资本小于等于 0 的情形。

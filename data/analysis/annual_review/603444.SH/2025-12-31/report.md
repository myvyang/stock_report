目标读者：需要复核本次 ROIC 排序口径的财务数据使用者。

## 结论与公式

核对年度：2025-12-31；上一年度：2024-12-31；单位：人民币元。

ROIC = NOPAT / 平均投入资本 = 2,124,382,501.14 / 2,483,817,618.46 = 85.53%

现金ROIC = 经营自由现金流 / 平均投入资本 = 2,792,731,485.15 / 2,483,817,618.46 = 112.44%

NOPAT = 经营 EBIT x (1 - 有效税率)

- 利润总额：2,503,587,601.56
- 利息费用：1,338,292.52
- 初算 EBIT：2,504,925,894.08
- 剔除理财产品及国债投资收益：25,916,669.44
- 剔除理财产品公允价值变动收益：479,744.97
- 经营 EBIT：2,478,529,479.67
- 所得税费用：357,727,431.47
- 有效税率：14.2886%
- NOPAT：2,124,382,501.14

平均投入资本 = (期末投入资本 + 期初投入资本) / 2

- 2025期末投入资本：6,539,174,927.15 + 23,811,018.59 - 4,288,661,256.97 = 2,274,324,688.77
- 2024期末投入资本：5,633,471,948.18 + 31,615,506.45 - 2,971,776,906.48 = 2,693,310,548.15
- 平均投入资本：2,483,817,618.46

## 与粗筛差异

粗筛 ROIC 为216.93%，本次核对后为85.53%，下降131.40个百分点。主因是粗筛把货币资金全额视作可扣除资金资产，本次改为“现金及现金等价物 - 25%经营现金流出”的超额现金口径，并且没有扣除战略性长期股权投资和其他非流动金融资产。

## 口径限制

`formula_status` 设为 `warning`、置信度 `medium`。完整年报 PDF 来源已由证据包验证；关键利润表、现金流量表、货币资金、交易性金融资产、融资负债附注已核对。限制主要在于：证据包未给出上一期交易性金融资产附注明细；其他债权投资/计息金融资产未能完整拆分到两期和收益；超额现金对应利息收入无法可靠分摊，未从经营 EBIT 中单独剔除。若全额剔除2025年利息收入83,085,105.04元，ROIC约为82.66%。

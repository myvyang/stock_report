# 海博思创 2025 ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务分析人员。

## 公式与结果

- ROIC = NOPAT / 平均投入资本 = 970,871,481.45 / 4,294,863,987.19 = 22.61%
- 现金 ROIC = 经营自由现金流 / 平均投入资本 = 59,601,155.52 / 4,294,863,987.19 = 1.39%
- NOPAT = 经营 EBIT x (1 - 有效税率) = 1,135,397,137.54 x (1 - 14.4906%) = 970,871,481.45
- 平均投入资本 = (期末投入资本 5,543,525,966.84 + 期初投入资本 3,046,202,007.53) / 2 = 4,294,863,987.19
- 经营自由现金流 = 经营活动现金流净额 532,262,652.65 - 经营性资本开支 472,661,497.13 = 59,601,155.52

## 分子调整

初算 EBIT = 利润总额 1,112,104,100.03 + 利息费用 28,596,814.14 = 1,140,700,914.17。

由于期末交易性金融资产已从投入资本扣除，配对剔除其收益：

- 处置交易性金融资产取得的投资收益：5,170,401.63
- 交易性金融资产公允价值变动收益：133,375.00

经营 EBIT = 1,140,700,914.17 - 5,303,776.63 = 1,135,397,137.54。

长期股权投资 412,360,851.16 未从投入资本扣除，因此权益法投资收益 -44,924,332.87 未从经营 EBIT 中剔除。其他权益工具投资 70,000,000.00 未纳入标准排序口径扣除项；年报未列示其当期股利收入。

## 粗筛差异

粗筛 ROIC 为 105.93%，本次核对为 22.61%，差异 -83.33 个百分点。主要原因是粗筛将期末货币资金近似全额作为资金资产扣除，使期末投入资本仅约 6.08 亿元；年报显示期末货币资金中 2,503,889,831.75 元为票据保证金、保函保证金、次日起息结构性产品认购等不属于现金及现金等价物，且按 25% 合并经营现金流出基准，2025 年末没有可扣超额现金。

## 口径限制

`formula_status` 标为 `warning`。原因是现金利息收入 22,583,504.26 元无法在经营必要现金、受限保证金、次日起息结构性产品和可扣超额现金之间精确拆分，本次未用“剔除全部利息收入”替代拆分；另外当期营业外收支净额对利润总额有约 28,420,675.37 元正向影响，其中包括无法支付的应付款和预计诉讼损失转回等项目。

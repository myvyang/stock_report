# 中科蓝讯 2025 ROIC 核对结果

目标读者：需要复核 ROIC 排序口径的研究或数据维护人员。

## 公式和结果

单位：人民币元。

```text
初算 EBIT = 利润总额 + 利息费用
          = 1,547,245,057.73 + 7,064,964.36
          = 1,554,310,022.09

经营 EBIT = 初算 EBIT - 可剥离资金/投资资产对应收益
          = 1,554,310,022.09 - 1,350,319,282.45
          = 203,990,739.64

税率 = 所得税费用 / 利润总额
     = 131,895,624.06 / 1,547,245,057.73
     = 8.524546477%

NOPAT = 203,990,739.64 * (1 - 8.524546477%)
      = 186,601,454.23
```

```text
期末投入资本 = 所有者权益 + 有息融资负债 - 可扣除资金资产 - 可剥离长期股权投资
             = 5,296,869,704.84 + 143,198,336.41 - 4,107,250,495.83 - 342,899,686.90
             = 989,917,858.52

期初投入资本 = 4,002,827,348.04 + 357,620,146.87 - 3,577,449,038.98 - 50,500,000.00
             = 732,498,455.93

平均投入资本 = 861,208,157.225

ROIC = 186,601,454.23 / 861,208,157.225
     = 21.6674%
```

```text
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
               = 64,051,503.68 - 25,175,858.72
               = 38,875,644.96

现金 ROIC = 38,875,644.96 / 861,208,157.225
          = 4.5141%
```

## 粗筛差异

粗筛 ROIC 为 138.6179%，本次核对为 21.6674%，差异为 -116.9504 个百分点。主要原因是粗筛把 2025 年大额金融资产投资收益、公允价值变动收益和创投基金权益法收益留在 EBIT 中，导致 NOPAT 被显著高估。

粗筛现金 ROIC 为 3.7901%，本次核对为 4.5141%。现金 ROIC 上升主要来自投入资本口径精修：不扣除经营现金，但扣除定期存款、大额存单和可剥离投资资产后，平均投入资本仍低于粗筛线索。

## 口径限制

`formula_status` 标为 `warning`，置信度为 `medium`。原因是其他非流动金融资产金额和对应公允价值收益明确，但年报没有展开单项被投资对象；本次按可剥离非经营金融投资处理。

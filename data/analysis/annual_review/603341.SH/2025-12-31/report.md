# 龙旗科技 603341.SH ROIC 核对报告

目标读者：需要复核本次 ROIC 精修结果的财务数据使用者。

## 公式与结果

核对年度：2025-12-31，上一年度：2024-12-31。单位：人民币元。

ROIC = NOPAT / 平均投入资本 = 590,026,138.34 / 6,965,166,314.86 = 8.4711%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 155,891,339.62 / 6,965,166,314.86 = 2.2382%。

NOPAT = 经营 EBIT x (1 - 有效税率) = 628,999,604.29 x (1 - 6.1961%) = 590,026,138.34。

经营 EBIT = 利润总额 627,195,296.53 + 利息费用 60,812,854.65 - 交易性金融资产投资收益 38,993,829.25 - 交易性金融资产公允价值变动收益 20,014,717.64 = 628,999,604.29。

期末投入资本 = 所有者权益 5,826,317,004.76 + 有息融资负债 4,438,310,441.31 - 可扣除超额现金 0 - 可剥离交易性金融资产 3,290,806,950.16 = 6,973,820,495.91。

期初投入资本 = 所有者权益 5,593,129,079.60 + 有息融资负债 2,748,284,725.20 - 可扣除超额现金 0 - 可剥离交易性金融资产 1,384,901,670.99 = 6,956,512,133.81。

平均投入资本 = (6,973,820,495.91 + 6,956,512,133.81) / 2 = 6,965,166,314.86。

经营自由现金流 = 经营活动现金流净额 1,137,911,542.73 - 经营性资本开支 982,020,203.11 = 155,891,339.62。

## 核对判断

完整年报已由证据包定位并逐页解析，来源为巨潮资讯《2025年年度报告》：https://static.cninfo.com.cn/finalpage/2026-03-31/1225059835.PDF。

现金不扣除。2025 年经营活动现金流出合计为 48,115,083,190.54，25% 必要现金为 12,028,770,797.64；期末现金及现金等价物为 4,987,901,608.97，低于必要现金。2024 年同口径必要现金为 12,972,962,583.80，期初现金及现金等价物为 5,461,527,574.14，也低于必要现金。因此两期可扣除超额现金均为 0，现金利息收入也不从 EBIT 剔除。

交易性金融资产扣除。年报第177页显示交易性金融资产期末 3,290,806,950.16，主要为理财产品 3,285,715,385.84，另有权益工具投资 5,091,564.32；期初 1,384,901,670.99。年报第82页披露委托理财未到期余额，包括银行、券商、信托、私募理财产品，属于可剥离金融资产。分子同步剔除第232页交易性金融资产股利和处置收益合计 38,993,829.25，以及第233页交易性金融资产公允价值变动收益 20,014,717.64。

其他投资资产不扣除。其他非流动金融资产为权益工具投资，年报说明本期新增股权投资；长期股权投资为 Mentech Investment Limited 联营企业权益法投资；投资性房地产金额很小且采用成本模式。上述资产未从投入资本扣除，对应其他非流动金融资产公允价值收益和权益法收益也未机械剔除。

税率采用实际有效税率。所得税费用 38,861,669.18 / 利润总额 627,195,296.53 = 6.1961%。该税率偏低，年报第235页所得税调节过程显示受研发加计扣除、非应税收入、未确认递延所得税资产等影响。

## 粗筛差异

粗筛 ROIC 为 121.7850%，现金 ROIC 为 29.4172%，主要差异来自分母。粗筛把资金资产大额扣除，导致上一期投入资本为 -105,932,499.70；本次按统一口径不扣除经营必要现金内的现金及现金等价物，只扣除年报可确认的交易性金融资产，使期初、期末投入资本均为正，ROIC 具备排序意义。

本次 verified_roic 为 8.4711%，较粗筛下降 113.3139 个百分点；verified_cash_roic 为 2.2382%。

## 口径限制

交易性金融资产收益按年报附注整体匹配扣除；年报未进一步拆分处置收益中理财与权益工具的比例，但该口径均对应已从分母扣除的交易性金融资产。

未扣除其他非流动金融资产和长期股权投资，因此其对应收益未从经营 EBIT 剔除。这遵守分子分母配对原则，但会使 ROIC 包含未剥离投资资产及其收益。

结论：`formula_status = ok`，`confidence = high`。

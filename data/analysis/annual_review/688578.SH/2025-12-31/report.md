# 艾力斯 688578.SH ROIC核对报告

目标读者：需要复核本次ROIC排序口径的财务分析人员。

## 结论

核对年度：2025-12-31，比较期：2024-12-31，单位：人民币元。

公式：

```text
ROIC = NOPAT / 平均投入资本
NOPAT = 经营EBIT × (1 - 有效税率)
平均投入资本 = (期末投入资本 + 期初投入资本) / 2
```

核对结果：

| 项目 | 数值 |
| --- | ---: |
| 初算EBIT = 利润总额 + 利息费用 | 2,545,067,932.91 |
| 剔除结构性存款收益及公允价值变动 | 53,986,104.06 |
| 剔除定期/大额存单利息收入分摊额 | 47,815,305.08 |
| 经营EBIT | 2,443,266,523.77 |
| 所得税率 | 13.9819836% |
| NOPAT | 2,101,649,399.01 |
| 期末投入资本 | 1,384,474,669.39 |
| 期初投入资本 | 1,528,899,751.12 |
| 平均投入资本 | 1,456,687,210.26 |
| verified_roic | 144.275956% |
| 经营自由现金流 | 2,136,528,694.69 |
| verified_cash_roic | 146.670382% |

期初、期末和平均投入资本均大于0，ROIC具备排序含义。`formula_status` 为 `warning`，原因是年报没有把利息收入精确拆分到活期经营现金、定期存款和大额存单，本次按资金池比例分摊剔除。

## 投入资本

期末投入资本：

```text
7,083,199,054.36 所有者权益
+ 3,887,763.98 融资负债
- 5,702,612,148.95 可剥离资金资产
= 1,384,474,669.39
```

期初投入资本：

```text
5,282,813,244.35 所有者权益
+ 1,296,194.61 融资负债
- 3,755,209,687.84 可剥离资金资产
= 1,528,899,751.12
```

可剥离资金资产包括结构性存款、非现金等价物定期存款、大额存单及对应应收利息。现金及现金等价物不扣除超额现金：2025年经营现金流出3,776,955,884.92，25%必要现金944,238,971.23，高于现金及现金等价物445,720,893.89；2024年同口径必要现金606,593,145.30，也高于现金及现金等价物523,063,240.55。

未扣除其他权益工具投资180,486,580.72。年报披露该项为ArriVent BioPharma股权，公允价值变动计入其他综合收益，未进入本期经营EBIT。

## 分子调整

经营EBIT从利润总额2,544,937,733.94加利息费用130,198.97开始。结构性存款已从分母扣除，因此剔除结构性存款到期收益13,692,051.60和交易性金融资产公允价值变动收益40,294,052.46。

定期/大额存单也作为可剥离资金资产扣除。年报财务费用附注只披露总利息收入54,492,921.19，未拆分来源；本次按扣除的定期/大额存单资金池3,191,600,141.75占其与现金及现金等价物合计3,637,321,035.64的比例87.7459%，剔除利息收入47,815,305.08。

有效税率使用所得税费用355,832,776.70除以利润总额2,544,937,733.94，即13.9819836%。年报披露企业所得税税率15%，有效税率略低主要受研发费用加计扣除等纳税调整影响。

## 粗筛差异

粗筛ROIC为74.980856%，本次精修ROIC为144.275956%，差异为+69.295100个百分点。主要原因是粗筛只扣除了货币资金和交易性金融资产线索，没有扣除年报附注列示的大额存单、非现金等价物定期存款及其应收利息，导致粗筛平均投入资本显著偏高。

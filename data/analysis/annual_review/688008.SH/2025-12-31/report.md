# 澜起科技 2025 ROIC 精修核对

## 公式与结果

- 初算 EBIT = 利润总额 2,320,568,053.46 + 利息费用 1,732,176.80 = 2,322,300,230.26 元
- 经营 EBIT = 初算 EBIT - 可剥离投资收益/公允价值变动 135,101,838.86 - 超额现金对应利息收入 241,495,788.20 = 1,945,702,603.20 元
- 税率 = 所得税费用 190,932,103.50 / 利润总额 2,320,568,053.46 = 8.2278%
- NOPAT = 1,945,702,603.20 × (1 - 8.2278%) = 1,785,613,744.67 元
- 期末投入资本 = 所有者权益 12,871,155,850.07 + 有息融资负债 34,138,185.97 - 超额现金 7,497,806,656.29 - 可剥离金融投资 1,406,818,610.45 = 4,000,668,769.31 元
- 期初投入资本 = 所有者权益 11,396,505,564.91 + 有息融资负债 44,755,795.24 - 超额现金 6,149,365,194.67 - 可剥离金融投资 2,358,738,676.65 = 2,933,157,488.83 元
- 平均投入资本 = 3,466,913,129.07 元
- ROIC = 1,785,613,744.67 / 3,466,913,129.07 = 51.50%
- 经营自由现金流 = 经营活动现金流净额 2,022,020,556.92 - 经营性资本开支 265,828,735.88 = 1,756,191,821.04 元
- 现金 ROIC = 1,756,191,821.04 / 3,466,913,129.07 = 50.66%

期初、期末和平均投入资本均大于 0，ROIC 有可排序意义。`formula_status` 标为 `warning`，因为现金利息收入只能按标准比例法估算，且其他非流动金融资产底层项目未完整展开。

## 核对判断

年报已由证据包逐页解析并核对。合并利润表列示利润总额 2,320,568,053.46 元、利息费用 1,732,176.80 元、所得税费用 190,932,103.50 元；所得税调节表显示有效税率受子公司不同税率、未确认递延所得税资产和研发加计扣除等影响，因此使用实际有效税率 8.2278%。

现金扣除采用统一 25% 经营必要现金基准。2025 年经营活动现金流出为 3,673,067,908.46 元，经营必要现金 918,266,977.12 元；现金及现金等价物 8,416,073,633.40 元，超额现金 7,497,806,656.29 元。2024 年经营活动现金流出为 2,198,265,960.01 元，经营必要现金 549,566,490.00 元；现金及现金等价物 6,698,931,684.67 元，超额现金 6,149,365,194.67 元。期末不属于现金及现金等价物的应收利息 54,706,742.38 元和受限保证金 8,204,000.00 元未纳入超额现金扣除。

可剥离金融投资包括交易性金融资产和其他非流动金融资产。交易性金融资产已由年报附注确认为结构性存款和权益工具投资；其他非流动金融资产为非上市股权投资和私募基金投资。与这些扣除资产配对，分子剔除了交易性金融资产持有/处置收益、结构性存款收益、理财产品收益、交易性金融资产公允价值变动、其他非流动金融资产处置/股利收益及其公允价值变动，合计 135,101,838.86 元。

现金只扣除超额部分，因此没有剔除全部利息收入。按标准比例法，剔除现金利息 = 财务费用附注利息收入 271,072,118.66 × 超额现金 7,497,806,656.29 / 现金及现金等价物 8,416,073,633.40 = 241,495,788.20 元。

长期股权投资、其他权益工具投资和投资性房地产未从投入资本扣除。长期股权投资为联营企业权益法投资，其他权益工具投资列为非交易性投资，投资性房地产无法与租金或处置收益完整配对；相应收益也未机械剔除。

## 与粗筛差异

粗筛 ROIC 为 81.05%，精修后为 51.50%，下降 29.55 个百分点。主要差异来自两点：一是精修口径不把全部货币资金直接扣除，而是保留 25% 年度经营现金流出作为经营必要现金；二是分子按配对原则剔除了超额现金对应利息收入和可剥离金融投资收益。现金 ROIC 从粗筛 66.79% 调整为 50.66%。

## 口径限制

其他非流动金融资产只披露到“非上市股权投资”和“私募基金投资”层级，未披露全部底层项目；本次按可剥离金融/创投资产处理。现金利息收入无法逐笔拆分经营必要现金和超额现金贡献，本次使用标准比例法估算。因此结果适合排序复核，但建议在人工终审时优先复查这些金融资产的战略属性。

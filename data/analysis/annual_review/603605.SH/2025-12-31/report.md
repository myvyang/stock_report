## 经营 EBIT

公式：

```text
初算 EBIT = 利润总额 + 利息费用
经营 EBIT = 初算 EBIT - 交易性金融资产收益 - 可扣除现金类资产对应利息收入
NOPAT = 经营 EBIT × (1 - 税率)
```

核对数：

- 利润总额：1,870,548,980.73，年报合并利润表 p.120。
- 利息费用：36,642,250.36，年报合并利润表 p.119、财务费用附注 p.206。
- 所得税费用：328,027,189.62，年报所得税费用附注 p.210。
- 交易性金融资产在持有期间的投资收益：5,331,694.81，年报投资收益附注 p.207；作为可剥离理财收益扣除。
- 利息收入：58,312,686.17，年报财务费用附注 p.206。年报未拆分经营必要现金、超额现金和大额存单对应利息，本次按平均可扣除现金类资产 / 平均货币资金池分摊，扣除 25,039,762.30。

税率 17.5364% 低于 25%，年报 p.210 的所得税调节表显示主要受子公司适用不同税率、投资收益影响、研发费加计扣除等影响；本次使用实际有效税率。

## 投入资本

公式：

```text
投入资本 = 所有者权益 + 有息融资负债 - 可扣除非经营资金资产
经营必要现金 = 经营活动现金流出小计 × 25%
可扣除超额 CCE = max(现金及现金等价物 - 受限CCE - 经营必要现金, 0)
```

| 项目 | 2025-12-31 | 2024-12-31 |
| --- | ---: | ---: |
| 所有者权益 | 6,266,522,129.38 | 5,486,247,850.96 |
| 有息融资负债 | 911,892,657.66 | 794,440,479.92 |
| 经营活动现金流出小计 | 9,288,403,690.99 | 9,935,227,527.18 |
| 经营必要现金 | 2,322,100,922.75 | 2,483,806,881.80 |
| 现金及现金等价物 | 3,934,243,638.77 | 2,742,569,684.62 |
| 受限 CCE | 242,114,323.46 | 149,891,967.73 |
| 可扣除超额 CCE | 1,370,028,392.56 | 108,870,835.09 |
| 大额存单及定期存款 | 1,119,455,583.40 | 1,327,741,986.16 |
| 合计扣除资金资产 | 2,489,483,975.96 | 1,436,612,821.25 |
| 投入资本 | 4,688,930,811.08 | 4,844,075,509.63 |

大额存单及定期存款在年报 p.214-p.215 明确列为“不属于现金及现金等价物的货币资金”，且不可随时支取；本次作为可剥离现金类投资扣除。ETC 保证金、直营店铺保证金、司法冻结资金、变压器定期存款保证金和受限 CCE 不计入可扣除超额现金。

长期股权投资、其他权益工具投资和投资性房地产没有作为可剥离金融资产扣除；对应权益法收益、股利或租赁收益也不机械剔除。

## 现金 ROIC

```text
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
              = 2,193,146,649.13 - 169,322,089.49
              = 2,023,824,559.64
现金 ROIC = 2,023,824,559.64 / 4,766,503,160.35 = 42.4593%
```

经营活动现金流净额和购建长期资产支付现金来自年报合并现金流量表 p.123。

## 与粗筛差异

粗筛 ROIC 为 72.8795%，现金 ROIC 为 93.7825%。差异主要来自粗筛把全部货币资金 5,060,981,558.27 从投入资本扣除，导致分母偏小。本次按统一口径保留 25% 年度经营现金流出作为经营必要现金，并排除受限现金及保证金，仅扣除超额 CCE 和可剥离大额存单/定期存款；同时从 EBIT 中剔除交易性金融资产收益和按比例分摊的现金利息收入。

## 口径限制

- 年报未精确拆分利息收入在经营必要现金、超额现金和大额存单之间的归属，本次使用标准比例分摊。
- 交易性金融资产期末余额为空，但年内有理财本金收回、理财本金支出和交易性金融资产持有收益；因此只剔除收益，不在期末分母另扣交易性金融资产余额。

# 海信家电 2025 ROIC 核对

目标读者：复核 `stock_analysis` ROIC 排序结果的财务数据使用者。

## 公式与结果

单位：人民币元。

```text
初算 EBIT = 利润总额 + 利息费用
          = 5,448,639,135.47 + 193,086,522.61
          = 5,641,725,658.08

经营 EBIT = 初算 EBIT - 已扣除金融/定期存款资产对应收益
          = 5,641,725,658.08 - 779,805,187.01
          = 4,861,920,471.07

有效税率 = 所得税费用 / 利润总额
        = 714,825,929.62 / 5,448,639,135.47
        = 13.119348%

NOPAT = 经营 EBIT * (1 - 有效税率)
      = 4,224,068,204.83

期末投入资本 = 所有者权益 + 有息融资负债 - 可剥离投资资产
            = 21,520,500,062.31 + 4,612,545,757.17 - 29,972,785,804.51
            = -3,839,739,985.03

期初投入资本 = 19,374,524,711.13 + 3,960,363,872.72 - 27,326,953,256.19
            = -3,992,064,672.34

平均投入资本 = -3,915,902,328.69

ROIC = 4,224,068,204.83 / -3,915,902,328.69
     = -107.8696%
```

现金辅助口径：

```text
经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
              = 5,796,029,180.51 - 2,114,104,984.92
              = 3,681,924,195.59

现金 ROIC = 3,681,924,195.59 / -3,915,902,328.69
          = -94.0249%
```

## 关键核对判断

完整年报来源为巨潮资讯 2025 年年度报告，证据包记录 PDF 已逐页解析，原始 PDF 位于 `work/000921_SZ_2025_annual_report.pdf`，URL 为 `https://static.cninfo.com.cn/finalpage/2026-03-31/1225050277.PDF`。

现金不扣除：2025 年经营活动现金流出合计 79,181,399,997.27 元，25% 经营必要现金为 19,795,349,999.32 元；期末现金及现金等价物为 2,413,566,573.84 元，低于经营必要现金。2024 年同样低于必要现金。因此可扣除超额现金为 0，现金利息收入 43,195,213.33 元不剔除。

可剥离投资资产扣除：年报附注明示交易性金融资产中“理财产品、股票基金等”为 19,129,043,706.26 元；一年内到期的非流动资产为一年内到期定期存款 5,358,503,333.34 元；其他流动资产中定期存款及利息 1,346,154,726.55 元；其他非流动资产中定期存款及利息 4,118,541,736.10 元。这些均按投资性、非经营资金资产扣除。其他非流动金融资产 20,542,302.26 元金额较小，也按可剥离金融资产扣除。

分子配对剔除：从经营 EBIT 中剔除处置交易性金融资产投资收益 320,370,547.70 元、定期存款利息收入 252,767,105.84 元、交易性金融资产公允价值变动收益 204,705,674.44 元、其他非流动金融资产公允价值变动收益 1,961,859.03 元。权益法投资收益 404,891,314.66 元未扣除，因为长期股权投资未从投入资本扣除。资产处置收益未与已扣除资金资产对应，也未剔除。

有息融资负债按筹资活动负债变动表确认，包含短期借款、长期借款含一年内到期部分、租赁负债含一年内到期部分，以及“其他应付款-关联公司借款”。2025 年末合计 4,612,545,757.17 元，2024 年末合计 3,960,363,872.72 元。

## 粗筛差异

粗筛 ROIC 为 214.8864%，核对后为 -107.8696%，差异 -322.7560 个百分点。主要原因不是利润口径，而是分母：粗筛只扣除了货币资金、交易性金融资产等显性资金资产，未识别年报附注中列示于一年内到期非流动资产、其他流动资产和其他非流动资产的大额投资性定期存款及利息。

## 口径限制

`formula_status` 标为 `warning`。扣除大额可剥离投资资产后，两期投入资本均为负，按公式可以计算 ROIC，但该比率的经济含义和排序可比性较弱，建议人工复核排名使用方式。

投资收益中的“其他”54,265,744.26 元未能在证据片段中明确归属到已扣除金融资产，未剔除。其他非流动金融资产的底层资产未完整展开，因金额较小，按可剥离金融资产处理并降低置信度至 `medium`。

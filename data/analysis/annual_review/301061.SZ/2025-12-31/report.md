# 匠心家居 301061.SZ ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务分析人员。

## 核对结论

核对年度：2025-12-31；上一年度：2024-12-31；单位：元。

公式：

```text
初算 EBIT = 利润总额 + 利息费用
经营 EBIT = 初算 EBIT - 交易性金融资产净收益 - 可扣除现金利息
NOPAT = 经营 EBIT × (1 - 有效税率)
投入资本 = 所有者权益 + 有息融资负债 - 超额现金 - 可剥离理财产品
平均投入资本 = (期末投入资本 + 期初投入资本) / 2
ROIC = NOPAT / 平均投入资本
现金 ROIC = (经营活动现金流净额 - 经营性资本开支) / 平均投入资本
```

结果：

| 指标 | 数值 |
| --- | ---: |
| 初算 EBIT | 981,964,620.43 |
| 交易性金融资产净收益剔除 | 30,244,096.42 |
| 可扣除现金利息剔除 | 43,436,545.58 |
| 经营 EBIT | 908,283,978.43 |
| 有效税率 | 11.5766% |

期初、期末及平均投入资本均大于 0，ROIC 有可排序经济含义。`formula_status=ok`。

## 分子核对

利润总额 969,743,303.51，利息费用 12,221,316.92，初算 EBIT 为 981,964,620.43。

已从投入资本扣除的交易性金融资产对应收益需配对剔除：

```text
投资收益 64,335,151.45 + 公允价值变动收益 -34,091,055.03
= 30,244,096.42
```

现金只扣除超额部分，因此只剔除可识别现金利息收入中与超额现金匹配的部分。现金流附注列示经营性利息收入 61,426,515.49；按平均超额现金 / 平均现金及现金等价物 70.7130% 计算，剔除 43,436,545.58。

资产处置收益主要来自使用权资产/固定资产处置，未与被扣除金融资产直接对应，本次未剔除。

## 粗筛差异

粗筛 ROIC 为 120.5586%，核对后 ROIC 为 57.1653%，下降 63.3933 个百分点。主要差异是粗筛把货币资金和理财资金扣除得更激进；本次按指定规则使用现金及现金等价物扣除 25% 经营必要现金后的超额现金，并剔除相应现金利息，平均投入资本从粗筛 720,219,176.10 上升至 1,404,935,470.54。

粗筛现金 ROIC 为 97.8412%，核对后为 50.1568%，差异同样主要来自分母扩大。

## 口径限制

现金利息收入无法逐笔归属至经营必要现金和超额现金，本次按规则使用平均超额现金占平均现金及现金等价物比例剔除。年报已披露交易性金融资产为理财产品，收益与公允价值变动可与扣除项目配对，未发现长期股权投资、投资性房地产、商誉等需要额外调整的可剥离投资项目。

# 天孚通信 300394.SZ 2025 ROIC 核对报告

目标读者：需要复核 ROIC 排序口径的财务数据审核人。

## 公式与结果

- ROIC = NOPAT / 平均投入资本 = 1,961,451,117.52 / 2,761,379,691.45 = 71.03%
- 现金 ROIC = 经营自由现金流 / 平均投入资本 = 1,450,693,075.70 / 2,761,379,691.45 = 52.54%
- NOPAT = 经营 EBIT 2,278,561,148.14 * (1 - 13.9171%) = 1,961,451,117.52
- 平均投入资本 = (期末投入资本 3,285,733,870.49 + 期初投入资本 2,237,025,512.42) / 2 = 2,761,379,691.45

经营必要现金按年度经营活动现金流出合计的 25% 计算：2025 年为 842,382,692.58 元，2024 年为 533,534,513.66 元。可扣除超额现金使用现金及现金等价物而非货币资金总额；年报披露期末货币资金中 57,100,000.00 元保函保证金和 75,814,642.47 元临时冻结账户资金，未进入现金等价物池。

## 分子调整

初算 EBIT = 利润总额 2,343,876,181.15 + 利息费用 1,180,956.44 = 2,345,057,137.59。

交易性金融资产附注列示为非固定收益性理财产品，已从投入资本扣除，因此剔除其配对收益：持有收益 7,992,083.96、处置收益 1,101,272.40、公允价值变动 53,444.45，合计 9,146,800.81。

现金只扣除超额现金，利息收入按超额现金占期末现金及现金等价物比例分摊剔除：

```text
81,248,917.83 * 2,021,360,307.64 / 2,863,743,000.22 = 57,349,188.64
```

经营 EBIT = 2,345,057,137.59 - 9,146,800.81 - 57,349,188.64 = 2,278,561,148.14。有效税率 = 所得税费用 326,200,000.46 / 利润总额 2,343,876,181.15 = 13.9171%；年报所得税调节表显示研发费用加计扣除等影响，税率未机械替换。

## 与粗筛差异

粗筛 ROIC 为 100.58%，本次核对为 71.03%，下降 29.55 个百分点。主要原因是粗筛把货币资金和交易性金融资产基本全额作为可扣除资金资产，本次按统一口径保留 25% 年度经营现金流出作为经营必要现金，使平均投入资本从粗筛约 20.07 亿元上升到 27.61 亿元；同时分子剔除了与可扣除资产配对的理财收益、公允价值变动和按比例分摊的现金利息收入。

## 口径限制

年报未直接拆分现金利息收入中经营必要现金和超额现金的贡献，本次采用运行契约规定的标准比例分摊。长期股权投资未认定为可剥离资金资产，权益法收益未剔除。资产处置收益、营业外收支主要对应固定资产处置或报废，不与已扣除金融资产配对，未作为 ROIC 分子调整项。

数据质量结论：完整年报已核对，`formula_status=ok`，但现金利息分摊仍依赖标准化假设，置信度为 `medium`。

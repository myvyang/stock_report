# 阳光电源 300274.SZ ROIC 核对报告

## 公式与结果

核对年度：2025-12-31；上一年度：2024-12-31；单位：元。

ROIC = NOPAT / 平均投入资本 = 13,542,647,878.44 / 42,895,418,433.18 = 31.57%。

现金 ROIC = 经营自由现金流 / 平均投入资本 = 13,909,759,755.51 / 42,895,418,433.18 = 32.43%。

NOPAT = 经营 EBIT * (1 - 有效税率)。利润总额 16,259,966,657.59，利息支出 346,953,688.50，初算 EBIT 16,606,920,346.09。扣除套保外非经营金融资产/负债损益 254,261,065.53，并按超额现金比例扣除现金利息收入 80,924,548.06，经营 EBIT 为 16,271,734,732.50。所得税费用 2,727,113,118.68，有效税率 16.7719%。

平均投入资本 = (期末投入资本 42,831,275,225.56 + 期初投入资本 42,959,561,640.81) / 2。

期末投入资本 = 所有者权益 49,771,867,668.89 + 有息融资负债 8,074,769,130.91 - 可扣除超额现金 4,535,208,936.44 - 可剥离理财产品 10,480,152,637.81。

期初投入资本 = 所有者权益 40,198,748,048.14 + 有息融资负债 15,041,864,934.86 - 可扣除超额现金 2,451,387,553.42 - 可剥离理财产品 9,829,663,788.77。

经营自由现金流 = 经营活动现金流净额 16,917,778,579.11 - 经营性资本开支 3,008,018,823.60 = 13,909,759,755.51。

## 核对判断

完整年报来源为巨潮资讯《2025年年度报告》，URL：https://static.cninfo.com.cn/finalpage/2026-04-01/1225066678.PDF。证据包已逐页解析完整 PDF，关键数据与年报主表或附注核对。

现金扣除不采用“货币资金全额扣除”。按统一基准，2025 年经营必要现金为经营现金流出 69,851,023,117.86 的 25%，即 17,462,755,779.47；期末现金及现金等价物 21,997,964,715.90，超额现金为 4,535,208,936.44。2024 年同口径超额现金为 2,451,387,553.42。

交易性金融资产中明确可剥离的是理财产品：2025 年末 10,480,152,637.81，2024 年末 9,829,663,788.77。权益工具投资、远期结售汇、其他非流动金融资产中的权益工具投资、长期股权投资和投资性房地产未默认扣除。

融资负债除短期借款、长期借款、一年内到期非流动负债和租赁负债外，补入长期应付款。年报附注列示长期应付款包括融资租赁借款、附有回购条款的投资款和非金融机构借款，具备融资性质。粗筛未纳入该项，是分母差异的重要来源。

分子调整遵守配对原则。远期结售汇未从分母扣除，且与经营套保相关，不机械剔除。处置长期股权投资收益未剔除，年报非经常性损益说明持有和转让电站项目股权属于公司日常经营业务。现金利息收入只按超额现金占现金及现金等价物比例剔除。

## 粗筛差异

粗筛 ROIC 为 65.59%，核对后为 31.57%，下降 34.01 个百分点。主要原因是粗筛把资金资产扣除得过多但未使用 25% 经营必要现金基准，同时未纳入长期应付款融资性质负债；核对后平均投入资本从粗筛约 21,074,119,940 增至 42,895,418,433.18。NOPAT 也因剔除套保外金融资产/负债损益和部分现金利息收入，从粗筛约 13,821,616,340 降至 13,542,647,878.44。

## 口径限制

`formula_status` 设为 `warning`。年报没有把交易性金融资产收益逐项拆到理财产品、权益工具和远期结售汇层面；本次用非经常性损益表中“套保外金融资产和金融负债损益”作为可剥离金融收益调整。若后续取得更细的理财产品收益拆分，需要同步修正分子。

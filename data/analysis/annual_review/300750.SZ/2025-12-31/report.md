# 宁德时代 300750.SZ 2025 ROIC 核对报告

目标读者：复核 ROIC 排序口径的财务分析人员。

## 结论与公式

单位：人民币元。

```text
初算 EBIT = 利润总额 + 利息费用
          = 89,526,545,000 + 2,734,017,000
          = 92,260,562,000

经营 EBIT = 初算 EBIT - 交易性金融资产相关收益 - 按比例剔除的现金利息
          = 92,260,562,000 - 829,817,000 - 7,406,990,066
          = 84,023,754,934

有效税率 = 所得税 / 利润总额
        = 12,740,236,000 / 89,526,545,000
        = 14.2307%

NOPAT = 经营 EBIT * (1 - 有效税率)
      = 72,066,603,371

期末投入资本 = 所有者权益 + 有息融资负债 - 可扣除超额现金 - 可剥离投资
            = 371,026,324,000 + 119,656,488,000 - 205,267,648,000 - 73,686,496,000
            = 211,728,668,000

期初投入资本 = 273,456,174,000 + 136,401,592,000 - 183,187,466,000 - 24,294,958,000
            = 202,375,342,000

平均投入资本 = 207,052,005,000

ROIC = NOPAT / 平均投入资本
     = 34.8060%

经营自由现金流 = 经营活动现金流净额 - 经营性资本开支
              = 133,219,982,000 - 42,344,558,000
              = 90,875,424,000

现金 ROIC = 43.8901%
```

期初、期末和平均投入资本均大于 0，本次 ROIC 具备排序含义。但现金利息收入未按资金池精确拆分，`formula_status` 为 `warning`，置信度为 `medium`。

## 核对判断

完整年报来源为巨潮资讯《2025年年度报告》，URL：`https://static.cninfo.com.cn/finalpage/2026-03-10/1225002214.PDF`。证据包已逐页解析 232 页年报，并提取关键主表及附注。

经营必要现金按统一基准计算：2025 年经营活动现金流出 378,648,372,000 元，必要现金 94,662,093,000 元，现金及现金等价物 299,929,741,000 元，可扣除超额现金 205,267,648,000 元；2024 年必要现金为 86,972,268,000 元，可扣除超额现金 183,187,466,000 元。

交易性金融资产附注列明为银行理财产品及结构性存款，2025 年末 58,993,528,000 元、2024 年末 14,282,253,000 元，作为可剥离金融投资扣除。年报还列示不属于现金及现金等价物的定期存款及应计利息，2025 年末 14,692,968,000 元、2024 年末 10,012,705,000 元，本次作为可剥离现金类存款扣除。保证金和质押定期存款因使用受限未计入可扣除超额现金。

分子分母配对方面，已从经营 EBIT 中剔除交易性金融资产公允价值变动收益 441,408,000 元和处置交易性金融资产收益 388,409,000 元。财务费用附注只披露利息收入总额 10,594,657,000 元，未按现金等价物、定期存款或其他资金来源拆分；本次按扣除的超额现金及定期存款占现金及现金等价物加定期存款资金池比例，剔除现金利息 7,406,990,066 元。

## 与粗筛差异

粗筛 ROIC 为 85.9086%，核对后为 34.8060%，差异为 -51.1026 个百分点。主要原因是粗筛把较大范围的资金资产直接扣除，导致平均投入资本仅 92,110,977,500 元；核对口径保留 25% 经营必要现金，且不机械扣除其他非流动金融资产、长期股权投资等未能确认为可剥离的资产，平均投入资本修正为 207,052,005,000 元。

## 口径限制

其他非流动金融资产、长期股权投资、其他权益工具投资没有被默认扣除；年报显示其他非流动金融资产主要为非上市股权投资并按净资产价值计量，长期股权投资收益也未机械剔除。

长期应付款单独列示金额 1,639,608,000 元，性质包括国开发展基金、应付合作投资款和矿业权出让收益。除一年内到期非流动负债中已包含部分外，本次未把长期应付款余额整体加入有息融资负债，因为附注未明确其完整有息融资属性。

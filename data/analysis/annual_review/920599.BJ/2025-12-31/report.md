# 同力股份 2025 ROIC 精修核对

目标读者：需要复核本次 ROIC 排序口径的财务分析人员。

## 公式和结果

- ROIC = NOPAT / 平均投入资本 = 844,149,169.82 / 2,759,456,354.28 = 30.5911%
- 现金 ROIC = 经营自由现金流 / 平均投入资本 = 360,007,800.00 / 2,759,456,354.28 = 13.0463%
- NOPAT = 经营 EBIT 967,683,078.07 × (1 - 12.7659%) = 844,149,169.82
- 经营 EBIT = 利润总额 962,176,505.37 + 利息支出 10,751,737.23 - 现金利息配对调整 5,245,164.53
- 平均投入资本 = (期末投入资本 2,995,464,388.97 + 期初投入资本 2,523,448,319.60) / 2
- 经营自由现金流 = 经营活动现金流净额 393,317,437.08 - 经营性资本开支 33,309,637.08 = 360,007,800.00

## 投入资本

期末投入资本 = 所有者权益 3,606,209,358.96 + 有息融资负债 194,866,877.50 - 可扣除超额现金 805,611,847.49 = 2,995,464,388.97。

期初投入资本 = 所有者权益 3,104,868,834.02 + 有息融资负债 320,619,883.52 - 可扣除超额现金 902,040,397.94 = 2,523,448,319.60。

经营必要现金采用统一标准：经营活动现金流出小计 × 25%。2025 年经营必要现金为 903,627,104.61，2024 年为 690,147,120.99。可扣除资金只使用现金及现金等价物超过经营必要现金的部分；票据保证金、分销通业务保证金、履约保证金等受限货币资金未计入可扣除超额现金。

有息融资负债纳入短期借款、一年内到期的非流动负债、租赁负债，以及长期应付款中的应付融资租赁款。长期应付款具有融资租赁性质，本次纳入有息融资负债。

## 分子调整

投资收益 -4,773,440.64 元全部为权益法长期股权投资收益。长期股权投资未从投入资本扣除，因此不从经营 EBIT 剔除该项损失。

资产处置收益 2,678,336.56 元来自固定资产和使用权资产处置。相关资产仍保留在投入资本中，因此不作为可剥离资金资产收益剔除。

现金利息收入 14,001,655.88 元未拆分现金及现金等价物和受限保证金来源。按配对原则，使用可扣除超额现金 805,611,847.49 / 期末货币资金 2,150,533,085.78 的比例，剔除 5,245,164.53 元。

有效税率 = 所得税费用 122,830,942.10 / 利润总额 962,176,505.37 = 12.7659%。年报所得税调节表显示税率受研发加计扣除、子公司适用不同税率、以前期间所得税调整等影响，本次使用实际有效税率。

## 粗筛差异

粗筛 ROIC 为 62.1679%，本次精修为 30.5911%，下降 31.5768 个百分点。主要原因是粗筛扣除了全部货币资金 2,150,533,085.78 元；本次按统一口径只扣除超额现金 805,611,847.49 元，并保留经营必要现金和受限保证金。

粗筛期末有息融资负债为 151,438,577.83 元，本次加入长期应付款中的融资租赁款后为 194,866,877.50 元。

## 质量限制

年报完整 PDF 已核对，官方来源为巨潮资讯。公式状态为 `warning`，置信度为 `medium`。限制是现金利息收入没有按现金等价物、受限保证金或定期存款拆分，只能按货币资金池比例进行标准配对调整。

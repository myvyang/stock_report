# 悍高集团 2025 年 ROIC 核对报告

目标读者：需要复核本次 ROIC 排序口径的财务分析人员。

## 核对结论

公式：

```text
ROIC = NOPAT / 平均投入资本
NOPAT = 经营 EBIT × (1 - 有效税率)
平均投入资本 = (期末投入资本 + 期初投入资本) / 2
投入资本 = 所有者权益 + 有息融资负债 - 可扣除超额现金 - 可剥离金融投资
```

核对结果：

| 指标 | 金额/比例 |
| --- | ---: |
| 初算 EBIT | 822,341,422.59 |
| 金融资产投资收益剔除 | 11,189,613.19 |
| 超额现金对应利息收入剔除 | 9,242,140.49 |
| 经营 EBIT | 801,909,668.91 |
| 有效税率 | 13.8366% |
| NOPAT | 690,952,744.59 |
| 期末投入资本 | 1,609,404,807.27 |
| 期初投入资本 | 1,563,593,678.88 |
| 平均投入资本 | 1,586,499,243.07 |
| ROIC | 43.5520% |
| 经营自由现金流 | 815,920,130.99 |
| 现金 ROIC | 51.4290% |

两期投入资本均大于 0，ROIC 具备可排序意义。本次 `formula_status` 为 `warning`，置信度 `medium`。

## 投入资本

期末投入资本：

```text
2,816,304,649.25 所有者权益
+ 385,089,561.94 有息融资负债
- 1,258,381,067.69 超额现金
- 333,608,336.23 可剥离金融投资
= 1,609,404,807.27
```

期初投入资本：

```text
1,746,393,137.56 所有者权益
+ 144,976,790.96 有息融资负债
- 327,776,249.64 超额现金
- 0.00 可剥离金融投资
= 1,563,593,678.88
```

经营必要现金按年度经营活动现金流出合计的 25% 计算：2025 年为 751,700,498.13 元，2024 年为 568,235,694.37 元。超额现金使用现金及现金等价物扣减经营必要现金，未把受限保证金和冻结/待结算资金作为可扣除现金。

可剥离金融投资包括期末交易性金融资产中的理财产品 283,128,336.22 元，以及其他流动资产中的大额存单及利息 50,480,000.01 元。长期股权投资、其他非流动金融资产、投资性房地产、商誉均为 0。

## 分子调整

初算 EBIT 使用利润总额 816,480,879.70 元加利息费用 5,860,542.89 元。

从 EBIT 中剔除的金融资产收益包括投资收益 8,061,276.97 元和交易性金融资产公允价值变动收益 3,128,336.22 元。年报附注列示投资收益均来自金融资产项目，无联营或合营企业投资收益。

现金利息遵守配对原则：只扣除超额现金对应的银行存款利息收入，不剔除全部利息收入。标准调整额为：

```text
14,762,981.34 × 1,258,381,067.69 / 2,010,081,565.83 = 9,242,140.49
```

## 与粗筛差异

粗筛 ROIC 为 83.6498%，本次核对 ROIC 为 43.5520%，差异为 -40.0977 个百分点。主要原因是粗筛近似扣除了全部货币资金和理财资产；本次按统一口径保留 25% 经营现金流出的经营必要现金，导致平均投入资本从粗筛的 847,052,365.8 元提高到 1,586,499,243.07 元。

## 口径限制

年报已核对完整 PDF 和关键附注，但投资收益中的“以摊余成本计量的金融资产终止确认收益”没有进一步披露底层产品明细。本次结合委托理财、大额存单及金融资产收益附注，按可剥离金融资产收益整体剔除。

银行存款利息收入没有披露日均经营必要现金和超额现金拆分，本次按合同标准使用期末超额现金占期末现金及现金等价物比例剔除。

本报告不构成买卖建议，不给目标价。

# 电动车技术发展史学习笔记

- Created: 2026-08-04 Asia/Shanghai
- Scope: 记录电动车整车路线、电池路线和生产成本差异的学习结论。本文是学习笔记，不是正式行业研究报告。

## 学习口径

分析技术发展史时，按下面五个问题记录：

```text
时间：什么时候
谁：哪个公司、科学家或工程团队
环境：当时行业卡在哪里
技术：做出了什么
结果：改变了什么成本、体验或竞争格局
```

一个技术的价值不能只看谁最早发明，还要分清谁先证明原理、谁看懂商业机会、谁完成工程化、谁完成规模化降本。

## 整车厂路线差异

整车厂不是简单组装零件，而是在一个价格带里定义产品，把能源系统、空间、智能化、制造成本和渠道组织成可卖的车。

| 路线 | 代表 | 核心逻辑 | 主要约束 |
|---|---|---|---|
| 垂直整合 + 全价格带 | 比亚迪 | 自己掌握电池、电驱、混动、平台和供应链，用规模压成本 | 组织复杂，价格战可能拖累品牌和利润 |
| 纯电平台 + 软件制造 | Tesla | 少车型、大规模、强平台复用，靠制造效率和全球品牌卖纯电 | 车型周期和价格战会压毛利 |
| 增程家庭 SUV | 理想 | 用增程解决补能焦虑，用大空间和高客单价覆盖复杂系统成本 | 增程长期竞争力和家庭 SUV 需求饱和 |
| 低成本自研 + 性价比 | 零跑 | 把主流配置压到较低价格，争夺大众市场 | 低价竞争下毛利更难守住 |
| 华为赋能 + 主机厂制造 | 赛力斯 / 鸿蒙智行 | 华为提供智能化、渠道和品牌心智，车企承担制造交付 | 利润和主动权可能不完全留在车企 |

## 100 元售价的粗拆

以中国 20 万元左右纯电车为学习模型，消费者支付的 `100` 元里，约 `11-12` 元是税费，车企确认收入约 `88-89` 元。继续拆到车企生产和经营，大致可以这样理解：

| 去向 | 每 100 元售价 | 说明 |
|---|---:|---|
| 动力电池包 | 24-30 | 电芯、材料、PACK、BMS 和电池热管理，是纯电车最大硬成本 |
| 电驱系统 | 6-8 | 电机、电控、逆变器、功率器件和减速机构 |
| 车身和底盘 | 13-17 | 钢铝材料、压铸件、悬架、制动、转向、轮胎 |
| 内外饰和安全 | 9-13 | 座椅、内饰、玻璃、车灯、安全气囊 |
| 智能座舱 / 智驾 / 电子电气 | 5-9 | 芯片、屏幕、摄像头、雷达、域控和线束 |
| 热管理 | 3-5 | 空调、热泵、阀、泵、管路和冷板 |
| 制造、物流、质保、折旧 | 6-10 | 工厂人工、设备折旧、运输和质保准备 |
| 毛利池 | 12-17 | 还要覆盖研发、销售、管理和净利润 |

整车毛利率看起来常收敛到 `15%-20%`，不是巧合。毛利太低，车企支撑不了研发、渠道、质保和下一代车型；毛利太高，竞争对手会降价或堆配置抢用户。真正强的整车厂，是在相近毛利率下还能做到更低费用、更高周转、更少库存、更强供应链和更稳定质量。

## 电池路线史

| 时间 | 谁 | 环境 | 技术 | 结果 |
|---|---|---|---|---|
| 1970s | M. Stanley Whittingham | 石油危机后，替代能源和高能储能被重新重视 | 早期可充电锂电池 | 证明锂体系有高能量密度潜力 |
| 1980 | John Goodenough | 早期锂电池安全、能量和寿命都不足 | 钴酸锂正极 | 推高锂电池能量密度，奠定消费电子锂电基础 |
| 1985-1991 | Akira Yoshino / Sony | 消费电子需要轻、小、可充电电池 | 商业化锂离子电池 | 锂电进入大规模商业化 |
| 1997 | Padhi、Nanjundaswamy、Goodenough | 锂电需要更安全、便宜、稳定的正极路线 | 磷酸铁锂 LFP | 提供安全、低成本、长寿命路线，但能量密度不占优 |
| 2003 左右 | AC Propulsion tZero | 大车企纯电路线受电池拖累 | 用约 `6800` 颗 18650 消费电子电芯做电动车原型 | 证明消费电子电芯可以带来高性能电动车 |
| 2008-2010 | Tesla Roadster | 主流车企仍担心纯电续航、安全和成本 | 用 `6831` 颗 18650 电芯做汽车级电池包 | Tesla 把原型思路工程化、产品化和资本市场化 |
| 2010s | Tesla / 松下、LG、三星、宁德、比亚迪 | 早期纯电最大痛点是续航信心 | 三元和圆柱 / 软包 / 方形电芯并行 | 高能量密度路线先在高端长续航车占优 |
| 2020 | 比亚迪 | 电动车进入大众市场，成本、安全和规模比极限续航更重要 | 刀片电池，长条形 LFP 电芯和结构优化 | LFP 通过结构工程重新获得大众车优势 |
| 2019-2022 | 宁德时代 | 电芯材料提升放缓，Pack 空间利用率成为瓶颈 | CTP / 麒麟电池 | 电池竞争从材料扩展到电芯形态、结构、热管理和整车适配 |

## 2010 前后的关键理解

用大量 18650 圆柱锂电池做电动车，不是 Elon Musk 的单人创举。更准确的分工是：

```text
AC Propulsion / tZero：先证明原理
Eberhard / Tarpenning：看懂创业方向
Musk：提供关键资本和公司化推动
Tesla：完成工程化、产品化和后续规模化
```

Tesla 真正做对的是把消费电子锂电供应链的成熟红利搬到汽车上，再用电池包、热管理、BMS、功率电子、电机和控制软件把几千颗小电芯组织成汽车级系统。

主流车企当年没有普遍跟随 18650，并不代表它们不懂电池，而是风险偏好不同。大车企要考虑几十万辆规模、8 年质保、碰撞安全、召回风险和品牌责任，更偏向少量大电芯或插混 / 增程路线。

## LFP 反转的启发

LFP 不是参数最极致的路线。它早期被三元压制，是因为纯电早期最缺长续航信心；后来反转，是因为大众电动车阶段更重视成本、安全、寿命和规模。刀片电池和 CTP 说明，电池竞争不只是化学材料，还包括结构工程、整包效率、安全设计、热管理、制造良率和整车平台适配。

比亚迪的优势不只是用了 LFP，而是把 LFP、插混系统、电驱、整车制造和大规模车型投放组合起来。它和 Tesla 形成对照：

| 路线 | 早期优势 | 后来挑战 |
|---|---|---|
| Tesla 圆柱电芯 / 纯电平台 | 借用消费电子高能量密度和成熟供应链，先打高端长续航 | 车型周期、价格战和成本下沉压力 |
| 比亚迪 LFP / 刀片 / 插混 | 安全、低成本、规模化，适合大众市场 | 品牌溢价和高端突破更难 |

# 具身机器人产品树拆解

- Created: 2026-08-03 Asia/Shanghai
- Purpose: 复习具身机器人从整机到核心零部件的树状组成关系。本文只讲产品结构和组成逻辑，不放公司名单。

## 总树

```text
具身机器人整机
-> 机械身体
-> 执行系统
   -> 关节执行器
      -> 电机
      -> 减速/传动机构
      -> 驱动器
      -> 关节传感器
      -> 轴承/壳体/制动/散热
   -> 直线执行器
      -> 电机
      -> 丝杠/导轨/螺母
      -> 驱动器和位置/力反馈
   -> 末端执行器
      -> 灵巧手
      -> 夹爪/工具接口
-> 感知系统
   -> 外部感知
   -> 本体感知
   -> 接触感知
-> 计算和控制系统
   -> AI 计算
   -> 运动控制
   -> 电机驱动
   -> 安全控制和通信
-> 电源和热管理
-> 软件、模型和数据
-> 制造、测试和运维
```

## 1. 具身机器人整机

具身机器人整机由机械身体、执行系统、感知系统、计算控制系统、电源热管理、软件数据、制造测试运维组成。这个组成逻辑是：机器人要先有身体承载重量和动作，要有执行系统产生动作，要有感知系统知道外界和自身状态，要有计算控制系统把任务变成动作，要有电源和热管理保证持续工作，最后还要靠软件、数据、制造和运维把样机变成可长期使用的产品。

## 2. 机械身体

机械身体由骨架、外壳、关节连接结构、负载安装位、线束通道、防护件和轻量化材料组成。它的作用不是单纯“做外形”，而是把电池、关节、传感器、计算单元和线束放在合理位置，同时承受行走、搬运、跌倒、碰撞和长期振动。机械身体设计不好，后面的电机再强、算法再好，也会因为重量、刚性、散热、维护和安全问题无法量产。

## 3. 执行系统

执行系统由关节执行器、直线执行器和末端执行器组成。它的作用是把电能和控制指令变成真实动作：腿和腰负责站立、行走和平衡，手臂负责移动物体，手或夹爪负责接触和操作物体。执行系统是机器人硬件成本和性能的核心，因为它直接决定机器人有多大力、动作多准、能工作多久、坏得快不快。

## 4. 关节执行器

关节执行器由电机、减速/传动机构、驱动器、关节传感器、轴承、壳体、制动和散热组成。它不是“一个电机”，而是一个小型闭环运动单元：电机出力，减速器把高速小力变成低速大力，驱动器控制电机，编码器和力矩传感器反馈位置和受力，轴承和壳体承受结构载荷，制动和散热保证安全与连续工作。人形机器人关节难，是因为这些东西要同时塞进很小体积里，还要轻、强、准、耐摔、低噪音、低发热、低成本。

## 5. 电机

电机由定子、转子、绕组、磁钢、轴和机壳组成。它的作用是把电能转换成旋转力矩。机器人常见电机包括无框力矩电机、空心杯电机、永磁同步电机等；区别主要在体积、重量、响应速度、力矩密度和成本。电机本身能让关节转起来，但通常转速高、直接输出力矩不够，所以还需要减速器或丝杠等传动机构配合。

## 6. 减速/传动机构

减速/传动机构由齿轮、谐波/应变波组件、RV/摆线结构、行星齿轮、丝杠、螺母、导轨等组成。它的作用是改变电机输出的速度、力矩和运动形式：减速器把高速旋转变成低速大力旋转，丝杠把旋转变成直线伸缩。这个环节影响关节精度、背隙、刚性、寿命、噪音和抗冲击，是执行器里最容易成为瓶颈的部分之一。

## 7. 驱动器

驱动器由功率器件、控制板、电流采样、保护电路、通信接口和固件组成。它的作用是把控制器给出的动作命令变成电机能执行的电流和电压。没有驱动器，控制系统只能“想让电机动”，不能精确控制电机怎么动。驱动器要低延迟、抗干扰、能保护电机和电池，还要和编码器、力矩传感器协同形成闭环控制。

## 8. 关节传感器

关节传感器由编码器、力矩传感器、温度传感器、电流采样和限位检测组成。它们回答的是：关节转到哪了、速度多快、用了多大力、有没有过热、有没有超限。关节传感器让机器人从“开环发力”变成“闭环修正”，是安全接触、精确操作和全身平衡的基础。

## 9. 直线执行器

直线执行器由电机、丝杠、螺母、导轨、轴承、驱动器和位置/力反馈组成。它的作用是产生直线伸缩动作，常用于腿部、手臂或躯干中需要推拉的部位。直线执行器和旋转关节的区别是输出运动形式不同：旋转关节像肩膀或膝盖转动，直线执行器像肌肉伸缩。行星滚柱丝杠、滚珠丝杠等就是这个分支的关键传动件。

## 10. 末端执行器

末端执行器由灵巧手、夹爪、吸盘、工具接口和末端传感器组成。它的作用是让机器人真正接触世界并完成任务。早期工厂和仓储任务可能只需要夹爪或专用工具；家庭服务、复杂装配和工具使用才更需要灵巧手。因此末端执行器的复杂度取决于落地场景，不是所有机器人一开始都需要五指灵巧手。

## 11. 灵巧手

灵巧手由手掌结构、手指关节、微型电机、微型减速器、腱绳/连杆、触觉传感器、力传感器、指尖材料、手部控制板和线束组成。它的组成逻辑是：手要在很小空间里完成多自由度动作，并且要知道自己碰到了什么、抓得多紧、是否滑落。灵巧手比普通关节更难，因为它同时要求小型化、触觉、耐磨、抗污染、低成本和复杂抓取控制。

## 12. 感知系统

感知系统由外部感知、本体感知和接触感知组成。外部感知看环境，本体感知看机器人自己的姿态和关节状态，接触感知看机器人和物体、人、地面之间的作用力。这个分法比按摄像头、雷达、IMU 罗列更清楚，因为机器人控制需要同时知道“外面发生什么”“自己身体在哪里”“自己碰到了什么”。

## 13. 外部感知

外部感知由摄像头、深度相机、激光雷达、毫米波雷达、麦克风和环境传感器组成。它的作用是识别道路、房间、工位、物体、人和障碍物。外部感知决定机器人能不能理解任务环境，但它本身不直接产生动作，必须和任务规划、运动控制和执行系统结合。

## 14. 本体感知

本体感知由 IMU、关节编码器、速度/加速度反馈、电流反馈和足底状态反馈组成。它的作用是让机器人知道自己的身体姿态、关节角度、速度和受力趋势。走路和平衡尤其依赖本体感知，因为机器人必须实时知道自己是不是要摔、哪只脚踩实了、身体重心在哪里。

## 15. 接触感知

接触感知由力矩传感器、六维力传感器、足底力传感器、触觉传感器和指尖压力传感器组成。它的作用是让机器人知道自己和外界接触时用了多大力、力来自哪个方向、物体有没有滑动。接触感知越强，机器人越可能做精细操作；但传感器也要解决成本、耐久、校准和一致性问题。

## 16. 计算和控制系统

计算和控制系统由 AI 计算单元、运动控制器、电机驱动器、安全控制器、通信总线和时钟同步组成。它的组成逻辑是分层控制：AI 计算负责理解任务和环境，运动控制负责把任务变成身体动作，驱动器负责控制每个电机，安全控制负责异常保护，通信和时钟同步负责让几十个关节和传感器在同一个时间基准下协同。

## 17. 软件、模型和数据

软件、模型和数据由视觉感知、语音语言、任务规划、路径规划、全身控制、抓取策略、仿真训练、遥操作数据和真实部署数据组成。它的作用是把硬件身体变成能学习、能泛化、能完成任务的系统。硬件决定机器人能不能做动作，软件和数据决定机器人知道做什么、怎么做、遇到变化如何调整。

## 18. 电源和热管理

电源和热管理由电池包、BMS、电源管理、DC-DC、电源分配、线束连接器、散热器、风冷/液冷结构和温度传感组成。电源系统提供能量，热管理让电池、驱动器、电机和计算单元保持在安全温度内。机器人空间小、关节密、运动连续，发热和续航会直接影响可用时间、寿命和安全。

## 19. 制造、测试和运维

制造、测试和运维由精密加工、装配、标定、老化测试、跌倒/冲击测试、可靠性测试、软件烧录、质量追溯、备件和现场维护组成。它的作用是把样机变成可复制、可交付、可维护的产品。具身机器人从演示走向商业化，难点不只是“能动一次”，而是大量机器长期稳定工作，并且故障可诊断、可维修、成本可控。

## 复习重点

读这棵树时先抓三条主线：

1. 动作链：软件指令 -> 控制器 -> 驱动器 -> 电机 -> 传动机构 -> 关节/手 -> 传感器反馈。
2. 身体链：结构件承载所有部件，线束和连接器把电源、信号、控制连起来，热管理保证持续工作。
3. 商业链：越靠近高价值、难标准化、难量产、影响安全和性能的节点，越可能有议价；越是标准结构件和普通加工件，越容易被规模化压价。

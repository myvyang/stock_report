# 具身机器人产品树拆解

- Created: 2026-08-03 Asia/Shanghai
- Purpose: 复习具身机器人从整机到核心零部件的树状组成关系。本文先解释每个模块解决什么问题、难在哪里，再列它由哪些子项组成；不放公司名单。

## 总树

```text
具身机器人整机
-> 机械身体
-> 执行系统
   -> 关节执行器
      -> 电机
      -> 减速/传动机构
      -> 驱动器
      -> 关节传感器
      -> 轴承/壳体/制动/散热
   -> 直线执行器
      -> 电机
      -> 丝杠/导轨/螺母
      -> 驱动器和位置/力反馈
   -> 末端执行器
      -> 灵巧手
      -> 夹爪/工具接口
-> 感知系统
   -> 外部感知
   -> 本体感知
   -> 接触感知
-> 计算和控制系统
   -> AI 计算
   -> 运动控制
   -> 电机驱动
   -> 安全控制和通信
-> 电源和热管理
-> 软件、模型和数据
-> 制造、测试和运维
```

读这棵树时不要先背零件名。更好的顺序是：先问这个模块在机器人里承担什么功能，为什么没有它机器人就不能稳定工作，再看它拆成哪些子项。子项只是实现路径，父模块的功能和约束才决定投资研究时应该看什么。

## 根节点：具身机器人整机

具身机器人整机不是“会聊天的机器装上手脚”，而是一套能在现实世界里持续感知、决策、运动、接触和维护的复杂机电系统。它要解决三个问题：第一，身体能不能承受自己的重量、负载、跌倒和长时间动作；第二，控制系统能不能把任务变成稳定动作；第三，量产后能不能便宜、可靠、可维修。

整机难度来自系统耦合。电池更大，续航更好，但身体更重，关节负担更大；关节更强，运动能力更好，但发热、噪音、成本和维护压力上升；传感器更多，感知更细，但线束、同步、算力和故障点也增加。所以整机厂的核心不是堆零件，而是在重量、成本、性能、安全和可靠性之间取舍。

组成上，整机由机械身体、执行系统、感知系统、计算和控制系统、电源和热管理、软件模型数据、制造测试运维组成。这个结构对应一条完整闭环：身体承载零件，执行系统产生动作，感知系统采集状态，计算控制系统决定动作，电源和热管理支撑连续工作，软件和数据让机器人从规则动作走向复杂任务，制造测试运维把样机变成可交付产品。

## 1. 机械身体

机械身体是机器人所有零部件的承载平台，不只是外壳或造型。它要决定关节放在哪里、电池和计算单元怎么布局、线束怎么走、摔倒时哪里先受力、维修时哪些部件能快速拆换。机械身体如果做得差，后面的算法和执行器都会被拖累：重量太大导致续航差，刚性不足导致动作发抖，空间太挤导致散热和维修困难。

制造难点在轻、强、稳、便宜之间取平衡。人形机器人既需要接近人类活动空间的尺寸，又需要关节频繁运动和承受冲击；结构件材料、加工精度、装配一致性、跌倒保护和防尘防水都会影响量产可靠性。这个环节不一定利润率最高，但决定整机能不能规模交付。

组成上，机械身体包括骨架、外壳、关节连接结构、负载安装位、线束通道、防护件和轻量化材料。骨架承受主要载荷，外壳保护内部零件，连接结构保证关节力能传到身体，线束通道让电源和信号不被运动磨坏，防护件处理跌倒、碰撞、灰尘和夹手等安全问题。

## 2. 执行系统

执行系统是机器人“把想法变成动作”的部分。计算系统可以规划动作，但真正让腿迈出去、腰保持平衡、手臂抬起物体、手指抓住杯子的，是执行系统。它决定机器人能不能站稳、能搬多重、动作是否顺滑、是否安全接触人和物体。

执行系统通常是硬件成本和性能瓶颈的核心。难点不是单次动作，而是小体积里输出足够力矩，还要低噪音、低发热、高寿命、抗冲击、低成本。执行系统越成熟，机器人越可能从演示样机走向长期工作；执行系统不成熟，软件再聪明也只能做轻量演示。

组成上，执行系统包括关节执行器、直线执行器和末端执行器。关节执行器负责旋转关节，例如肩、肘、髋、膝；直线执行器负责推拉伸缩，例如某些腿部、躯干或手臂结构；末端执行器负责最后接触物体，例如灵巧手、夹爪、吸盘或工具接口。

### 2.1 关节执行器

关节执行器可以理解为机器人的“可控肌肉关节”。它不是一个电机，而是一个高度集成的小型闭环运动单元：既要发力，又要知道自己转到哪里、受了多大力、是否过热，还要在异常时保护机器人和人。人形机器人自由度多，单台机器可能有几十个关节，所以关节执行器的成本、寿命和一致性会直接决定整机商业化。

制造难点集中在小型化和一致性。关节需要轻而强，既要力矩密度高，又要响应快、背隙小、噪音低、发热少；还要经得起摔倒、冲击和重复动作。一个关节样品做出来不难，难的是几万、几十万个关节都稳定一致，并且价格降到整机能卖出去。

组成上，关节执行器包括电机、减速/传动机构、驱动器、关节传感器、轴承、壳体、制动和散热。电机产生旋转力，减速器把高速小力变成低速大力，驱动器把控制命令变成电流，编码器和力矩传感器反馈位置和受力，轴承与壳体承载结构载荷，制动和散热保证安全与连续工作。

#### 2.1.1 电机

电机负责把电能变成旋转力矩，是执行器的动力来源。机器人电机和普通工业电机的要求不同：它更重视体积、重量、响应速度、力矩密度和发热控制。人形机器人关节空间有限，电机越轻越小越好，但输出不能太弱，否则腿站不稳、手臂拿不起东西。

电机不是最孤立的零件。它通常要和减速器、驱动器、编码器、散热结构一起设计；只看电机参数容易误判。一个电机转得很快不等于关节有力，因为关节需要的是低速大力矩和可控性。投资研究时要看公司是否只是卖标准电机，还是能进入机器人关节的集成设计和客户验证。

组成上，电机包括定子、转子、绕组、磁钢、轴和机壳。常见类型包括无框力矩电机、空心杯电机、永磁同步电机等。无框电机适合集成进关节结构，空心杯电机更常用于灵巧手等小型空间，永磁同步电机则是更广泛的高效率电机路线。

#### 2.1.2 减速/传动机构

减速/传动机构负责把电机“不适合直接使用的运动”变成关节真正需要的运动。电机天然更擅长高速旋转，但机器人关节需要低速、大力、可控、耐冲击。减速器把速度降下来、力矩放大；丝杠把旋转运动变成直线推拉。没有传动机构，很多关节会力不够、抖动大、控制不稳。

这个环节容易成为瓶颈，因为它同时影响精度、背隙、刚性、寿命、噪音和抗冲击。所谓背隙，可以简单理解为齿轮或传动件之间的空档，空档大了动作就不准、会晃。人形机器人还要求轻、小、便宜和可量产，进一步提高难度。减速器、丝杠这类零件的加工精度、材料热处理、装配和寿命验证都很重要。

组成上，减速/传动机构包括齿轮、谐波/应变波组件、RV/摆线结构、行星齿轮、丝杠、螺母、导轨等。谐波/应变波减速器适合小型高精度旋转关节，RV/摆线减速器更偏大扭矩高刚性，行星齿轮适合较通用的减速场景，滚珠丝杠和行星滚柱丝杠用于直线执行器。

#### 2.1.3 驱动器

驱动器是控制系统和电机之间的执行翻译层。上层控制器说“这个关节转到某个位置、用某个速度和力矩”，驱动器把这个命令变成电机实际需要的电流和电压。没有驱动器，软件只能下指令，不能让电机精准执行。

驱动器难在低延迟、高可靠和安全保护。机器人有很多关节同时动作，驱动器要快速响应，还要抗电磁干扰、控制发热、保护电机和电池，在异常电流、过温、堵转、通信中断时及时处理。驱动器和编码器、力矩传感器配合不好，关节就会抖、冲、延迟或不安全。

组成上，驱动器包括功率器件、控制板、电流采样、保护电路、通信接口和固件。功率器件负责电能转换，控制板运行电机控制算法，采样和保护电路监控状态，通信接口连接上层控制器，固件决定响应速度、控制精度和故障处理逻辑。

#### 2.1.4 关节传感器

关节传感器让机器人知道自己的动作结果。没有传感器，机器人只能发出动作命令，却不知道关节是否真的转到位、用了多大力、是否被外物卡住、有没有过热。这叫开环控制，风险很大；有了反馈后，机器人才能闭环修正。

关节传感器难在精度、稳定性、体积和校准。编码器精度不够，动作位置会偏；力矩传感不准，抓东西可能夹坏或拿不稳；温度和电流监控不足，关节可能过热损坏。传感器还要在长期振动、冲击、温度变化和线束弯折下保持一致。

组成上，关节传感器包括编码器、力矩传感器、温度传感器、电流采样和限位检测。编码器看位置和速度，力矩传感器看受力，温度传感器看热风险，电流采样间接反映负载，限位检测防止关节超出机械安全范围。

### 2.2 直线执行器

直线执行器负责产生推拉伸缩动作，可以理解为更接近“肌肉伸缩”的执行单元。旋转关节像肩膀、肘部、膝盖那样转动；直线执行器则把电机旋转变成直线位移，用来推动腿部、手臂或躯干中的某些结构。

直线执行器的难点在高推力、小体积、寿命和效率。丝杠、螺母、导轨等传动件要承受轴向力，还要低摩擦、低噪音、抗磨损。行星滚柱丝杠常被重点讨论，是因为它相比普通滚珠丝杠更适合高负载和紧凑空间，但制造精度和量产难度也更高。

组成上，直线执行器包括电机、丝杠、螺母、导轨、轴承、驱动器和位置/力反馈。电机提供旋转动力，丝杠和螺母把旋转转成直线运动，导轨保证运动方向稳定，轴承承受力和降低摩擦，驱动器和传感器负责控制与反馈。

### 2.3 末端执行器

末端执行器是机器人真正接触世界、完成任务的最后一环。机器人能不能搬箱子、拧螺丝、拿杯子、折衣服，不只取决于手臂能不能到达位置，还取决于末端能不能稳定接触、夹持、施力和适应物体形状。

末端执行器的复杂度取决于场景。工厂和仓储早期可能只需要夹爪、吸盘或专用工具，目标是稳定、便宜、耐用；家庭服务、复杂装配和工具使用才更需要灵巧手。灵巧手能力更强，但成本、寿命、抗污染、触觉和控制难度都更高，不一定是最早商业化的形态。

组成上，末端执行器包括灵巧手、夹爪、吸盘、工具接口和末端传感器。夹爪适合规则物体，吸盘适合平整表面，工具接口适合专用任务，灵巧手适合多形状、多动作的复杂操作，末端传感器提供触觉和力反馈。

#### 2.3.1 灵巧手

灵巧手是末端执行器里最复杂的路线，目标是接近人手的多自由度操作。它不只是“多装几个手指”，而是要在很小空间里实现多个关节协同，还要感知接触、控制力度、避免滑落和损坏物体。对家庭服务、精密装配、工具使用来说，灵巧手可能很关键。

灵巧手难度通常高于普通大关节。它要求小型化电机和传动、柔性或刚性手指结构、触觉传感、耐磨材料、复杂抓取算法和高可靠线束。手指空间极小，零件更难做；触觉和力控不成熟，抓东西就容易要么太松、要么夹坏；长期使用还要抗灰尘、油污、冲击和磨损。

组成上，灵巧手包括手掌结构、手指关节、微型电机、微型减速器、腱绳/连杆、触觉传感器、力传感器、指尖材料、手部控制板和线束。微型电机和减速器负责驱动手指，腱绳或连杆传递动作，触觉和力传感判断接触状态，指尖材料影响摩擦和抓取稳定性，控制板负责多指协同。

## 3. 感知系统

感知系统负责让机器人知道外界和自身状态。它不是简单堆摄像头，而是回答三个问题：外面有什么，自己的身体在哪里，自己碰到了什么。机器人要在现实世界里行动，就必须同时掌握环境、身体姿态和接触力。

感知难点在融合和可靠性。单个传感器可能会被光线、遮挡、振动、温度、灰尘和接触冲击影响；机器人必须把不同传感器的信息融合起来，并且在数据不完整时仍能安全行动。感知系统越强，机器人越能处理复杂任务；但传感器越多，成本、线束、同步和故障诊断也越复杂。

组成上，感知系统包括外部感知、本体感知和接触感知。外部感知看环境，本体感知看机器人自身姿态和关节状态，接触感知看机器人和物体、人、地面之间的作用力。这个分法比单纯罗列摄像头、雷达、IMU 更适合学习控制逻辑。

### 3.1 外部感知

外部感知负责理解机器人周围的世界。它让机器人知道房间、工位、货架、道路、人、物体和障碍物在哪里，也让机器人识别任务对象，例如杯子、箱子、门把手或工具。外部感知越好，机器人越可能从固定工位走向开放环境。

外部感知的难点在真实环境变化。光照会变，物体会遮挡，人会突然出现，家庭和工厂布局也不固定。外部感知本身不产生动作，它必须和任务规划、运动控制、接触感知结合，否则“看见了”也不等于“能稳定拿起来”。

组成上，外部感知包括摄像头、深度相机、激光雷达、毫米波雷达、麦克风和环境传感器。摄像头提供视觉语义，深度相机和激光雷达提供距离和空间结构，毫米波雷达适合部分低能见度场景，麦克风支持语音和声源，环境传感器处理温湿度、烟雾等特定需求。

### 3.2 本体感知

本体感知负责让机器人知道自己的身体状态。人走路时不用低头也知道腿在哪里、身体是不是倾斜，机器人也需要类似能力。没有本体感知，机器人无法稳定平衡，也无法准确控制手臂和腿部动作。

本体感知难点在实时性和准确性。走路、跑动、被推、搬重物时，机器人必须快速判断姿态、关节角度、速度、加速度和受力趋势。反馈延迟或误差会直接导致摔倒、冲击或动作失控。这个环节和全身控制强绑定。

组成上，本体感知包括 IMU、关节编码器、速度/加速度反馈、电流反馈和足底状态反馈。IMU 看身体姿态变化，编码器看关节角度，速度和加速度反馈看运动状态，电流反馈间接看负载，足底状态反馈判断脚是否踩实和地面反作用力。

### 3.3 接触感知

接触感知负责理解“碰到之后发生了什么”。机器人最终要和物体、人、地面接触，只靠视觉不够。拿杯子时要知道夹得紧不紧，走路时要知道脚是否踩实，协作时要知道有没有碰到人。接触感知是精细操作和安全交互的关键。

接触感知难在传感器耐久和数据解释。力和触觉传感器需要长期承受冲击、摩擦、挤压和温度变化，还要保持校准一致。更难的是软件要理解这些接触信号：滑动、碰撞、挤压、正常支撑，在数据上可能非常接近。

组成上，接触感知包括力矩传感器、六维力传感器、足底力传感器、触觉传感器和指尖压力传感器。力矩传感器看关节受力，六维力传感器看三方向力和三方向力矩，足底力传感器看地面支撑，触觉和指尖压力传感器看抓取接触状态。

## 4. 计算和控制系统

计算和控制系统是机器人的大脑和神经系统。它不是一个芯片就能解决的问题，而是分层协同：上层理解任务和环境，中层规划动作，底层控制每个关节，安全层处理异常。机器人动作多、传感器多、关节多，必须在很短时间内协调所有信息。

难点在实时闭环。语言模型可以慢一点回答问题，但机器人摔倒、碰撞、抓取滑落这些事情需要毫秒级反应。控制系统要在复杂任务和底层实时控制之间分工，还要处理通信延迟、时钟同步、冗余安全和故障降级。

组成上，计算和控制系统包括 AI 计算单元、运动控制器、电机驱动器、安全控制器、通信总线和时钟同步。AI 计算负责感知和任务理解，运动控制器把任务变成身体动作，驱动器控制每个电机，安全控制器处理异常保护，通信总线和时钟同步让几十个关节和传感器在同一节奏下协同。

## 5. 软件、模型和数据

软件、模型和数据决定机器人是否“会用身体”。硬件提供动作能力，但机器人要完成任务，还需要理解指令、识别环境、规划路径、控制全身、选择抓取方式，并从失败中学习。没有软件和数据，机器人只是昂贵的机电平台。

难点在泛化和数据闭环。固定工厂任务可以预设规则，开放环境任务却变化很大：物体不同、摆放不同、人的行为不同、失败情况不同。机器人需要仿真、遥操作、真实部署数据共同训练，还要把真实场景里的失败变成下一轮改进。

组成上，软件、模型和数据包括视觉感知、语音语言、任务规划、路径规划、全身控制、抓取策略、仿真训练、遥操作数据和真实部署数据。视觉和语言理解任务，规划模块决定做什么，全身控制和抓取策略决定怎么动，仿真和数据负责训练与迭代。

## 6. 电源和热管理

电源和热管理决定机器人能工作多久、能不能持续高负载、安全边界在哪里。机器人不像固定设备可以随时接电，也不像汽车有很大的底盘空间；它要把电池、驱动器、电机、计算单元都塞进有限身体里，还要持续运动。

难点在续航、重量和发热。电池大，续航长，但机器人变重，关节消耗更大；电机和驱动器功率高，动作强，但热量上升；算力强，模型能力好，但耗电和散热压力更大。热管理做不好，机器人可能降频、停机、寿命下降甚至出现安全问题。

组成上，电源和热管理包括电池包、BMS、电源管理、DC-DC、电源分配、线束连接器、散热器、风冷/液冷结构和温度传感。电池包提供能量，BMS 管电池安全，电源管理和 DC-DC 给不同部件供电，线束连接器传输电力和信号，散热结构和温度传感控制热风险。

## 7. 制造、测试和运维

制造、测试和运维是把演示样机变成商业产品的最后门槛。机器人能在发布会上走几分钟，和几千台机器在客户现场每天稳定工作，是两件事。真正商业化要求零件一致、装配可控、故障可诊断、维修有备件、软件能升级、成本能下降。

难点在长期可靠性和量产一致性。关节、线束、传感器、外壳、散热、电池都要经受振动、跌倒、灰尘、温湿度和重复动作。任何一个小故障都可能让整机停机。制造能力强的公司不一定最会做算法，但在量产阶段可能非常重要。

组成上，制造、测试和运维包括精密加工、装配、标定、老化测试、跌倒/冲击测试、可靠性测试、软件烧录、质量追溯、备件和现场维护。加工和装配保证零件一致，标定让传感和控制准确，测试发现寿命问题，质量追溯定位批次缺陷，运维体系决定客户现场能不能长期使用。

## 复习重点

读这棵树时先抓三条主线：

1. 动作链：软件指令 -> 控制器 -> 驱动器 -> 电机 -> 传动机构 -> 关节/手 -> 传感器反馈。
2. 身体链：结构件承载所有部件，线束和连接器把电源、信号、控制连起来，热管理保证持续工作。
3. 商业链：越靠近高价值、难标准化、难量产、影响安全和性能的节点，越可能有议价；越是标准结构件和普通加工件，越容易被规模化压价。

# 具身智能 A股候选专注度与技术优势初判

- Created: 2026-08-03 Asia/Shanghai
- Status: 学习用初判，非正式股票研究报告

## 判断框架

不把“位置对了”直接等同于“有竞争力”。更苛刻的判断是：

```text
是否长期专注一个关键部件
+ 这个部件是否是 McKinsey 框架里的高风险/高瓶颈环节
+ 公司是否有明确官方产品线和应用场景
+ 是否能解释为什么它难替代
+ 是否已有量产、客户、收入或质量体系证据
```

McKinsey 的框架里，最值得看的是执行器、谐波/应变波减速器、行星滚柱丝杠、机器人级力/触觉传感，以及低延迟控制平台。其中电机、电池、标准轴承、摄像头等能借用相邻产业能力，通常更容易被规模化压价。

## 结论分层

| 层级 | 公司 | 判断 |
|---|---|---|
| 最符合“专注 + 技术瓶颈” | 绿的谐波、雷赛智能、步科股份、柯力传感 | 这些公司主业或产品线更贴近机器人核心部件，且不是简单概念延伸。绿的谐波对应减速器瓶颈；雷赛/步科对应运动控制和关节底层部件；柯力对应力/多维传感。 |
| 不够专注但竞争力可能更强 | 三花智控、拓普集团、汇川技术、双环传动 | 它们不是纯具身公司，但有汽车/工业自动化量产、客户、质量体系和成本能力。竞争力来自制造平台和客户导入，而不是单点技术纯度。 |
| 方向对但领先证据不足 | 中大力德、鸣志电器、兆威机电、五洲新春、北特科技、贝斯特、安培龙 | 产品方向有意义，但需要核量产收入、客户和技术指标。很多仍可能处在样品/送样/小批量阶段。 |
| 暂不按领先公司看 | 丰立智能、东华测试、埃斯顿、南方精工、苏轴股份、汉宇集团、捷昌驱动、众辰科技、信捷电气 | 有机器人相关性，但要么财务承压，要么机器人不是核心瓶颈，要么更偏泛工业自动化或参股培育。 |

## 重点公司判断

### 绿的谐波

最专注。公司对应的是谐波/应变波减速器和旋转执行器。McKinsey 把 harmonic / strain-wave drives 列为高风险瓶颈，因为它们精密制造难、供应商集中、扩产和客户认证周期长。Leaderdrive 官网的人形机器人应用页也明确指出人形机器人关节需要紧凑、高扭矩、低重量的应变波齿轮/谐波减速器和高级旋转执行器。

初判：技术位置最硬，但估值极高，必须核订单、毛利率和产能。

### 雷赛智能

较专注。雷赛不只是“机器人概念”，官网已把人形机器人核心部件单列，覆盖无框电机、空心杯电机、编码器、驱动器、关节模组和灵巧手方案。它不是只做一个零件，而是在执行器底层部件和运动控制上做组合供应。

初判：产品链条贴近关节核心，技术相关性强；但估值高，真实批量收入和客户质量是关键。

### 步科股份

较专注。步科定位是机器人与智能设备运动控制、人机交互部件供应商，官网展示人形机器人关节运动控制部件方案和无框力矩电机。它的优势在运动控制和伺服部件，但财务上自由现金流弱，当前估值主要反映预期。

初判：技术路线对，专注度不错；但需要证明规模收入和现金利润。

### 柯力传感

专注传感器。公司长期做传感器和工业物联网，官网列出机器人多维力传感器。McKinsey 认为六轴力/扭矩传感、线性力传感、触觉传感属于高风险瓶颈，原因是校准、计量、质量控制要求高，难直接借用汽车或消费电子规模。

初判：方向重要，但机器人传感器收入占比、客户和批量能力还要核。

### 三花智控

不专注，但可能强。公司主业是制冷空调和汽车热管理零部件，2025 年报把仿生机器人机电执行器作为战略新兴业务，强调研发、大规模生产和热管理阀泵技术迁移。它的优势不是“机器人技术最纯”，而是制造、客户、质量体系、全球产能和成本控制。

初判：若客户定点真实且能放量，可能比小公司更能交付；但不能把热管理领先自动等同于机器人执行器领先。

### 拓普集团

不专注，但迁移逻辑清楚。官网已单列机器人执行器事业部，产品包括直线执行器、旋转执行器和机械臂系统。公司本体是汽车零部件平台型企业，底盘、轻量化、热管理、智能座舱、空气悬架等能力与执行器集成有相邻性。

初判：竞争力更像“汽车级制造平台外溢”，而不是纯单点技术领先。

### 汇川技术

不专注，但底座能力强。汇川的优势在工业自动化、驱动、伺服、控制，是机器人运动控制底座公司。问题是具身智能收入边界不清；它可能强在平台能力，但未必是人形机器人单一瓶颈零件的最大受益者。

### 双环传动

不够纯，但财务和制造基础更实在。双环是汽车齿轮和精密传动公司，已有机器人关节减速器批量制造相关披露。相比绿的谐波，它更偏齿轮/传动制造平台，机器人业务不是全部。

初判：不像绿的那么纯，但估值和财务更容易研究。

## 当前排序

如果只问“专注 + 技术瓶颈”，优先顺序：

1. 绿的谐波
2. 雷赛智能
3. 步科股份
4. 柯力传感
5. 中大力德 / 鸣志电器 / 兆威机电

如果问“可能真正做成生意”，优先顺序会变成：

1. 三花智控
2. 拓普集团
3. 雷赛智能
4. 绿的谐波
5. 汇川技术 / 双环传动

原因是具身智能从样机到量产时，不只拼技术参数，还拼客户导入、质量体系、成本控制、供应链组织和交付能力。

## 下一步

正式股票研究应先做两类代表：

- 纯技术瓶颈代表：绿的谐波、雷赛智能。
- 制造平台代表：三花智控、拓普集团。

这四家能帮助区分“技术专注型公司”和“制造平台型公司”哪类更可能留住利润。

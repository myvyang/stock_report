# 公司研究成果与发布边界

`stock_report`保存公司研究的原始披露、结构化结果、正式正文和历史版本，承担内部中转与数字追溯，不承担面向读者的发布。

当前公司研究成果固定写入：

```text
data/analysis/stock_research/<证券代码>/<报告期>/result.json
data/analysis/stock_research/<证券代码>/<报告期>/report.md
```

当前结构化协议是`stock-research-analysis-v2`。事实来源、标准字段映射、研究估计、公式结果和Sol核心自审保存在`result.json`；`report.md`只呈现转写表与公司特定经营分析。旧协议和历史版本可以继续保存，但同一报告期的当前协议是内部正式读取入口。

AH Note是唯一公开渠道。它只读取通过协议门槛的结果，并按证券选择最新报告期；本仓库的Git文件地址不作为报告交付链接。发布层不得修补经营数字、估值或中心判断，研究错误必须回到上游模型或报告修正。

原始财报、标准化事实和早期资产结构复核仍属于本仓库的可追溯数据资产。它们与当前公司研究成果分层保存，不因发布角色变化而删除或重命名。

## Engineering Facts Learned

- Tencent quote endpoint `https://qt.gtimg.cn/q=<symbol>` works for SH, SZ, BJ and STAR examples tested.
- Tencent response is GBK/GB18030 encoded; decoding as UTF-8 causes company-name mojibake.
- Eastmoney push2 JSON worked for SH 600, SZ 000 and BJ 920 examples, but returned an empty connection for `688188.SH` in this environment; it is used as fallback rather than sole source.
- Tencent field 3 is current price, field 30 is quote timestamp, field 31 is price change and field 32 is percentage change.

## Mistakes And Corrections

- Initial Tencent decode used UTF-8 and produced garbled Chinese names; changed quote response decoding to `gb18030`.
- One parallel test command hit a chmod race; subsequent tests use `python3 script.py` and the script is executable.

## Project Memory Candidates

- Current stock price is market data, not a financial statement fact. Store it in `market_price`, show it below the report title, and exclude it from financial-statement reconciliations.
